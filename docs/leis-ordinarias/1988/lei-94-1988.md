**LEI Nº-94/88, De 02 de fevereiro de 1988.**
{ .centro }

Dispõe sobre a re-ratificação das Leis nº-403/82, de 27.05.82, e [84/87, de 07.10.87](../1987/lei-84-1987.md), e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica retificado o prazo constante do Art. 1º da [Lei Municipal nº-84/87, de 07.10.87](../1987/lei-84-1987.md#art-1), por mais 12 (doze) meses a partir da data da publicação da presente Lei.
{ #art-1 }

**Art. 2º** - Ficam ratificados todos os demais termos da Lei Municipal nº-403/82, de 27.05.82 e da Lei constante no artigo anterior.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos dois dias do mês de fevereiro de 1988.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
