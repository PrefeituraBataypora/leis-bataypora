**LEI Nº-97/88, De 18 de agosto de 1988.**
{ .centro }

Dispõe sobre Empréstimo de Bens Imóveis, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica autorizado o Poder Executivo, a ceder por empréstimo o prédio da Creche, para funcionamento provisório da Sociedade Hospitalar São Lucas.
{ #art-1 }

Parágrafo Único - O período do empréstimo será o necessário para a reforma do Hospital constante deste artigo.

**Art. 2º** - Sendo o Hospital Entidade Filantrópica, não será exigido nenhuma despesa de aluguel.
{ #art-2 }

Parágrafo Único - Havendo danificação no prédio, a Entidade constante deste artigo se responsabilizará pelo reparo.

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos dezoito dias do mês de agosto de 1988.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
