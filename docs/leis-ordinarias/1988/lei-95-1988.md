**LEI Nº-95/88, De 16 de março de 1988.**
{ .centro }

Dispõe sobre realinhamento salarial do Magistério Municipal, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Ficam fixados os vencimentos do Pessoal do Magistério Municipal, de conformidade com os [anexos I e II](#anexos) da presente Lei, que dispõe sobre a classificação de cargos, consideradas as habilitações especificadas dos Servidores, constantes da [Lei nº-76/86](../1986/lei-76-1986.md) (Estatuto do Magistério Público Municipal).
{ #art-1 }

**Art. 2º** - Havendo aumento do Piso Salarial ou Salário Mínimo Referência vigente nesta data, fica o Prefeito Municipal autorizado a decretar reajustes ou reposições salariais no presente exercício, obedecendo a legislação Federal e a situação econômica municipal.
{ #art-2 }

Parágrafo Único - Toda vez que for decretado reajuste ou reposição constantes deste artigo, o Executivo Municipal fica obrigado a encaminhar cópia do Decreto ao Poder Legislativo.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação, retroagindo seus efeitos a partir de 1º de março de 1.988.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos dezesseis dias do mês de março de 1988.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
