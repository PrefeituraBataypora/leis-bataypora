**LEI Nº-98/88, De 31 de agosto de 1988.**
{ .centro }

Dispõe sobre serviços em propriedades de terceiros, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a executar a drenagem da Lagoa do Sapo, através de envaletamento na propriedade do Sr. Diego Sanches Marchi, numa extensão de aproximadamente 900metros.
{ #art-1 }

Parágrafo Único - Os serviços constantes deste artigo serão executados por retro-escavadeira.

**Art. 2º** - As despesas decorrentes com a execução desta Lei, correrão por conta de verbas constantes no orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos trinta e um dias do mês de agosto de 1988.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
