**LEI Nº-155/91, De 22 de maio de 1991.**
{ .centro .revogado .tudo }

Cria o Fundo Especial de Saúde-FES-do Município de Batayporã, e dá outras providencias.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.
{ .revogado .tudo }

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica criado o Fundo Especial de Saúde de Batayporã, vinculado ao Deptº de Saúde, com a finalidade de administrar os recursos do Sistema Único de Saúde (SUS) transferidos pela União, pelo Estado, bem como a contrapartida do Município na forma da Lei Federal nº-8.142, de 28.12.90.
{ #art-1 .revogado }

Parágrafo único - Na administração de recursos que trata este artigo, compreende-se:
{ .revogado .tudo }

I - realização de despesas correntes e de capital necessárias ao atendimento das ações e serviços públicos de Saúde Integrantes do SUS, respeitadas as normas previstas em convênios e termos aditivos.
{ .revogado .tudo }

II - transferências de recursos destinados às ações e serviços do SUS a serem executados pelo Município.
{ .revogado .tudo }

**Art. 2º** - O Fundo Municipal de Saúde de Batayporã será administrado por um Conselho Administrativo composto pelo Deptº de Saúde, que o presidirá; pelo seu Diretor ou responsável; pelo Coordenador e um Servidor do Setor de Contabilidade.
{ #art-2 .revogado }

Parágrafo único - O Conselho Administrativo do Fundo Municipal de Saúde de Batayporã será apoiado, no desenvolvimento de suas atividades administrativas, pelos órgãos integrantes da Estrutura do Deptº de Saúde.
{ .revogado .tudo }

**Art. 3º** - Constituem Receitas do Fundo Municipal de Saúde de Batayporã;
{ #art-3 .revogado }

I - recursos de prestação de serviços públicos de Saúde recebido do Ministério da Saúde-INAMPS, através do Sistema de Cobertura Ambulatorial e Hospitalar;
{ .revogado .tudo }

II - recursos específicos para programas especiais de Saúde;
{ .revogado .tudo }

III - transferências à conta de orçamento do Município;
{ .revogado .tudo }

IV - auxílios, subvenções, convênios e contribuições de entidades públicas e/ou privadas, nacionais ou estrangeiras, desde que destinados especificamente ao desenvolvimento de ações de saúde;
{ .revogado .tudo }

V - recursos provenientes de aplicações financeiras e alienações na forma da Lei, de bens móveis e imóveis incorporados às unidades de Saúde do Deptº de Saúde;
{ .revogado .tudo }

VI - doações e legados; e
{ .revogado .tudo }

VII - outras rendas eventuais.
{ .revogado .tudo }

Parágrafo único - À conta de recursos provenientes do ítem I deste artigo, poderão ser realizadas despesas com o pagamento de gratificação de pessoal do Quadro do Deptº de Saúde, conforme dispuser o regulamento.
{ .revogado .tudo }

**Art. 4º** - Os saldos financeiros do Fundo Municipal de Saúde de Batayporã, verificados ao final de cada exercício, serão automáticamente transferidos para o exercício seguinte, a seu crédito.
{ #art-4 .revogado }

**Art. 5º** - As Receitas do Fundo Municipal de Saúde de Batayporã e as importâncias arrecadadas a qualquer título serão depositadas e mantidas em conta especial, no Banco do Brasil S/A, Agência Local.
{ #art-5 .revogado }

**Art. 6º** - A execução orçamentária do Fundo Municipal de Saúde de Batayporã atenderá as normas gerais estabelecidas pela Lei Federal nº-4.320/64, assim como as normas peculiares de controle, prestação e tomada de contas baixadas pela Inspetoria Geral de Finanças da Secretaria de Estado de Fazenda
{ #art-6 .revogado }

**Art. 7º** - O Fundo Municipal de Saúde de Batayporã será fiscalizado, internamente, pelo Conselho Municipal de Saúde e, na conformidade da Lei, pelo Tribunal de Contas do Estado.
{ #art-7 .revogado }

**Art. 8º** - No prazo de até 30 (trinta) dias, a partir da publicação desta Lei, o Poder Executivo expedirá decreto regulamentador do Fundo Municipal de Saúde, observadas as finalidades de suas instituições e obedecidas as disposições legais.
{ #art-8 .revogado }

**Art. 9º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-9 .revogado }

Prefeitura Municipal de Batayporã-MS, aos vinte e dois dias do mês de maio de 1991.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
