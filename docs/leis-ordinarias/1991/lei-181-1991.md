**LEI Nº181/91, De 28 de novembro de 1991.**
{ .centro }

Dispõe sobre abertura de créditos suplementares no Orçamento do Município, para o exercício financeiro de 1991, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido o limite constante da [Lei nº-150/90, de 23.11.90](../1990/lei-150-1990.md), fica o Poder Executivo autorizado a suplementar mais 20% (vinte por cento) da despesa orçada.
{ #art-1 }

Parágrafo único - São recursos para abertura de créditos suplementares constantes deste artigo, os previstos na Lei nº-4.320/64.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos vinte e oito dias do mês de novembro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de constume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }
