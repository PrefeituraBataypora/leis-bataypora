**LEI Nº-179/91, De 27 de novembro de 1991.**
{ .centro }

Dispõe sobre concessão de abono salarial aos Servidores da Câmara Municipal e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Artigo 1º** - Fica concedido um abono salarial aos servidores da Câmara Municipal de Batayporã-MS., para o mês de Novembro do corrente ano, segundo as seguintes faixas salariais:
{ #art-1 }

I - De CR$-20.000,00 (Vinte mil cruzeiros), para os que recebem salários até CR$-103.000,00 (Cento e três mil cruzeiros);

II - De CR$-30.000,00 (Trinta mil cruzeiros), para os que recebem salários de CR$-103.001,00 à CR$-180.000,00.

III - De CR$-40.000,00 (Quarenta mil cruzeiros), para os que recebem salários acima de CR$-180.001,00.

**Artigo 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-2 }

**Artigo 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Artigo 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e sete dias do mês de novembro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
