**LEI Nº-168/91, De 23 de outubro de 1991.**
{ .centro }

Dispõe sobre criação do Mercado Municipal de Batayporã-MS, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Artigo 1º** - Fica criado o Mercado Municipal, com a denominação de **MERCADO MUNICIPAL DE BATAYPORÃ-MS**, que funcionará em prédio próprio, na Rua Ataliba Ramos.
{ #art-1 }

**Artigo 2º** - No Mercado Municipal criado pelo artigo anterior, serão permitidas instalações para venda dos seguintes produtos:
{ #art-2 }

a- nos boxes: flores, sementes, jornais, revistas e artigos de consumo para o asseio e o uso doméstico;

b- no centro demarcado: em bancas, todos os produtos de gêneros alimentícios, de limpeza e de consumo popular.

Parágrafo único - Nas atividades constantes deste artigo, terão prioridades os produtos já consignados em Feiras-Livres oriundos dos lavradores e as sociedades constituídas de produtores, para o comércio dos produtos de sua cultura, localizados no Município, de preferência.

**Artigo 3º** - Iniciado o funcionamento do Mercado, ficará extinta a Feira-Livre na parte central da cidade.
{ #art-3 }

**Artigo 4º** - Após a aprovação desta Lei, o Executivo Municipal regulamentará no prazo máximo de até 30 dias o funcionamento do Mercado Municipal.
{ #art-4 }

Parágrafo único - O regulamento constante deste artigo, será elaborado por uma Comissão formada de até 05 (cinco) membros, sendo um indicado pelo Legislativo Municipal.

**Artigo 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-5 }

**Artigo 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos vinte e três dias do mês de outubro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
