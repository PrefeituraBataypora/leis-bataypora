**LEI Nº177/91, De 27 de novembro de 1991.**
{ .centro }

Dispõe sobre aquisição e doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir imóveis de até 10.000m² (dez mil metros quadrados).
{ #art-1 }

Parágrafo único - A aquisição constante deste artigo será precedida de avaliação prévia por uma Comissão Especial nomeada para os fins específicos, composta de até 5 (cinco) membros.

**Art. 2º** - Adquirido o imóvel na forma do artigo anterior, fica também autorizado a efetuar a doação para interessados a instalar cerâmica mecanizada neste Município.
{ #art-2 }

**Art. 3º** - Os interessados serão obrigados a instalar sua Indústria mediante a apresentação de Projetos aprovados pela Prefeitura.
{ #art-3 }

**Art. 4º** - A doação constante do artigo segundo, poderá ser realizada com imóvel da própria municipalidade.
{ #art-4 }

**Art. 5º** - O prazo para instalação previsto no artigo terceiro, é de 12 (doze) meses, com 06 (seis) de carência, a partir da aprovação desta Lei.
{ #art-5 }

**Art. 6º** - Não cumpridas as exigências constantes da presente Lei, o imóvel doado retornará ao domínio do Município.
{ #art-6 }

**Art. 7º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-7 }

**Art. 8º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-8 }

Prefeitura Municipal de Batayporã-MS, aos vinte e sete dias do mês de novembro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
