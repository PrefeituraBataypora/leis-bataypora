**LEI Nº175/91, De 08 de novembro de 1991.**
{ .centro }

Dispõe sobre denominação de Vila, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica denominada de Vila **"CANTIDIANO DUARTE"**, a vila localizada no prolongamento da Avenida Brasil, oriunda do loteamento promovida pelo Executivo Municipal.
{ #art-1 }

Parágrafo único - A vila constante no "caput" deste artigo, é parte da chácara adquirida recentemente da Srª. ROMANA LOPES DUARTE.

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verbas próprias, constantes no Orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos oito dias do mês de novembro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
