**LEI Nº154/91, De 08 de maio de 1991.**
{ .centro }

Dispõe sobre doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a efetuar doações de imóveis parcial ou total, até o limite de 12.300m² (doze mil e trezentos metros quadrados).
{ #art-1 }

Parágrafo único - A doação constante deste artigo será realizada de imóveis do Patrimônio do Município, localizados na margem esquerda do Córrego Esperança, conforme consta das escrituras de domínio da municipalidade, respeitando-se as doações anteriores, preservando uma área adequada para construção do Balneáreo Público.

**Art. 2º** - As doações constantes do artigo anterior, será feita a empresários interessados que comprometam-se em construir e instalar as seguintes atividades ou ramos industriais, a saber:
{ #art-2 }

a. área de **10.300m² (dez mil e trezentos metros quadrados)** para um laboratório de produção de alevinos, para facilitar o crescimento desta atividade no Município e região;

b. área de **2.000m² (dois mil metros quadrados)** para uma estufa, destinada ao cultivo de verduras, legumes e flores, também para expandir o incentivo e o comércio da região.

**Art. 3º** - Os interessados deverão apresentar Projetos para aprovação da atividade e aceitação no Município, através de documento que comprometa a garantia de instalação e funcionamento.
{ #art-3 }

**Art. 4º** - O prazo para construção e instalação previstos nos artigos anteriores, é de seis meses, com três de carência, a partir da aprovação da presente Lei.
{ #art-4 }

**Art. 5º** - Não cumpridas as exigências constantes da presente Lei, os imóveis doados retornarão ao domínio do Município.
{ #art-5 }

**Art. 6º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-6 }

**Art. 7º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Batayporã-MS, aos oito dias do mês de maio de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
