**LEI Nº161/91, De 26 de junho de 1991.**
{ .centro }

Dispõe sobre Isenção de Pagamento de Ingressos no Estádio Municipal Mohamed Mustafá, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica isento de pagamento de ingressos para adentrar no Estádio Municipal Mohamed Mustafá, todas as pessoas idosas com idade acima de 60 (sessenta) anos.
{ #art-1 }

**Art. 2º** - Todos os beneficiados com a presente Lei, ficarão obrigados a apresentarem documentos de identidades na Portaria do Estádio Municipal.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e seis dias do mês de junho de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
