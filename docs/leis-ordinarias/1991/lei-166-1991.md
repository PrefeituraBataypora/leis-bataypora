**LEI Nº-166/91, De 21 de agosto de 1991.**
{ .centro }

Dispõe sobre aquisição de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir um imóvel urbano ou rural até 30.000m² (trinta mil metros quadrados).
{ #art-1 }

Parágrafo único - A aquisição constante deste artigo será precedida de avaliação prévia, por uma Comissão Especial nomeada para os fins específicos, composta de cinco Membros.

**Art. 2º** - O imóvel adquirido de conformidade com o artigo 1º, será destinado para armazenamento e ou construção de usina de beneficiamento do lixo.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e um dias do mês de agosto de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
