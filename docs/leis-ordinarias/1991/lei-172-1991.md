**LEI Nº172/91, De 23 de outubro de 1991.**
{ .centro }

Dispõe sobre a poda de árvores plantadas em logradouros públicos, dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a proceder a poda de árvores anualmente, nas épocas próprias, independente de solicitação ou requerimento de interessados.
{ #art-1 }

Parágrafo único - As árvores referidas no caput deste artigo, são apenas as plantadas em logradouros públicos.

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de dotações próprias, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e três dias do mês de outubro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.
