**LEI Nº-178/91, De 27 de novembro de 1991.**
{ .centro }

Dispõe sobre concessão de abono salarial aos Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Artigo 1º** - Fica o Poder Executivo autorizado a conceder abono a todos os Servidores Públicos Municipais, para o mês de Novembro do corrente ano; segundo as seguintes faixas salariais:
{ #art-1 }

I - De CR$-20.000,00 (Vinte mil cruzeiros), para os que recebem salários até CR$-103.000,00 (Cento e três mil cruzeiros);

II - De CR$-30.000,00 (Trinta mil cruzeiros), para os que recebem salários, de CR$-103.001,00 (Cento e três mil e um cruzeiros) até CR$-180.000,00 (Cento e oitenta mil cruzeiros);

III - De CR$-40.000,00 (Quarenta mil cruzeiros), para os que recebem salários acima de CR$-180.001,00 (Cento e oitenta mil e um cruzeiro).

Parágrafo único - O abono concedido pelo presente artigo, será pago até o dia 15 do mês seguinte ao da concessão.

**Art. 2º** - Não havendo reajuste no salário mínimo para o mês de dezembro, fica o Poder Executivo autorizado a conceder outro abono para o mês de até 150% (cento e cinquenta por cento) do concedido no artigo anterior, obedecendo a situação financeira do Município.
{ #art-2 }

**Artigo 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor, suplementadas se necessário.
{ #art-3 }

**Artigo 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Artigo 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos vinte e sete dias do mês de novembro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
