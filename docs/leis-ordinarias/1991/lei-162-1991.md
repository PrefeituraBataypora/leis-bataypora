**LEI Nº-162/91, De 25 de julho de 1991.**
{ .centro .revogado .tudo }

INSTITUI REGIME JURÍDICO ÚNICO, SISTEMA DE ADMINISTRAÇÃO DE PESSOAL E PLANO DE CARREIRA NA PREFEITURA MUNICIPAL DE BATAYPORÃ-MS, E DÁ OUTRAS PROVIDÊNCIAS.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço Saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

## CAPÍTULO I — DO REGIME JURÍDICO ÚNICO { .centro .revogado }

**Artigo 1º** - Fica instituído Regime Jurídico Único de contratação para os Servidores da Prefeitura e Câmara Municipal de Batayporã.
{ #art-1 .revogado }

**Artigo 2º** - O Regime ora instituído é o Trabalhista, e estabelecerá as relações entre a Prefeitura e Câmara Municipal e seus Servidores, nos termos da Consolidação das Leis do Trabalho-**CLT (Decreto-Lei Federal nº-5.452, de 01.05.43)**.
{ #art-2 .revogado }

!!! danger "Revogado pela Lei nº 241/1993"
    Revogado pelo [art. 1º da Lei nº 241/1993](../1993/lei-241-1993.md#art-1).

## CAPÍTULO II — DO SISTEMA DE ADMINISTRAÇÃO DO PESSOAL { .centro .revogado }

**Artigo 3º** - Esta Lei institui o Sistema de Administração de Pessoal, o quadro de pessoal de carreira, a escala de vencimentos e salários, a progressão funcional e ascensão funcional dos Servidores Públicos da Prefeitura Municipal de Batayporã, exceto os Servidores regidos pelo Estatuto do Magistério Público Municipal.
{ #art-3 .revogado }

**Artigo 4º** - Os Servidores Públicos Municipais, constantes do Quadro do Magistério, reger-se-ão pelo Estatuto do Magistério Público Municipal, **Lei nº-76/86, de 28 de novembro de 1986**.
{ #art-4 .revogado }

**Artigo 5º** - O Sistema de Administração de Pessoal compreende os seguintes órgãos:
{ #art-5 .revogado }

I - ÓRGÃOS DE ASSISTÊNCIA DIRETA E IMEDIATA AO PREFEITO
{ .revogado .tudo }

II - ÓRGÃOS CENTRAIS DE DIREÇÃO SUPERIOR
{ .revogado .tudo }

III - ÓRGÃOS VINCULADOS
{ .revogado .tudo }

**Artigo 6º** - Para efeito da presente Lei, considera-se:
{ #art-6 .revogado }

I - **CARGO** - é o lugar instituído na organização do funcionalismo, com denominação própria, atribuições específicas e remuneração correspondente, para ser exercido por um titular, na forma estabelecida em Lei;
{ .revogado .tudo }

II - **FUNÇÃO** - é a atribuição ou conjunto de atribuições que a Administração confere a cada categoria funcional, ou comete individualmente a determinados Servidores para a execução de serviços;
{ .revogado .tudo }

III - **CLASSE** - O conjunto de cargos da mesma natureza;
{ .revogado .tudo }

IV - **CATEGORIA FUNCIONAL** - O conjunto de atividades desdobráveis em classes e identificados pela natureza e pelo grau de conhecimento exigível para o seu desempenho;
{ .revogado .tudo }

V - **GRUPO** - O conjunto de categorias funcionais, segundo a correlação e afinidade entre as atividades de cada uma, a natureza do trabalho ou o grau de conhecimento necessário ao exercício das respectivas atribuições;
{ .revogado .tudo }

VI - **EMPREGADO PÚBLICO** - Servidor contratado para prestar serviços sob o regime de contratação da Consolidação das Leis do Trabalho-CLT;
{ .revogado .tudo }

VII - **FUNCIONÁRIO PÚBLICO** - Pessoa admitida no serviço público com seus direitos regidos pelo Estatuto do Servidor;
{ .revogado .tudo }

VIII - **ESCALA DE REFERÊNCIAS** - Escala de Referências Numéricas para o pessoal de Nível Intermediário e Superior-**NIS**, bem como para o pessoal de Nível Médio-**NM**, numeradas de 01 a 43, com respectivos valores de vencimentos ou salários;
{ .revogado .tudo }

IX - **PROGRESSÃO FUNCIONAL** - é a mudança do Servidor, da referência em que se encontra para a imediatamente superior;
{ .revogado .tudo }

X - **ASCENSÃO FUNCIONAL** - é a mudança do Servidor da categoria funcional em que se encontra para outra superior;
{ .revogado .tudo }

XI - **QUADRO GERAL DE PESSOAL** - é o conjunto de cargos, funções e empregos públicos pertinentes à Prefeitura Municipal.
{ .revogado .tudo }

## CAPÍTULO III — DO QUADRO GERAL DE PESSOAL { .centro .revogado }

**Artigo 7º** - O Quadro Geral de Pessoal da Prefeitura Municipal de Batayporã é composto de 04 grupos:
{ #art-7 .revogado }

I - Quadro de Pessoal de Carreira, composto do grupo de pessoal das categorias funcionais relacionadas no **QUADRO 1**.
{ .revogado .tudo }

II - Grupo Assessoria Técnica, composto dos cargos previstos no **QUADRO 2**.
{ .revogado .tudo }

III - Grupo Chefia, composto dos cargos previstos no **QUADRO 3**.
{ .revogado .tudo }

IV - Quadro do Magistério Público Municipal.
{ .revogado .tudo }

§1º - Fica limitado em 180 (cento e oitenta) o número de empregos previstos no **QUADRO 1**.
{ .revogado .tudo }

§2º - Fica limitado em 05 (cinco) o número de empregos previstos no **QUADRO 2**.
{ .revogado .tudo }

§3º - O número de cargos previstos no **QUADRO 3**, Grupo Direção Superior-GDS- é de 09 (nove), e de 29 (vinte e nove) o número de funções gratificadas previstas no Grupo Direção Intermediário-GDI, e estão discriminados no Quadro de Correlação de Remuneração e Gratificação, **QUADRO 4**, anexo a esta Lei.
{ .revogado .tudo }

§4º - Fica limitado em 40 (quarenta) o número de empregos previstos no Quadro do Magistério Público Municipal.
{ .revogado .tudo }

§5º - As funções gratificadas previstas no parágrafo 3º não constituem novos empregos, e serão concedidas a Servidores que forem designados para as funções de Chefias nas condições previstas no parágrafo 3º do artigo 13.
{ .revogado .tudo }

§6º - Qualquer alteração que importe no aumento de empregos, cargos ou funções previstas nos parágrafos 1º, 2º, 3º e 4º acima, dependerá de prévia autorização da **Câmara Municipal de Batayporã**.
{ .revogado .tudo }

!!! info "Alterado pela Lei nº 187/1991 e pela Lei nº 212/1992"
    O [art. 34 da Lei nº 187/1991](lei-187-1991.md#art-34) alterou para 200 (duzentos) o número de empregos previstos no §1º deste artigo. Depois, o [art. 1º da Lei nº 212/1992](../1992/lei-212-1992.md#art-1) elevou esse número para 300 (trezentos), exceto o Quadro de Professores e Especialistas de Educação.

## CAPÍTULO IV — DOS CARGOS E SEU PROVIMENTO { .centro .revogado }

**Artigo 8º** - Ficam criados os empregos, cargos ou funções previstos nos quadros 1, 2, 3 e 4 anexos a esta Lei e os constantes dos anexos I e II da **Lei nº-76/86, de 28.11.86 (Estatuto do Magistério Público Municipal)**.
{ #art-8 .revogado }

**Artigo 9º** - Os empregos, cargos ou funções previstos no artigo anterior são regidos pelo Regime da Consolidação das Leis do Trabalho (C.L.T.).
{ #art-9 .revogado }

**Artigo 10** - Os cargos do Grupo Direção Superior-GDS, previstos no Quadro Chefia, quadro 3, bem como os do Grupo Assessoria Técnica previstos no quadro 2, são em Comissão ou função de confiança de que trata o artigo 468, parágrafo único da Consolidação das Leis do Trabalho.
{ #art-10 .revogado }

Parágrafo único - Para os efeitos do disposto no artigo 468, parágrafo único da CLT, a gratificação prevista no Grupo Direção Intermediária-GDI, do Grupo Chefia, quadro 3, equipara-se a **função de confiança**.
{ .revogado .tudo }

**Artigo 11** - A contratação ou designação para os cargos do Grupo Assessoria Técnica se fará diretamente pela denominação prevista nos grupos Assistente Técnico nível I a V e Assessor nível I a V previstos no quadro 2, através de Portaria do Prefeito Municipal.
{ #art-11 .revogado }

**Artigo 12** - A contratação ou designação para os cargos do Grupo Direção Superior se fará diretamente pela denominação prevista no Quadro de Correlação de Remuneração e Gratificações, especificadas no quadro 4, através de Portaria do Prefeito Municipal.
{ #art-12 .revogado }

**Artigo 13** - O preenchimento dos cargos do Grupo Direção Superior poderá ser feito com o pessoal do Quadro do Pessoal de Carreira ou Pessoal do Grupo Assessoria Técnica.
{ #art-13 .revogado }

§1º - Quando a designação recair em empregado público, este ficará afastado do emprego que exerce, sem prejuízo das vantagens do cargo ou emprego público, ressalvando-se o direito de retorno ao emprego ou cargo de origem.
{ .revogado .tudo }

§2º - Quando a designação recair em Pessoal do Grupo Assessoria Técnica, será feita apenas a devida anotação na Carteira Profissional e demais Registros.
{ .revogado .tudo }

§3º - A gratificação prevista para o Grupo Direção Intermediária, só será concedida ao Pessoal do Quadro de Carreira, e aos Assistentes Técnicos de nível I a V do Grupo Assessoria Técnica, sendo incompatível com a retribuição de cargo ou função do Grupo Direção Superior-GDS, Assessor nível I a V do Grupo Assessoria Técnica, bem como qualquer outra gratificação por vantagem de cargo.
{ .revogado .tudo }

## CAPÍTULO V — DA ESCALA DE REFERÊNCIAS { .centro .revogado }

**Artigo 14** - Os vencimentos e salários dos Servidores Municipais, serão calculados de acordo com as Escalas de Referências constantes dos Anexos I e II que fazem parte integrante desta Lei.
{ #art-14 .revogado }

Parágrafo único - As Escalas de Referências do Pessoal de nível médio, anexo I e de nível intermediário e superior, anexo II, são constituídas de 43 (quarenta e três) referências numéricas indicativas de salário e são representadas por algarismos arábicos.
{ .revogado .tudo }

**Artigo 15** - Os valores dos vencimentos, salários e gratificações do Pessoal do Grupo Assessoria Técnica, bem como dos Grupos Direção Intermediária e Superior, estão previstos nos próprios quadros 2 e 3 respectivamente.
{ #art-15 .revogado }

## CAPÍTULO VI — DO ENQUADRAMENTO { .centro .revogado }

**Artigo 16** - A partir do primeiro dia do mês seguinte ao da publicação desta Lei, os Servidores Municipais serão enquadrados no Quadro de Pessoal de Carreira, no Grupo Assessoria Técnica ou Grupo Chefia constante dos Quadros 1, 2 e 3, que fazem parte integrante desta Lei.
{ #art-16 .revogado }

§1º - O Prefeito Municipal, através de Portaria, constituirá uma Comissão com até cinco membros, com o Chefe do Setor Pessoal, um representante do Legislativo, um representante dos Servidores Municipais legalmente constituído, e até dois Servidores Públicos do Município, que será responsável pelo enquadramento dos Servidores previstos no "caput" deste artigo.
{ .revogado .tudo }

§2º - O enquadramento no Quadro do Pessoal de Carreira se fará nas Escalas de Referências dos Anexos I e II, sendo que o atual salário mais os adicionais do Servidor é que determinará, respeitando-se a referência inicial de sua categoria funcional, a referência em que o Servidor será enquadrado.
{ .revogado .tudo }

§3º - O Prefeito Municipal terá poderes para, promover o reenquadramento de Servidor que eventualmente esteja com desvio de função ou inadequação salarial compatível com sua formação profissional, enquadrando-o na função que realmente esteja exercendo seu trabalho ou referência salarial correspondente.
{ .revogado .tudo }

§4º - O enquadramento de que trata o parágrafo 2º deste artigo será feito através de Decreto do Prefeito Municipal, e através de Portaria para os cargos em Comissão ou função de confiança dos quadros 2, 3 e 4.
{ .revogado .tudo }

**Artigo 17** - Para o enquadramento no Quadro de Pessoal de Carreira deverá ser observado que o salário dos Servidores Municipais não poderá ser inferior ao valor da referência inicial da Categoria Funcional a que pertença, com a bonificação de uma referência por cada 3 (três) anos de serviço que o Servidor tenha completado ou venha completar até 31.12.1991, com a bonificação máxima de 4 (quatro) referências.
{ #art-17 .revogado }

Parágrafo único - O tempo de serviço constante deste artigo é o existente no último contrato de trabalho firmado com o Município.
{ .revogado .tudo }

**Artigo 18** - Os atuais Servidores contratados sob o regime da legislação trabalhista, CLT, serão enquadrados nos novos cargos ou empregos correspondentes, independentemente de nova seleção ou admissão, mediante as anotações trabalhistas devidas.
{ #art-18 .revogado }

Parágrafo único - O enquadramento previsto no "caput" deste artigo não isenta de prestação de **concurso público** os Servidores que eventualmente estejam sujeitos a prestá-lo nas condições previstas na Constituição Federal.
{ .revogado .tudo }

**Artigo 19** - Tendo em vista que a partir da vigência desta Lei, ficam extintos todos os cargos, empregos ou funções anteriormente existentes no Regime da Consolidação das Leis do Trabalho, fica assegurado aos ocupantes de cargo de Chefia extintos, o direito a manutenção de seus salários.
{ #art-19 .revogado }

§1º - O Servidor que tiver sido contratado ou que constar de seus registros trabalhistas como Encarregado, Chefe, Coordenador, Supervisor ou outro, agora extintos, serão enquadrados no Quadro de Pessoal de Carreira na Categoria Funcional que venha guardar correlação com sua formação profissional ou trabalho que venha exercendo efetivamente.
{ .revogado .tudo }

§2º - A criação dos cargos ou funções de Chefias de Seção, Chefias de Setor ou Departamento equivalentes às exercidas pelos Servidores citados no parágrafo anterior, não assegura àqueles a recondução ou nomeação para estes cargos, que por serem de confiança, terão sua designação efetivada por decisão e escolha do Prefeito Municipal, ouvindo, se julgar necessário os Diretores de Departamento.
{ .revogado .tudo }

**Artigo 20** - Após o enquadramento dos atuais Servidores nenhuma contratação poderá ser efetuada senão na referência inicial de cada Categoria Funcional.
{ #art-20 .revogado }

Parágrafo único - Excetua-se da regra acima a contratação do pessoal para os grupos subdivididos em classes, cuja contratação, considerando-se o grau de especialização de cada um, poderá ser efetuada nas referências iniciais das classes que compõem o referido grupo, conforme dispuser o **Edital de Concurso Público**.
{ .revogado .tudo }

**Artigo 21** - A partir da vigência desta Lei, nenhuma mudança de referência de Servidor que não esteja prevista nos artigos anteriores poderá ser efetuada, a não ser através da Progressão Funcional prevista no artigo 22.
{ #art-21 .revogado }

Parágrafo único - A mudança de referência, de uma classe para outra, dos grupos subdivididos em classes, poderá ser concedida pelo Prefeito Municipal, que deverá considerar o grau de especialização de cada um, aferida e atestada pelo superior hierárquico do Servidor.
{ .revogado .tudo }

## CAPÍTULO VII — DA PROGRESSÃO FUNCIONAL { .centro .revogado }

**Artigo 22** - A partir da vigência desta Lei, fica criado o **Instituto de Progressão Funcional**, a ser aplicado aos Servidores Públicos ocupantes das Categorias Funcionais previstas no Quadro de Pessoal de Carreira.
{ #art-22 .revogado }

**Artigo 23** - A efetivação da Progressão Funcional está condicionada ao cumprimento de interstício por parte do Servidor, que é o período de tempo que o Servidor deve ter cumprido entre duas datas.
{ #art-23 .revogado }

§1º - Serão consideradas como **datas-base** para o início de contagem de interstício, sempre o dia primeiro de janeiro e primeiro de julho.
{ .revogado .tudo }

§2º - Serão considerados os dias **primeiro de janeiro e primeiro de julho de 1991** o início de contagem do interstício para fins da primeira Progressão Funcional dos Servidores Públicos da Prefeitura Municipal de Batayporã.
{ .revogado .tudo }

§3º - Os efeitos financeiros da Progressão Funcional terão vigência a partir de **primeiro de março e primeiro de setembro**, conforme o interstício tenha se completado em janeiro ou julho respectivamente.
{ .revogado .tudo }

§4º - A própria Progressão Funcional determina o início de novo interstício, a partir de primeiro de janeiro ou primeiro de julho, imediatamente anterior à sua vigência.
{ .revogado .tudo }

§5º - Os interstícios a serem cumpridos para os fins estabelecidos no Instituto da Progressão Funcional serão de **12 (doze) meses**.
{ .revogado .tudo }

§6º - O Prefeito Municipal aprovará, através de **Decreto**, todas as normas que deverão regulamentar o Instituto da Progressão Funcional.
{ .revogado .tudo }

## CAPÍTULO VIII — DA ASCENSÃO FUNCIONAL { .centro .revogado }

**Artigo 24** - A **Ascensão Funcional** é o ato pelo qual o Servidor Público muda da última referência de uma Categoria Funcional para outra Categoria superior.
{ #art-24 .revogado }

**Artigo 25** - A Ascensão Funcional também será permitida a Servidores que estejam incluídos em Categorias Funcionais de nível médio e concluam curso superior nas profissões previstas nas Categorias Funcionais de nível superior constantes do Quadro de Pessoal de Carreira na presente Lei ou Categorias Funcionais que venham a ser aprovadas futuramente.
{ #art-25 .revogado }

**Artigo 26** - A Ascensão prevista na forma dos artigos 24 e 25 não se fará automaticamente, dependendo sempre, no mínimo de justificativa da Chefia imediata do Servidor ao Prefeito Municipal, no caso do artigo 24, exigindo-se ainda o comprovante de conclusão do curso superior, no caso do artigo 25.
{ #art-26 .revogado }

§1º - O Prefeito Municipal poderá indeferir a Ascensão Funcional prevista no artigo 25 caso considere ser desnecessário o preenchimento de novo cargo de nível superior em áreas que efetivamente já estejam supridas.
{ .revogado .tudo }

§2º - A Ascensão Funcional também determina o início de novo interstício a contar de primeiro de janeiro ou primeiro de julho subsequente à data de exercício no novo cargo ou emprego.
{ .revogado .tudo }

§3º - O Prefeito Municipal baixará normas complementares necessárias à regulamentação da Ascensão Funcional.
{ .revogado .tudo }

## CAPÍTULO IX — DAS SUBSTITUIÇÕES { .centro .revogado }

**Artigo 27** - O Prefeito Municipal poderá designar Servidores para substituirem ocupantes dos Cargos de Chefia do Grupo Direção Superior e Chefia do Grupo Direção Intermediária.
{ #art-27 .revogado }

**Artigo 28** - Nos casos de impedimento legal e temporário dos ocupantes dos cargos de chefia, o substituto ocupará o cargo, com direito à remuneração da gratificação do cargo que esteja substituindo.
{ #art-28 .revogado }

§1º - O Substituto receberá, durante o tempo que exercer o cargo ou função, seus salários cumulativamente com a gratificação do cargo que substituir ou a diferença da sua gratificação, quando tiver, com a gratificação do cargo que passou a exercer.
{ .revogado .tudo }

§2º - Quando o substituto ocupar cargo com gratificação igual à do cargo que substituir, não haverá acumulação de gratificação.
{ .revogado .tudo }

§3º - A designação para as substituições de Chefia será sempre através de Portaria do Prefeito Municipal, ocorrendo a remuneração apenas no caso do "caput" deste artigo, devendo tal fato ser comunicado ao **Setor de Pessoal**.
{ .revogado .tudo }

## CAPÍTULO X — DAS GRATIFICAÇÕES { .centro .revogado }

**Artigo 29** - Além das gratificações previstas no quadro 3, ficam criadas 6 (seis) gratificações de gabinete, sendo 2 (duas) com remuneração correspondente ao Código GDI-2, 2 (duas) correspondentes ao Código GDI-4 e 2 (duas) correspondentes ao Código GDI-6.
{ #art-29 .revogado }

§1º - A gratificação será concedida mediante designação individual, através de Portaria do Prefeito Municipal e é destinada a Servidores que prestem serviços considerados relevantes, preferencialmente servindo ao Gabinete do Prefeito, no serviço de melhoria de atendimento ao público, no serviço de saúde, nos convênios com órgãos estaduais ou federais ou outros a critério do Prefeito.
{ .revogado .tudo }

§2º - Para os efeitos do disposto no artigo 468, parágrafo único da CLT, a gratificação equipara-se a **Função de Confiança**.
{ .revogado .tudo }

§3º - A percepção da gratificação instituída neste artigo é incompatível com a retribuição de cargo ou função do Grupo Direção Superior, bem como de Assessores de nível I a V.
{ .revogado .tudo }

## CAPÍTULO XI — DAS DISPOSIÇÕES GERAIS E TRANSITÓRIAS { .centro .revogado }

**Artigo 30** - No prazo de 180 (cento e oitenta) dias a contar da publicação desta Lei, o Prefeito Municipal deverá aprovar por Decreto um manual ou outro documento que terá a finalidade de orientar a Administração no tocante às atribuições de cada Categoria Funcional existente na Prefeitura Municipal de Batayporã, que será um roteiro permanente às atribuições/tarefas de cada Categoria e visará orientar a adequação funcional do Servidor nos respectivos campos de trabalho.
{ #art-30 .revogado }

Parágrafo único - O Manual deverá conter, para cada Categoria Funcional, a descrição das atribuições, as tarefas típicas da Categoria ou Classe, a forma de recrutamento e seleção do Pessoal, bem como a escolaridade exigida.
{ .revogado .tudo }

**Artigo 31** - Após o enquadramento dos Servidores na forma prevista nesta Lei, o Prefeito Municipal encaminhará à **Câmara Municipal um Projeto de Lei** quantificando por Grupo e Categoria Funcional os empregos e cargos previstos no Quadro de Pessoal de Carreira-**QUADRO 1** e no **Quadro do Magistério** Público Municipal, respeitando-se os limites previstos nos parágrafos primeiro e quarto do artigo 7º.
{ #art-31 .revogado }

**Artigo 32** - Esta Lei entrará em vigor no dia primeiro do mês seguinte ao da sua publicação, **revogadas todas as disposições em contrário**.
{ #art-32 .revogado }
