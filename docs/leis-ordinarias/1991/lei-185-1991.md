**LEI Nº185/91, De 11 de dezembro de 1991.**
{ .centro }

Dispõe sobre denominação de Quadra Poliesportiva e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica denominado a Quadra Poliesportiva localizada na sede da Fazenda Primavera, neste Município de **ACREP - ASSOCIAÇÃO CULTURAL RECREATIVA E ESPORTIVA PRIMAVERA**.
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente lei, correrão por conta de verba própria constante no orçamento vigente.
{ #art-2 }

**Art. 3º** - Esta lei entrará em vigor na data de sua aplicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos onze dias do mês de dezembro de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
