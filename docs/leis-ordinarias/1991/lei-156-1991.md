**LEI Nº-156/91, De 22 de maio de 1991.**
{ .centro }

Dispõe sobre reajuste salarial aos Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Artigo 1º** - Fica concedido um reajuste salarial aos Servidores Públicos Municipais, sobre seus vencimentos, de **15% (quinze por cento), e mais o abono concedido pela legislação federal**.
{ #art-1 }

**Artigo 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Artigo 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 01.05.91.
{ #art-3 }

**Artigo 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e dois dias do mês de maio de 1991.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
