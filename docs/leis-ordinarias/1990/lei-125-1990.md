**LEI Nº-125/90, De 04 de abril de 1990.**
{ .centro }

Dispõe sobre a re-ratificação da Lei nº-116/89, de 28.07.89, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS, Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Ficam retificados a letra "C" do artigo 2º, e artigo 4º, da [Lei nº-116/89, de 28.07.89](../1989/lei-116-1989.md), de Frigorífico Maringá S/A, para "FRIPORÃ-Frigorífico Bataiporã Ltda".
{ #art-1 }

**Art. 2º** - Ficam ratificados todos os demais termos da Lei Municipal nº-116/89, de 28.07.89.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos quatro dias do mês de abril de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
