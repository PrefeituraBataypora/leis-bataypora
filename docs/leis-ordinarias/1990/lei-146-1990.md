**LEI N 146/90, De 05 de setembro de 1990.**
{ .centro }

Dispõe sobre perfuração e doação de Poço Artesiano, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a perfurar e doar um Poço Artesiano para o FRIPORÃ-Frigorífico Batayporã Ltda.
{ #art-1 }

Parágrafo único - O Poço constante deste artigo será perfurado no imóvel de propriedade do beneficiário, para fornecimento de água à sua Indústria.

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no Orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos cinco dias do mês de setembro de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
