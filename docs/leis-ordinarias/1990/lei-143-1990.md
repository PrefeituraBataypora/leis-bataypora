**LEI Nº-143/90, De 15 de agosto de 1990.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores da Câmara Municipal de Batayporã-MS., e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento de 10% (dez por cento) sobre os vencimentos dos Servidores da Câmara Municipal.
{ #art-1 }

**Art. 2º** - Fica concedido a todos os Servidores da Câmara Municipal, no mês de agosto de 1990, um abono no valor de CR$-3.000,00 (três mil cruzeiros).
{ #art-2 }

Parágrafo Único - O abono a que se refere este artigo não será incorporado aos salários, a qualquer título, nem será sujeito a quaisquer incidências de caráter tributário ou previdenciário.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de agosto de 1990.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS., aos quinze dias do mês de agosto de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
