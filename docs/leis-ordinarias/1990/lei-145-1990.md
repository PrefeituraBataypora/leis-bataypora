**LEI N 145/90, De 05 de setembro de 1990.**
{ .centro }

Dispõe sobre alteração da Lei n 119/89, de 25.10.89.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - O [artigo 3º, da Lei n 119/89](../1989/lei-119-1989.md#art-3), de 25 de outubro de 1989, passa a vigorar com a seguinte redação:
{ #art-1 }

> "Art. 3º - A ASSOCIAÇÃO beneficiada com a doação constante do artigo 2º, será obrigada a desenvolver sómente atividades previstas nos seus Estatutos Sociais.

**Art. 2º** - Ficam suprimidos os artigos 4º e 5º da Lei n 119/89, de 25 de outubro de 1989.
{ #art-2 }

**Art. 3º** - As despesas decorrentes da presente Lei, correrão por conta de dotações orçamentárias constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação opu afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos cinco dias do mês de setembro de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
