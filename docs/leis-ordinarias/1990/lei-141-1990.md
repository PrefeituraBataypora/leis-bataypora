**LEI Nº-141/90, De 15 de agosto de 1990.**
{ .centro }

Dispõe sobre abertura de créditos suplementares no Orçamento do Município, para o exercício financeiro de 1990, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido o limite constante das Leis nº-[121/89](../1989/lei-121-1989.md) e [130/90](lei-130-1990.md), de 30.11.89 e 30.05.90, fica o Poder Executivo autorizado a suplementar mais 100% (cem por cento) da despesa orçada.
{ #art-1 }

Parágrafo Único - São recursos para abertura de créditos suplementares constantes neste artigo, os da Lei nº-4320/64 artigo 43.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS., aos quinze dias do mês de agosto de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
