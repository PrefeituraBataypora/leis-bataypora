**LEI Nº-140/90, De 15 de agosto de 1990.**
{ .centro }

Dispõe sobre doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a doar um imóvel urbano até 630m², para a Igreja Evangélica Assembléia de Deus, Ministério de Madureira.
{ #art-1 }

Parágrafo Único - A doação constante deste artigo será realizada dentre os imóveis de propriedade da municipalidade.

**Art. 2º** - A Igreja beneficiada será obrigada a construir seu Templo, em alvenaria, mediante um Projeto de obra.
{ #art-2 }

**Art. 3º** - O prazo para construção previsto no artigo anterior, é de 12 (doze) meses, com 6 (seis) meses de carência, a partir do recebimento do imóvel.
{ #art-3 }

**Art. 4º** - Não cumpridas as exigências constantes da presente Lei, o imóvel doado retornará ao domínio do Município.
{ #art-4 }

**Art. 5º** - As despesas decorrentes da presente Lei, correrão por conta de dotações orçamentárias, constantes do Orçamento Municipal, suplementadas se necessário.
{ #art-5 }

**Art. 6º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos quinze dias do mês de agosto de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
