**LEI Nº149/90, De 20 de novembro de 1990.**
{ .centro }

Dispõe sobre alteração do Anexo I, da Lei nº-112/89, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Artigo 1º** - Fica fixado o valor e alteradas as referências e grupos do ANEXO I da [Lei nº-112/89, de 28.06.89](../1989/lei-112-1989.md), obedecendo os cargos criados através das Leis nº-[81/87](../1987/lei-81-1987.md) e [118/89](../1989/lei-118-1989.md) (Estrutura Administrativa e Setor da Creche Municipal), de conformidade com o Anexo I.
{ #art-1 }

**Artigo 2º** - Ficam também fixados os vencimentos dos Servidores Municipais, de conformidade com cada referência e nível, constantes dos Anexos I, II e III.
{ #art-2 }

**Artigo 3º** - As despesas decorrentes com a execução da presente Lei, serão atendidas no decorrente exercício, por conta das dotações próprias consignadas no Orçamento vigente, suplementadas se necessário.
{ #art-3 }

**Artigo 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de novembro de 1990.
{ #art-4 }

**Artigo 5º** - Revogam-se a [Lei nº-112/89](../1989/lei-112-1989.md), e as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos vinte dias do mês de novembro de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
