**LEI Nº-131/90, De 20 de junho de 1990.**
{ .centro }

Dispõe sobre aumento de salário aos Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento de 15% (quinze por cento) sobre os vencimentos dos Servidores Públicos Municipais.
{ #art-1 }

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no Orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de junho de 1990.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS., aos vinte dias do mês de junho de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
