**LEI N 139/90, De 08 de agosto de 1990.**
{ .centro }

Dispõe sobre aquisição e doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir um imóvel urbano ou rural até 24.344,32m².
{ #art-1 }

Parágrafo único - A aquisição constante deste artigo será precedida de avaliação prévia, por uma Comissão Especial nomeada para os fins específicos, composta de cinco Membros.

**Art. 2º** - Adquirido o imóvel na forma do artigo anterior, fica também autorizado a efetuar a doação para a COCAMAR - Cooperativa de Cafeicultores e Agropecuaristas de Maringá Ltda, instalar sua filial neste Município.
{ #art-2 }

**Art. 3º** - A COCAMAR será obrigada a instalar sua filial mediante a apresentação de Projetos aprovados pela Prefeitura.
{ #art-3 }

**Art. 4º** - O prazo para instalação previsto no artigo anterior, é de doze meses, com seis de carência, a partir da aprovação da presente Lei.
{ #art-4 }

**Art. 5º** - Não cumpridas as exigências constantes da presente Lei, o imóvel doado retornará ao domínio do Município.
{ #art-5 }

**Art. 6º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-6 }

**Art. 7º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Batayporã-MS, aos oito dias do mês de agosto de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
