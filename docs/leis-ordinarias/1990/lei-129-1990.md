**LEI Nº-129/90, De 18 de maio de 1990.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores da Câmara Municipal de Batayporã, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento de 15% (quinze por cento) sobre os vencimentos dos Servidores da Câmara Municipal.
{ #art-1 }

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta deedotações orçamentárias constante no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de maio de 1990.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos dezoito dias do mês de maio de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
