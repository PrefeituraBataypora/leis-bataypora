**LEI Nº-142/90, De 15 de agosto de 1990.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento salarial aos Servidores Públicos Municipais sobre seus vencimentos de 10% (dez por cento).
{ #art-1 }

**Art. 2º** - Fica concedido a todos os Servidores Públicos do Município, no mês de agosto de 1990, um abono no valor de CR$-3.000,00 (três mil cruzeiros).
{ #art-2 }

Parágrafo Único - O abono a que se refere este artigo não será incorporado aos salários, a qualquer título, nem será sujeito a quaisquer incidências de caráter tributário ou previdenciário.

**Art. 3º** - Havendo aumento do salário mínimo vigente nesta data, fica o Prefeito Municipal autorizado a decretar reajustes ou reposições salariais até o limite verificado no aumento concedido pela Legislação Federal, obedecendo a situação econômica municipal.
{ #art-3 }

Parágrafo Único - Toda vez que for decretado reajuste ou reposição nos salários constantes deste artigo, o Executivo Municipal fica obrigado a encaminhar cópia do decreto ao Poder Legislativo.

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal em vigor.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 01 de agosto de 1990.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS., aos quinze dias do mês de agosto de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
