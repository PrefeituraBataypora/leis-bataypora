**LEI Nº-127/90, De 19 de abril de 1990.**
{ .centro }

Dispõe sobre permuta de imóveis urbanos, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS, Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a realizar a permuta do imóvel data nº-23 da quadra 20, com 630m², sem benfeitorias, pela data nº-06 da quadra 26, com 630m², onde consta uma construção em madeira serrada de 8x5,5, ou seja 44m², de propriedade da Srª. Marinete Pereira de Almeida, com a condição de retirar a construção e colocar no imóvel permutado.
{ #art-1 }

**Art. 2º** - O imóvel adquirido através do artigo 1º, será doado para a Associação de Desenvolvimento Comunitário de Bataiporã, para cumprir as determinações da [Lei nº-116/89](../1989/lei-116-1989.md), de 28.06.89.
{ #art-2 }

**Art. 3º** - As despesas decorrentes da presente Lei, correrão por conta de dotações orçamentárias constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos dezenove dias do mês de abril de 1990.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
