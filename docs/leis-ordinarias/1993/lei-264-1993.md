**LEI Nº-264/93, De 08 de dezembro de 1993.**
{ .centro }

Estima a Receita e fixa a Despesa do Fundo Municipal de Saúde, para o exercício financeiro de 1994.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS., usando das atribuições que lhe são conferidas por Lei, faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Artigo 1º** - O Orçamento Geral para o Fundo Municipal de Saúde para o exercício financeiro de 1994, que será ministrado pela Secretaria Municipal de Saúde, estima a Receita em CR$-180.000.000,00 (cento e oitenta milhões de cruzeiros reais), e fixa a Despesa em CR$-180.000.000,00 (cento e oitenta milhões de cruzeiros reais), discriminados pelos anexos integrantes desta Lei.
{ #art-1 }

**Artigo 2º** - A Receita será realizada mediante a arrecadação dos tributos, rendas e outras receitas correntes e de capital, na forma da legislação em vigor e das especificações constantes do anexo nº-2 da Lei nº 4320/64, com os seguintes desdobramentos:
{ #art-2 }

| Discriminação | Desdobramento (CR$) | Total (CR$) |
|---|---:|---:|
| **01 - RECEITAS CORRENTES** | | **154.000.000,00** |
| 13 - Receita Patrimonial | 15.020.000,00 | |
| 16 - Receita de Serviços | 2.385.000,00 | |
| 17 - Transferências Correntes | 136.595.000,00 | |
| **02 - RECEITAS DE CAPITAL** | | **26.000.000,00** |
| 24 - Transf. de Capital | 25.500.000,00 | |
| 25 - Outras Receitas de Capital | 500.000,00 | |
| **TOTAL DA RECEITA** | | **180.000.000,00** |

**Artigo 3º** - A despesa será realizada segundo discriminação dos Quadros Programa de Trabalho e Natureza da Despesa, que apresentam o seguinte desdobramento:
{ #art-3 }

#### 1 - POR FUNÇÃO DE GOVERNO { .centro }

| Função | Valor (CR$) |
|---|---:|
| 13 - Saúde e Saneamento | 180.000.000,00 |
| **TOTAL DA DESPESA POR FUNÇÃO** | **180.000.000,00** |

#### 2 - POR PROGRAMA { .centro }

| Programa | Valor (CR$) |
|---|---:|
| 75 - Saúde | 180.000.000,00 |
| **TOTAL DAS DESPESA POR PROGRAMA** | **180.000.000,00** |

#### 3 - POR CATEGORIAS ECONÔMICAS { .centro }

| Categoria | Valor (CR$) |
|---|---:|
| 01 - Despesas Correntes | 132.720.000,00 |
| 02 - Despesas de Capital | 47.280.000,00 |
| **TOTAL DA DESPESA POR CATEGORIA** | **180.000.000,00** |

#### 4 - POR ÓRGÃOS DA ADMINISTRAÇÃO { .centro }

| Órgão | Valor (CR$) |
|---|---:|
| 09 - Secretaria Municipal de Saúde — Fundo Municipal de Saúde | 180.000.000,00 |
| **TOTAL DA DESPESA POR ÓRGÃO** | **180.000.000,00** |

**Artigo 4º** - Fica o Poder Executivo autorizado a:
{ #art-4 }

I-realizar em qualquer mês do exercício, operações de crédito por antecipação da Receita, até o limite de 25% (vinte e cinco por cento), da Receita estimada, nos termos do artigo 52, inciso VII, da Constituição Federal;

II-abrir Créditos Suplementares, até o limite de 50% (cinquenta por cento), do presente Orçamento da Despesa, nos termos do artigo 7º, da Lei 4320/64;

III-incluir em seus programas de trabalho dotações necessárias para atender os encargos advindos de nova legislação federal.

**Artigo 5º** - Esta Lei entrará em vigor a partir de primeiro de janeiro de 1994, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS., aos oito dias do mês de dezembro do ano de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
