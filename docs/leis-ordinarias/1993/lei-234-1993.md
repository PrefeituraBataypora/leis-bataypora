**LEI Nº-234/93, De 02 de abril de 1993.**
{ .centro .revogado .tudo }

Dispõe sobre doação de imóveis, construção de casas populares, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a doar imóveis urbanos medindo até 200m², às famílias carentes, cujo chefe ou responsável deverá preencher os seguintes requisitos:
{ #art-1 .revogado }

a- Residir no Município há pelos menos um ano, a contar de 01.03.92; b- Não possuir imóvel ou casa residencial;
{ .revogado .tudo }

c- Ser eleitor no Município;
{ .revogado .tudo }

d- Ser casado(a) ou viver maritalmente com cônjuge;
{ .revogado .tudo }

e- Ser viúvo(a), desquitado(a) ou divorciado(a);
{ .revogado .tudo }

f- Ter renda familiar até 03 (três) salários mínimos.
{ .revogado .tudo }

Parágrafo único - Na dúvida do preenchimento do item "b", do caput desse artigo, o Executivo Municipal exigirá Certidão fornecida pelo Cartório competente, da cidade de origem.
{ .revogado .tudo }

**Art. 2º** - Procedida a doação do imóvel nos termos do artigo anterior, fica também o Executivo autorizado a construir às respectivas casas, fornecendo os materiais e mão-de-obra necessários, com execução dentro da Planta Padrão do Município.
{ #art-2 .revogado }

Parágrafo único - Na construção constante desse artigo poderá o proprietário(a) do imóvel contribuir com material e mão-de-obra, não cabendo-lhe qualquer indenização por parte da municipalidade.
{ .revogado .tudo }

imóveis doados pela municipalidade com casas iniciadas na gestão anterior, que se encontrarem em fase de conclusão.
{ .revogado .tudo }

**Art. 3º** - Poderáo Executivo Municipal concluir obras nos.
{ #art-3 .revogado }

Parágrafo único - A execução destas obras terá prioridade em relação às autorizadas pelo artigo segundo.
{ .revogado .tudo }

**Art. 4º** - A execução das construções de casas autorizadas pelo artigo 2º, será feita mediante um sorteio de 20 (vinte) casas mensais, e entregues aos mutuários, com prioridade para o sorteio aqueles que contribuírem com material e/ou mão-de-obra em fase de construção.
{ #art-4 .revogado }

**Art. 5º** - Os imóveis doados pela municipalidade só poderão ser transferidos ou negociados após 10 (dez) anos, a contar da assinatura do termo de doação.
{ #art-5 .revogado }

**Art. 6º** - Os beneficiados pelo artigo anterior, não poderão ceder, alugar, doar, vender ou negociar seu imóvel sem a prévia autorização do Executivo, referendada pelo Legislativo.
{ #art-6 .revogado }

Parágrafo único - No caso do proprietário do imóvel, ter seu requerimento referendado pelo Poder Legislativo nos termos dos artigos 59 e 6º, o mesmo recolherá aos cofres da municipalidade os valores gastos com materiais, bem como o valor do imóvel, corrigidos monetáriamente, conforme Cadastro Imobiliário existente no Setor de Tributação.
{ .revogado .tudo }

**Art. 7º** - Às doações efetuadas até apresente data, e que não preencherem os requisitos desta Lei, serão julgados pelo Executivo Municipal, mediante levantamento efetuado pelo Setor de Cadastro.
{ #art-7 .revogado }

Parágrafo único - O levantamento constante no caput desse artigo, após ser julgado pelo Executivo Municipal, será encaminhado à Câmara Municipal para o respectivo referendo.
{ .revogado .tudo }

**Art. 8º** - Às pessoas que forem contempladas com o imóvel doado pela Prefeitura Municipal, e que vier negociá-lo ou transferilo, antes do prazo fixado no artigo S da presente Lei, ficará vedada a sua inscrição para outra doação.
{ #art-8 .revogado }

**Art. 9º** - Os casos omissos na presente Lei, serão resolvidos através de uma Comissão Especial constituída pelo Executivo Municipal, composta de 05 (cinco) membros, sendo obrigatório a participação de no mínimo 03 (três) Vereadores.
{ #art-9 .revogado }

Parágrafo único - Às deliberações previstas no caput desse artigo, serão encaminhadas ao Executivo Municipal para homologação.
{ .revogado .tudo }

**Art. 10** - O Poder Executivo Municipal regulamentará a presente Lei, dentro de 10 (dez) dias, a contar da promulgação da presente Lei.
{ #art-10 .revogado }

**Art. 11** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-11 .revogado }

**Art. 12** - Revogam-se as disposições em contrário.
{ #art-12 .revogado }

Prefeitura Municipal de Batayporã-MS, aos dois dias do mês de abril de 1993.
{ .revogado .tudo }

Registrado em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.
