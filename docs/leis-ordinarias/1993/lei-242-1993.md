**LEI Nº-242/93, De 05 de maio de 1993.**
{ .centro }

Dispõe sobre concessão de abono salarial aos Servidores Públicos Municipais, e dá outras providências.

JOÃO JAMIL. MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a conceder um abono de 25% (vinte e cinco por cento), sobre os vencimentos de abril do corrente ano, a todos os Servidores Públicos Municipais, exceto os que prestam serviços como Profissionais Autônomos e Liberais.
{ #art-1 }

Parágrafo único - O abono concedido pelo presente artigo, corresponde aos salários de abril próximo passado, que será pago até o dia 17 do corrente mês.

**Art. 2º** - Não havendo alteração no salário mínimo no presente Exercício, poderá a critério do Prefeito ser concedido abonos de até 100% (cem por cento) da inflação ocorrida no mês anterior, obedecendo às disponibilidades financeiras da municipalidade.
{ #art-2 }

Parágrafo único - A inflação que se refere este artigo, é a verificada pelo órgão Responsável do Governo Federal.

**Art. 3º** - Havendo concessão de abono, nos termos do Artigo 2º, o Poder Executivo encaminhará cópia do Decreto ao Legislativo.
{ #art-3 }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor, suplementadas se necessário.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos cinco dias do mês de maio de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
