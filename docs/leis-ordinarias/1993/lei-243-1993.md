**LEI Nº-243/93, De 05 de maio de 1993.**
{ .centro }

Dispõe sobre concessão de abono salarial aos Servidores da Câmara Municipal, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um abono de 25% (vinte e cinco) por cento, sôbre os vencimentos de abril do corrente ano, a todos os Servidores da Câmara Municipal-MS.
{ #art-1 }

Parágrafo único - O abono concedido pelo presente artigo, corresponde aos salários de abril próximo passado, e será pago até o dia 17 do corrente mês.

**Art. 2º** - Não havendo alteração no salário mínimo no presente Exercício, poderá a Mesa Diretora conceder abonos de até 100% (cem por cento) da inflação ocorrida no mês anterior, através de Resolução.
{ #art-2 }

Parágrafo único - A inflação que se refere este artigo, é a verificada pelo órgão Responsável do Governo Federal.

**Art. 3º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos cinco dias do mês de maio de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
