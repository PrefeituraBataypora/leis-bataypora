**LEI Nº-268/93, De 14 de dezembro de 1993.**
{ .centro }

Denomina o Recinto da Festa do Peão, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica denominado o Recinto da Festa do Peão de Batayporã-MS..,de "RECINTO DA FESTA DO PEÃO DIEGO SANCHES MARCHI".
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria, constante no Orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos catorze dias do mês de dezembro de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
