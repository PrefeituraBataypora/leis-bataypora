**LEI Nº-246/93, De 09 de junho de 1993.**
{ .centro }

Dispõe sobre prorrogação de prazo e liberação de imóvel doado pela municipalidade, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica prorrogado o prazo constante da [Lei nº-116/89](../1989/lei-116-1989.md), de 28.07.89, de 12 (doze) meses, com 06 (seis) de carência, a partir do recebimento do imóvel, para 31.12.93, ao FRIPORA-Frigorífico Batayporã Ltda, CGC.-33.733.395/0001-90.
{ #art-1 }

**Art. 2º** - Fica o Friporã-frigorífico Batayporã Ltda autorizado a hipotecar o terreno doado pelo Decreto n2-25/90, de 02.05.90, nos termos das Leis nº-116/89 e 125/90, junto ao Banco do Brasil S/A, Agência de Batayporã, para financiamento de Projeto de suas instalações.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos sete dias do mês de junho de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
