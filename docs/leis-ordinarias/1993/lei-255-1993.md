**LEI Nº-255/93, De 15 de setembro de 1993.**
{ .centro .revogado .tudo }

Dispõe sobre Subvenção Social, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica o Poder Executivo autorizado a conceder Subvenção Social no valor de 03 (três) salários mínimos, mensal, à APAEAssociação de Pais e Amigos dos Excepcionais de Nova Andradina.
{ #art-1 .revogado }

**Art. 2º** - A Associação beneficiada constante do artigo 1º, fica obrigada a prestar contas de conformidade com às normas do Tribunal de Contas Estadual, à Contabilidade Municipal.
{ #art-2 .revogado }

**Art. 3º** - A contribuição concedida pelo artigo 1º, será paga de 1. a 15 do mês subsequente ao seu vencimento.
{ #art-3 .revogado }

**Art. 4º** - As despesas decorrentes da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-4 .revogado }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 01.07.93.
{ #art-5 .revogado }

**Art. 6º** - Fica revogada a Lei n.-235/93, de 02.04.93, e disposições em contrário.
{ #art-6 .revogado }

Prefeitura Municipal de Batayporã-MS, aos quinze dias do mês de setembro de 1993.
{ .revogado .tudo }

Dr. JOÃO JAMIL MELLA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
