**LEI Nº-232/93, De 08 de janeiro de 1993.**
{ .centro }

Dispõe sobre concessão de reajuste salarial, e dá outras providências.

JOÃO JAMIL. MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Art. 1º** - Fica concedido um reajuste salarial aos Servidores da Câmara Municipal, sobre seus vencimentos de 25% (vinte e cinco por cento).
{ #art-1 }

**Art. 2º** - Havendo aumento do salário mínimo vigente nesta data, fica a Mesa Diretora autorizada a conceder reajustes ou reposições salariais até o limite verificado no aumento concedido pela Legislação Federal.
{ #art-2 }

**Art. 3º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 01.01.93.
{ #art-4 }

**Artigo 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos oito dias do mês de janeiro de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
