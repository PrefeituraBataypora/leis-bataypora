**LEI Nº-252/93, De 20 de julho de 1993.**
{ .centro }

Dispõe sobre abertura de créditos suplementares no Orçamento do Município, para o exercício financeiro de 1993, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido o limite constante do [artigo 4º, item II da Lei nº-230/92](../1992/lei-230-1992.md#art-4), de 17.12.92, fica o Poder Executivo autorizado a suplementar mais 25% (vinte e cinco por cento) da despesa orçada.
{ #art-1 }

Parágrafo único - São recursos para abertura de créditos suplementares constantes deste artigo, os previstos na Lei n2-4.320/64.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos vinte dias do mês de julho de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
