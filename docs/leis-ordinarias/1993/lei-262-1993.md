**LEI Nº-262/93, De 01 de dezembro de 1993.**
{ .centro }

Dispõe sobre concessão de abono salarial aos Servidores Públicos Municipais, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Artigo 1º** - Fica o Poder Executivo autorizado a conceder abono a todos os Servidores Públicos Municipais Mensalistas, para o mês de dezembro do corrente ano; segundo às seguintes faixas salariais:
{ #art-1 }

I-De CR$-20.000,00 (vinte mil cruzeiros reais),, para os que recebem salários até 02 (dois) mínimos do Município;

II-De CR$-40.000,00 (quarenta mil cruzeiros reais), para os que recebem salários de 02 (dois) a 04 (quatro) mínimos do Município;

III-De CR$-80.000,00 (oitenta mil cruzeiros reais),. para os que recebem salários acima de 04 (quatro) mínimos do Município.

Parágrafo único - O abono concedido pelo presente artigo, será pago até o dia 23 de dezembro do corrente ano.

**Artigo 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Artigo 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Artigo 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, ao primeiro dia do mês de dezembro de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Depto Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
