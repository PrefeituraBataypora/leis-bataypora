**LEI Nº-257/93, De 23 de setembro de 1993.**
{ .centro .revogado .tudo }

REORGANIZA A ESTRUTURA ADMINISTRATIVA DA PREFEITURA MUNICIPAL DE BATAYPORÃ, E DÁ OUTRAS PROVIDÊNCIAS.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

## TÍTULO I — DO SISTEMA ADMINISTRATIVO DA PREFEITURA { .centro .revogado }

**Artigo 1º** - A Prefeitura Municipal de Batayporã-MS, para a execução das obras e serviços de responsabilidade do Município, fica reorganizada nos termos da presente Lei, com os seguintes órgãos diretamente ligados ao Prefeito Municipal:
{ #art-1 .revogado }

I - ÓRGÃOS DE ASSISTÊNCIA DIRETA E IMEDIATA AO PREFEITO
{ .revogado .tudo }

1 - Gabinete do Prefeito; 2 - Secretaria de Administração; 3 - Procuradoria e Assessoria Jurídica; 4 - Coordenadoria de Promoção e Assistência Social.
{ .revogado .tudo }

II - ÓRGÃOS CENTRAIS DE DIREÇÃO SUPERIOR
{ .revogado .tudo }

1 - Secretaria Municipal de Serviços Urbanos; 2 - Secretaria Municipal de Educação e Cultura; 3 - Secretaria Municipal de Saúde; 4 - Secretaria Municipal de Fazenda; 5 - Secretaria Municipal de Obras Públicas; 6 - Secretaria Municipal de Agricultura e Pecuária.
{ .revogado .tudo }

III - ÓRGÃOS VINCULADOS
{ .revogado .tudo }

1 - Junta de Serviço Militar; 2 - UMC (Unidade Municipal de Cadastro do ITR); 3 - Preposto de Expedição de Carteira de Trabalho.
{ .revogado .tudo }

**Artigo 2º** - Os órgãos componentes da Estrutura Administrativa da Prefeitura, obedecerão a seguinte subordinação hierárquica:
{ #art-2 .revogado }

a - Secretaria ou Coordenadoria; b - Departamento; c - Setor.
{ .revogado .tudo }

## TÍTULO II — DETALHAMENTO DA ESTRUTURA BÁSICA { .centro .revogado }

### CAPÍTULO I { .centro .revogado }

**Artigo 3º** - Subordinam-se direta e imediatamente ao Prefeito Municipal:
{ #art-3 .revogado }

{ .revogado .tudo }

II - A Secretaria de Administração: 1 - Departamento Pessoal (1.1. - Setor de: a - Preparo e pagamento de Pessoal; b - Recrutamento e Seleção; c - Cadastro e Locação); 2 - Departamento de Almoxarifado (2.2. - Setor de: a - Material; b - Licitação); 3 - Departamento de Planejamento e Informática.
{ .revogado .tudo }

III - A Procuradoria e Assessoria Jurídica.

IV - A Coordenadoria de Promoção e Assistência Social: 1 - Departamento Social; 2 - Departamento de Programas Sociais (2.2. - Setor de: a - Asilo; b - Creche; c - Associações Comunitárias).
{ .revogado .tudo }

## TÍTULO III — COMPETÊNCIA DOS ÓRGÃOS { .centro .revogado }

### CAPÍTULO I — DOS ÓRGÃOS DE ASSISTÊNCIA DIRETA E IMEDIATA AO PREFEITO { .centro .revogado }

**Artigo 10** - O Gabinete do Prefeito é o órgão de assistência do Prefeito para as funções administrativas, registro dos atos oficiais, e funções políticas, atendimento de munícipes e de ligação com os demais poderes e autoridades, assim como de relações públicas, incluindo as de representação e divulgação, bem como pela supervisão da guarda municipal.
{ #art-10 .revogado }

**Artigo 11** - A Secretaria de Administração é o órgão encarregado de exercer as atividades de administração geral do Município.
{ #art-11 .revogado }

**Artigo 12** - A Procuradoria e Assessoria Jurídica são os órgãos de consultoria nos assuntos jurídicos da Prefeitura, competindo-lhes pronunciar-se sobre toda matéria legal que lhes forem submetidas pelo Prefeito e demais órgãos do Executivo Municipal, bem como efetuar a cobrança judicial da Dívida Ativa e defender o Município em juízo, atuando ainda como órgãos de assessoramento na elaboração de Projetos de Lei, Decretos, Minuta de Contratos e outras matérias de natureza jurídica.
{ #art-12 .revogado }

**Artigo 13** - A Coordenadoria de Promoção e Assistência Social é o órgão responsável pelas atividades de assistência social à população local, bem como da promoção do Bem Estar social da comunidade, prestando ajuda aos necessitados e orientando os desajustados, visando assim a recuperação e melhoria das condições de vida desses indivíduos e grupos sociais.
{ #art-13 .revogado }

### CAPÍTULO II — DOS ÓRGÃOS CENTRAIS DE DIREÇÃO SUPERIOR { .centro .revogado }

**Artigo 14** - A Secretaria Municipal de Serviços Urbanos é o órgão encarregado de exercer as atividades ligadas à administração urbana do Município, no que se refere a Transporte e Serviços em Geral.
{ #art-14 .revogado }

**Artigo 15** - A Secretaria Municipal de Educação e Cultura é o órgão responsável pelas atividades educacionais exercidas pelo Município, referente ao Ensino Fundamental e no Pré-Escolar, manutenção de bibliotecas e correlatos de cultura e recreação.
{ #art-15 .revogado }

**Artigo 16** - A Secretaria Municipal de Saúde é o órgão responsável pela integração com a União e o Estado, do sistema de saúde no Município, no atendimento integral, com prioridade para as atividades preventivas, sem prejuízo dos serviços assistenciais, com a participação da comunidade, através dos Postos de Saúde e Hospitais.
{ #art-16 .revogado }

**Artigo 17** - A Secretaria Municipal de Fazenda é o órgão encarregado da execução da política financeira e fiscal do Município, bem como das atividades relativas a lançamento de tributos e arrecadação de rendas municipais; fiscalização dos Contribuintes; recebimento, guarda e movimentação de valores; da despesa, contabilidade e escrituração do patrimônio; elaboração, controle e a execução do orçamento, com a colaboração do Setor de Planejamento e Assessoria Jurídica.
{ #art-17 .revogado }

**Artigo 18** - A Secretaria Municipal de Obras Públicas é o órgão responsável pela execução, orientação e controle das obras municipais; construção e conservação de estradas e caminhos municipais; abertura, pavimentação e conservação de vias e logradouros públicos, bem como outros serviços e obras pertinentes ao sistema viário do Município.
{ #art-18 .revogado }

**Artigo 19** - A Secretaria Municipal de Agricultura e Pecuária é o órgão responsável pela execução das atividades de produção de alimentos, tanto para consumo comunitário como de expansão agrícola, através de programas de conservação de solo e os recursos naturais, bem como a inspeção no Município e ainda a Melhoria de Plantel em geral dos programas ligados à pecuária.
{ #art-19 .revogado }

### CAPÍTULO III — DOS ÓRGÃOS VINCULADOS { .centro .revogado }

**Artigo 20** - Aos órgãos vinculados cabem:
{ #art-20 .revogado }

I-A Junta de Serviço Militar as atribuições que lhes são pertinentes.
{ .revogado .tudo }

II-A UMC-Unidade Municipal de Cadastro do Imposto Territorial Rural (ITR) as atribuições que lhes são específicas.
{ .revogado .tudo }

III-Ao Preposto de Expedição de Carteira de Trabalho as atribuições que lhes são pertinentes.
{ .revogado .tudo }

## TÍTULO IV — DAS DISPOSIÇÕES TRANSITÓRIAS { .centro .revogado }

**Artigo 21** - O Prefeito Municipal deverá regulamentar a presente Lei no prazo de 90 (noventa) dias, aprovando, por decreto o Regulamento Interno da Prefeitura, que discriminará detalhadamente a estrutura administrativa e técnica dos órgãos constantes do artigo 19, suas atribuições e das respectivas subunidades administrativas.
{ #art-21 .revogado }

**Artigo 22** - Na regulamentação da presente Lei dever-se-á observar as normas Constitucionais e obedecer a Lei Orgânica do Município.
{ #art-22 .revogado }

**Artigo 23** - Na medida em que forem instalando os órgãos que compõem a estrutura administrativa da Prefeitura Municipal, prevista nesta Lei, serão extintos automaticamente os atuais órgãos, ficando o Prefeito Municipal autorizado a promover as necessárias transferências de pessoal, verbas, atribuições e instalações.
{ #art-23 .revogado }

**Artigo 24** - As despesas decorrentes da execução desta Lei, serão atendidas por conta das dotações próprias, consignadas no Orçamento Municipal do exercício de 1994.
{ #art-24 .revogado }

**Artigo 25** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário, e em especial a [Lei nº-148/90](../1990/lei-148-1990.md), de 08.11.90.
{ #art-25 .revogado }

Prefeitura Municipal de Batayporã-MS, aos vinte e três dias do mês de setembro de 1993.
