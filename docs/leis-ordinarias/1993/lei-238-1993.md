**LEI Nº-238/93, De 14 de abril de 1993.**
{ .centro }

Dispõe sobre aquisição de imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir um imóvel urbano ou rural até 48.700m² (quarenta e oito mil e setecentos metros quadrados).
{ #art-1 }

Parágrafo único - A aquisição constante deste artigo será precedida de avaliação prévia, por uma Comissão Especial nomeada para os fins específicos, composta de cinco Membros.

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos quatorze dias do mês de abril de 1.993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
