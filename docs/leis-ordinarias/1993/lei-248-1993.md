**LEI Nº-248/93, De 25 de junho de 1993.**
{ .centro .revogado .tudo }

Institui o CONSELHO MUNICIPAL DE SAÚDE, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte lei:
{ .revogado .tudo }

## CAPÍTULO I — Dos Objetivos { .centro .revogado }

**Art. 1º** - Fica instituído o Conselho Municipal de Saúde, em caráter permanente, órgão colegiado, deliberativo do Sistema único de Saúde - SUS, no âmbito Municipal.
{ #art-1 .revogado }

**Art. 2º** - Sem prejuízo das funções do Poder Legislativo, são competências do C.M.S.:
{ #art-2 .revogado }

I - Definir as prioridades de saúde;
{ .revogado .tudo }

II - Estabelecer as diretrizes a serem observadas na elaboração do Plano Municipal de Saúde;
{ .revogado .tudo }

III - Atuar na formulação das estratégias e no controle da execução da política de saúde;
{ .revogado .tudo }

IV - Propor critérios para a programação, execuções financeiras e orçamentárias do Fundo Municipal de Saúde, acompanhando a administração e o destino dos recursos;
{ .revogado .tudo }

V - Acompanhar, avaliar e fiscalizar os serviços prestados à população pelos órgãos e entidades públicas e privadas, integrantes do SUS - Sistema único de Saúde no Município;
{ .revogado .tudo }

VI - Definir critérios de qualidade para o funcionamento dos serviços de saúde pública e privada no âmbito do SUS;
{ .revogado .tudo }

VII - Definir critérios para elaboração de contratos ou convênios entre o setor público e as entidades privadas de saúde, no que tange à prestação de serviços de saúde;
{ .revogado .tudo }

VIII - Apreciar previamente os contratos e convênios referidos no inciso anterior;
{ .revogado .tudo }

IX - Estabelecer diretrizes quanto à localização e o tipo de unidades prestadoras de serviços de saúde, públicos e privados, no âmbito do SUS;
{ .revogado .tudo }

X - Elaborar seu regimento interno;
{ .revogado .tudo }

XI - Outras atribuições estabelecidas em normas complementares.
{ .revogado .tudo }

## CAPÍTULO II — Da Estrutura e do Funcionamento { .centro .revogado }

### SEÇÃO I — Da Composição { .centro .revogado }

**Art. 3º** - O C.M.S. terá a seguinte composição:
{ #art-3 .revogado }

I - REPRESENTANTES DO GOVERNO
{ .revogado .tudo }

A - Um representante da Secretaria Municipal de Saúde;
{ .revogado .tudo }

B - Um representante do Departamento Municipal de Administração;
{ .revogado .tudo }

C - Um representante do Departamento Municipal de Educação e Cultura, e Promoção Social;
{ .revogado .tudo }

D - Um representante da Fundação Nacional de Saúde do Município;
{ .revogado .tudo }

E - Um representante do Hospital conveniado - SUS - Sistema Único de Saúde (Hospital São Lucas);
{ .revogado .tudo }

F - Um representante do Centro de Saúde.
{ .revogado .tudo }

§1º - A cada titular do C.M.S., corresponderá um suplente.
{ .revogado .tudo }

§2º - O número de representantes de que trata o inciso I do presente artigo, não será inferior a 50% (cinquenta por cento), dos membros do C.M.S..
{ .revogado .tudo }

§3º - Dos representantes dos usuários, serão escolhidos pelas suas comunidades e/ou representantes de Associações de Moradores, 03 (três) representantes que deverá ser lavrado em ata e encaminhado ao Prefeito Municipal que nomeará um de cada unidade.
{ .revogado .tudo }

!!! info "Redação dada pela Lei nº 322/1995"
    Nova redação deste artigo e dos §§ 1º, 2º e 3º, dada pelo [art. 1º da Lei nº 322/1995](../1995/lei-322-1995.md#art-1). Antes, a [Lei nº 314/1995](../1995/lei-314-1995.md) já tinha alterado o artigo; ela foi revogada pela Lei nº 322/1995.

    Art. 3º - O Conselho Municipal de Saúde terá a seguinte composição:

    I-REPRESENTANTES DO GOVERNO MUNICIPAL:

    a. um representante da Secretaria de Administração;

    b. um representante da Secretaria Municipal de Educação e Cultura;

    c. um representante da Coordenadoria de Promoção e Assistência Social.

    II-DOS PRESTADORES DE SERVIÇO:

    a. um representante da Sociedade Hospitalar São Lucas;

    b. um representante do Centro de Saúde.

    III-DOS TRABALHADORES DO SUS

    a. um representante da F.N.S.

    IV-DOS USUÁRIOS

    a. um representante do Centro Rural do Bairro da Festa;

    b. um representante da Associação de Desenvolvimento Comunitário de Batayporã;

    c. um representante dos Trabalhadores Rurais de Batayporã;

    d. um representante da Associação Batayporãense de Ecologia e Cultura;

    e. um representante da Associação dos Produtores de Leite de Batayporã-Pró-Leite;

    f. um representante da Associação de Moradores da Fazenda Primavera.

    §1º - A cada titular do C.M.S., corresponderá um suplente.

    §2º - O número de representantes de que trata o inciso IV, do presente artigo, não será inferior a 50% (cinquenta por cento), dos membros do C.M.S.

    §3º - Dos representantes dos usuários, serão escolhidos pelas suas comunidades/e ou representantes de Associações de Moradores, que deverá ser lavrado em Ata e encaminhado ao Prefeito Municipal, que nomeará um de cada unidade.

**Art. 4º** - Os membros efetivos e suplentes do C.M.S., serão nomeados pelo Prefeito Municipal, mediante indicação:
{ #art-4 .revogado }

I - Das respectivas entidades:
{ .revogado .tudo }

§1º - Os representantes do Governo Municipal serão de livre escolha do Prefeito;
{ .revogado .tudo }

§2º - O Secretário Municipal de Saúde é membro nato do C.M.S..
{ .revogado .tudo }

§3º - Na ausência ou impedimento do Secretário Municipal de Saúde, a presidência do C.M.S., será assumida pelo seu suplente.
{ .revogado .tudo }

**Art. 5º** - O C.M.S., reger-se-á pelas seguintes disposições no que se refere a seus membros:
{ #art-5 .revogado }

I - O exercício da função de conselheiro não será remunerado, considerando-se como serviço público relevante;
{ .revogado .tudo }

II - Os membros do C.M.S., serão substituídos caso faltem, sem motivo justificado, a 03 (três) reuniões consecutivas ou 06 (seis) reuniões intercaladas no período de 12 meses.
{ .revogado .tudo }

### SEÇÃO II — Do Funcionamento { .centro .revogado }

**Art. 6º** - O C.M.S., terá seu funcionamento regido pelas seguintes normas:
{ #art-6 .revogado }

I - O órgão de deliberação máxima é o plenário;
{ .revogado .tudo }

II - As sessões plenárias serão realizadas ordinariamente a cada mês e extraordinariamente quando convocadas pelo presidente ou por requerimento da maioria dos seus membros;
{ .revogado .tudo }

III - Para a realização das reuniões será necessário a presença da maioria absoluta dos membros do C.M.S., que deliberará pela maioria dos votos dos presentes;
{ .revogado .tudo }

IV - Cada membro do C. M. S., terá direito a um único voto na Sessão Plenária;
{ .revogado .tudo }

V - As decisões do C.M.S., serão consubstanciadas em resoluções.
{ .revogado .tudo }

**Art. 7º** - Para melhor desempenho de suas funções, o C.M.S. poderá recorrer as pessoas e entidades, mediante os seguintes critérios:
{ #art-7 .revogado }

I - Consideram-se colaboradores do C.M.S., as instituições de recursos humanos para a saúde e as entidades representativas de profissionais e usuários;
{ .revogado .tudo }

II - Poderão ser convidadas pessoas ou instituições de notória especialização para acessorar o C.M.S., em assuntos específicos;
{ .revogado .tudo }

III - Poderão ser criadas comissões internas, constituídas por entidades - membros do C.M.S., e outras instituições, para promover estudos e emitir pareceres a respeito de temas específicos.
{ .revogado .tudo }

**Art. 8º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-8 .revogado }

**Art. 9º** - Revogam-se as disposições em contrário e a [Lei nº 159/91](../1991/lei-159-1991.md), de 19 de junho de 1991.
{ #art-9 .revogado }

Prefeitura Municipal de Batayporã-MS., aos vinte e cinco dias do mês de junho de 1993.
{ .revogado .tudo }

Dr. JOÃO JAMIL MELLA
{ .centro .revogado .tudo }

Prefeito Municipal
