**LEI Nº-261/93, De 24 de novembro de 1993.**
{ .centro .revogado .tudo }

Dispõe sobre Isenção de Tributos Municipais incidentes sobre atividades exercidas agências bancárias, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica concedido isenção de tributos municipais incidentes sobre atividades exercidas por agências bancárias estabelecidas no Município de Batayporã, bem como os tributos incidentes sobre seu imóvel objeto de propriedade da referida Agência.
{ #art-1 .revogado }

**Art. 2º** - A isenção constante do artigo anterior será concedida pelo prazo de 10 (dez) anos, a contar da vigência desta Lei.
{ #art-2 .revogado }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, nos termos do artigo 2º, da Lei Complementar nº-01/91, de 11.12.91, revogadas as disposições em contrário.
{ #art-3 .revogado }

Prefeitura Municipal de Batayporã-MS, aos vinte e quatro dias do mês de novembro de 1993.
{ .revogado .tudo }

Dr. JOÃO JAMIL MELLA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
