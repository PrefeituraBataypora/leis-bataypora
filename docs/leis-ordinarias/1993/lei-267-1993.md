**LEI Nº-267/93, De 08 de dezembro de 1993.**
{ .centro }

Dispõe sobre doação de um Padrão completo trifásico, com transformador de 75 KVA, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a doar o padrão completo trifásico, com transformador de 75kvA, ao BATAYPORÃ TENIS CLUBE, CGC-15.487.804/0001-34, para instalação em sua Sede Social.
{ #art-1 }

Parágrafo único - O transformador constante deste artigo será doado dentre os usados, de propriedade do Município, sem função definida até apresente data.

**Art. 2º** - O valor da presente doação seráo constante no Patrimônio Municipal.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos oito dias do mês de dezembro de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
