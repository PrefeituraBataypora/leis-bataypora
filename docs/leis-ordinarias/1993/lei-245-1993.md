**LEI Nº-245/93, De 09 de junho de 1993.**
{ .centro }

Dispõe sobre aquisição e doação de imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir e doar imóveis aos interessados abaixo descritos:
{ #art-1 }

a- a EDSON APARECIDO KRINGER, de até 840m² (oitocentos e quarenta metros quadrados), para a instalação de uma indústria de extratos de cama;

b- a OSCAR NEPUMOCENO, de até 1.600m² (hum mil e seiscentos metros quadrados), para instalação de uma Empresa com o ramo de mecânica pesada e leve, à diesel, torno e solda, etc.

c- a GPMB-Representação e Consultoria Ltda, de até 80.000m² (oitenta mil metros quadrados), para implantação de uma INDÚSTRIA DE BENEFICIAMENTO DE COURO "CURTUME".

Parágrafo único - As aquisições constantes deste artigo serão precedidas de avaliação prévia, por uma Comissão Especial nomeada para os fins específicos, composta de até 05 (cinco) membros.

**Art. 2º** - Os imóveis constantes do artigo anterior poderão ser doados dentre os já de propriedade da municipalidade.
{ #art-2 }

**Art. 3º** - Os empresários beneficiados serão obrigados a instalarem e funcionarem as respectivas empresas.
{ #art-3 }

**Art. 4º** - Os interessados receberão os imóveis constantes do artigo primeiro, após a apresentação de uma petição, em que conste a descrição dos objetivos propostos, e detalhe todos os bens a serem incorporados no imóvel objeto da doação, bem como apresentação do Projeto de contrução da Obra.
{ #art-4 }

Parágrafo único - Os objetivos e detalhamentos constantes deste artigo, são os propostos nas Cartas e ou Requerimentos de Intenção.

**Art. 5º** - O prazo para construção e funcionamento de suas atividades previstos no artigo anterior, é de 12 (doze) meses, com 03 (três) de carência, a partir da doação do imóvel.
{ #art-5 }

**Art. 6º** - Não cumpridas as exigências constantes da presente Lei, o imóvel doado retornará ao domínio do Município.
{ #art-6 }

**Art. 7º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-7 }

**Art. 8º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-8 }

Prefeitura Municipal de Batayporã-MS, aos nove dias do mês de junho de 1993.

Dr. JOÃO JAMIL MELLA
