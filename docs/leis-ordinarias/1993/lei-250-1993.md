**LEI Nº-250/93, De 25 de junho de 1993.**
{ .centro }

Dispõe sobre nova redação do art. 1º da Lei nº-161/91, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - O [art. 1º da Lei nº-161/91](../1991/lei-161-1991.md#art-1), de 26 de junho de 1991, passa ter a seguinte redação:
{ #art-1 }

> “Art. 1º - Fica isento de pagamento de ingressos para adentrar no Estádio Municipal Mohamed Mustafá e no Ginásio Poli-Esportivo ERNESTO MAGNI FRUGULI, todas as pessoas idosas com idade acima de 60 (sessenta) anos.”

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos vinte e cinco dias do mês de junho de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
