**LEI Nº-244/93, De 12 de maio de 1993.**
{ .centro }

Dispõe sobre perfuração e doação de Poço Artesiano, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a perfurar e doar um Poço Artesiano para o Friporã-frigorífico Batayporã Ltda.
{ #art-1 }

Parágrafo único - O Poço constante deste artigo será perfu rado no imóvel de propriedade do beneficiário, para fornecimento de água à sua Indústria.

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos doze dias do mês de maio de 1993.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
