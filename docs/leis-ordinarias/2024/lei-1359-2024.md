**Lei nº. 1.359, de 30 de março de 2024.**
{ .centro .revogado .tudo }

“Altera dispositivos na Lei Complementar 102/88, e dá outras providências”.
{ .revogado .tudo }

O Exmo. Sr. Vice-Presidente, da Câmara Municipal de Batayporã, Estado de Mato Grosso do Sul, Sr. Vanderley Rodrigues Pedroso, no uso e gozo de suas atribuições legais, que lhe conferem a Lei Orgânica Municipal:
{ .revogado .tudo }

Considerando a ausência de sanção ou promulgação pelo Chefe do Executivo e do Presidente da Câmara Municipal, observando que a promulgação de Leis é um ato obrigatório sem margens para discricionariedade, nos termos do artigo 30 §7º da Lei Orgânica Municipal;
{ .revogado .tudo }

Faz saber que a CÂMARA MUNICIPAL aprovou o Projeto de Lei nº 015/2023, de autoria e iniciativa do vereador João Paulo da Silva Souza, sendo que o Sr. Vice-Presidente, Vanderley Rodrigues Pedroso, PROMULGA a seguinte Lei, passando a receber o nº 1.359 de 30 de abril de 2024:
{ .revogado .tudo }

**Art. 1º** Altera-se a alínea “a” do artigo 47 da Lei Complementar nº102/88, passando a vigorar com a seguinte redação:
{ #art-1 .revogado }

**Art. 47.** Os afastamentos mínimos previstos serão:
{ #art-47 .revogado }

a) Afastamento frontal: 3,00m (três metros); com possibilidade de edificação de varanda a partir de 1,50 (um metro e cinquenta centímetros) quando se tratar de edificação residencial.
{ .revogado .tudo }

**Art. 2º** As regulamentações necessárias para o fiel cumprimento desta lei, poderão ser efetuadas por meio de Decreto do Poder Executivo Municipal.
{ #art-2 .revogado }

**Art. 3º** As despesas decorrentes da aplicação da presente Lei correrão por conta de dotações próprias constantes no orçamento vigente do Legislativo Municipal.
{ #art-3 .revogado }

**Art. 4º** Esta Lei entrará em vigor na data de sua publicação, permanecendo inalteradas as demais disposições da [Lei nº. 1.169/2017](../2017/lei-1169-2017.md) de 28 de dezembro de 2017.
{ #art-4 .revogado }

Plenário das Deliberações “Erberto Flauzino de Oliveira”, em 30 de abril de 2024.
{ .revogado .tudo }
