**Lei nº. 1012/2013 de 28 de maio de 2013.**
{ .centro .revogado .tudo }

“Autoriza a permuta e cedência de pessoal que especifica, e dá outras providências”.
{ .revogado .tudo }

**ALBERTO LUIZ SÃOVESSO**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Fica o Poder Executivo Municipal autorizado a realizar a cedência dos Servidores Públicos Municipais, conforme demonstrado no quadro abaixo, para atendimento dos Programas destinados a população, em parceria com a **SOCIEDADE HOSPITALAR SÃO LUCAS** (Entidade Filantrópica, conforme Resolução do Conselho Nacional de Assistência Social nº. 156 de 29/09/97) , inscrita no CNPJ nº. 03.211.935/0001-05, com sede à Rua João Antonio da Silva, 400, município de Batayporã-MS, pelo período de até 31 de dezembro de 2016.
{ #art-1 .revogado }

I - 01 (um) médico ortopedista;
{ .revogado .tudo }

II - 01 (um) técnico em raios-X;
{ .revogado .tudo }

III - 03 (três) enfermeiros;
{ .revogado .tudo }

IV - 01 (um) auxiliar de operador de equipamentos de raios-X;
{ .revogado .tudo }

V - 01 (um) auxiliar de serviços gerais;
{ .revogado .tudo }

VI - 02 (dois) vigias.
{ .revogado .tudo }

Parágrafo único. A presente cedência fica condicionada a elaboração de Convênio especifico, onde serão mencionadas as obrigações da parceria.
{ .revogado .tudo }

**Art. 2º** Não havendo no Quadro de Pessoal, os servidores mencionados no artigo anterior, fica autorizada a contratação dos mesmos em caráter temporário, com ônus (vencimentos e vantagens) para a Secretaria Municipal de Saúde de Batayporã-MS, em conformidade com a legislação em vigor.
{ #art-2 .revogado }

**Art. 3º** Fica também o Poder Executivo Municipal, autorizado a realizar a permuta de Servidores Públicos Municipais do Quadro de Pessoal com os Servidores Públicos Estaduais, de conformidade com os instrumentos legais do Governo do Estado de Mato Grosso do Sul.
{ #art-3 .revogado }

**Art. 4º** As despesas decorrentes com a execução da presente Lei correrão à conta de dotações orçamentárias pertinentes a cada programa, de acordo com o orçamento municipal vigente.
{ #art-4 .revogado }

**Art. 5º** Esta lei entra em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-5 .revogado }

Prefeitura Municipal de Batayporã-MS., aos vinte e oito dias do mês de maio de 2013.
{ .revogado .tudo }

**Alberto Luiz Sãovesso**

Prefeito Municipal
