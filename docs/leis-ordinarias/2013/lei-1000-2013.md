**Lei nº 1000/2013 de 16 de janeiro de 2013.**
{ .centro .revogado .tudo }

“Dispõe sobre a reformulação da organização estrutural da Prefeitura Municipal de Batayporã-MS, e dá outras providências”.
{ .revogado .tudo }

Faço saber que a Câmara Municipal aprovou e eu, **ALBERTO LUIZ SÃOVESSO**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, sanciono a seguinte Lei:
{ .revogado .tudo }

## TÍTULO I — DA FINALIDADE { .centro .revogado }

**Art. 1º** Esta Lei organiza a estrutura administrativa da Prefeitura Municipal de Batayporã-MS, unidade territorial com autonomia política, administrativa e financeira, nos termos assegurados pela Constituição da República Federativa do Brasil, pela Constituição Estadual e pela Lei Orgânica, e Leis Municipais pertinentes, com a seguinte finalidade:
{ #art-1 .revogado }

I - a proteção do patrimônio histórico-cultural do Município, observada a legislação e a ação fiscalizadora federal e estadual;
{ .revogado .tudo }

II - o desenvolvimento de programas de construção de moradias e melhoria das condições habitacionais e de saneamento básico;
{ .revogado .tudo }

III - a promoção do adequado reordenamento territorial, mediante planejamento e controle do uso, do parcelamento e da ocupação do solo urbano;
{ .revogado .tudo }

IV - a organização e a prestação, direta ou sob regime de concessão de permissão dos serviços públicos de interesse local, incluído o essencial de transporte coletivo;
{ .revogado .tudo }

V - o planejamento de suas atividades, atendendo às peculiaridades locais e aos princípios técnicos convenientes ao desenvolvimento integral da comunidade;
{ .revogado .tudo }

VI - a coordenação e a supervisão do processo de planejamento e execução de programas, voltados para o atendimento aos direitos da criança e do adolescente;
{ .revogado .tudo }

VII - a promoção de ações de combate às causas de pobreza e de fatores de marginalização, promovendo a integração social da população menos favorecida;
{ .revogado .tudo }

VIII - a proteção do meio ambiente e combate à poluição em qualquer de suas formas, preservando a flora e a fauna e estimulando a recuperação do meio ambiente depredado;
{ .revogado .tudo }

IX - o desenvolvimento de ações de saúde e assistência social à população;
{ .revogado .tudo }

X - a proteção às pessoas portadoras de deficiências;
{ .revogado .tudo }

XI - o desenvolvimento de ações que assegurem o acesso à cultura e à educação pré-escolar e ensino fundamental.
{ .revogado .tudo }

XII - o desenvolvimento de ações objetivando os direitos sociais do idoso, criando condições para promover sua autonomia;
{ .revogado .tudo }

XIII - a proteção a mulher com a finalidade de promover, no âmbito municipal, toda mulher, independente de classe, raça, etnia, orientação sexual, cultura, nível educacional, idade e religião, goze dos direitos fundamentais inerentes à pessoa humana, sendo-lhes asseguradas oportunidades e facilidades para viver sem violência, preservando sua saúde física e mental e seu aperfeiçoamento moral, intelectual e social
{ .revogado .tudo }

XIV - atuação instrumental com o objetivo de viabilizar a infra estrutura e apoio técnico operacional que visem a instalação e o adequado funcionamento do Centro Integrado de Atendimento ao Trabalhador – CIAT no município de Batayporã-MS, em parceria com o Governo Estadual e Federal;
{ .revogado .tudo }

XV - implantação do Sistema de Controle Interno da Administração Pública com plataforma de sustentação no sistema de informação e comprometimento dos gestores, de acordo com os instrumentos constitucionais (Lei nº 4320/64, Lei Complementar nº 101/00 e Constituição Federal, instituído pela [Lei nº 941/2011](../2011/lei-941-2011.md), de 20 de dezembro de 2011
{ .revogado .tudo }

## TÍTULO III — DAS FINALIDADES DAS UNIDADES INTEGRANTES DA ESTRUTURA ORGANIZACIONAL { .centro .revogado }

### CAPÍTULO I — DOS ÓRGÃOS COLEGIADOS { .centro .revogado }

#### SEÇÃO ÚNICA — DOS CONSELHOS MUNICIPAIS { .centro .revogado }

**Art. 5º** Os Conselhos Municipais têm suas finalidades e composições definidas em seus atos de criação e seus funcionamentos regulados em regimentos próprios.
{ #art-5 .revogado }

### CAPÍTULO II — DOS ÓRGÃOS DE ASSESSORAMENTO { .centro .revogado }

#### SEÇÃO I — DO GABINETE DO PREFEITO { .centro .revogado }

**Art. 6º** A Secretaria de Governo - SEGOV, órgão de assessoramento direto ao Prefeito Municipal, tem por finalidade:
{ #art-6 .revogado }

I - o assessoramento ao Prefeito Municipal e Vice-Prefeito, em assuntos técnicos político e administrativos pertinentes à Administração Municipal;
{ .revogado .tudo }

II - a coordenação geral do desenvolvimento de ações técnico-administrativas pertinentes à Administração municipal;
{ .revogado .tudo }

III - a articulação técnica e política com a Câmara Municipal, objetivando assegurar a consecução das metas da Administração Municipal e o atendimento as necessidades da comunidade;
{ .revogado .tudo }

IV - a integração e articulação com os órgãos da Administração Pública e organismos representativos da comunidade, para garantir a efetividade do Plano de Governo;
{ .revogado .tudo }

V - o desempenho das atividades de comunicação institucional;
{ .revogado .tudo }

VI - a supervisão das atividades relacionadas à habitação, cultura, esporte, lazer e de planejamento urbano e de meio ambiente;
{ .revogado .tudo }

VII - a supervisão dos assuntos relacionados a Guarda Municipal;
{ .revogado .tudo }

VIII - a adequação das atividades de competência municipal, através do Departamento Municipal de Transporte e Trânsito-DMTT, criado pela [Lei nº 648/2005](../2005/lei-648-2005.md), com observância do art. nº 333, § 2º da Lei nº 9.503/97 (Código de Trânsito Brasileiro);
{ .revogado .tudo }

IX - a adequação das atividades de competência municipal, através do Sistema de Controle Interno na Administração Pública, de conformidade com o item XV do art. 1º desta Lei, passível de sua implantação;
{ .revogado .tudo }

X - o fomento ao comércio, indústria e turismo;
{ .revogado .tudo }

XI - o estabelecimento de diretrizes e normas relativas à regularização e assentamentos de favelas e à concessão de áreas em regime de comodato;
{ .revogado .tudo }

XII - o planejamento e a coordenação do processo de execução da Política Fundiária para a população de baixa renda do Município;
{ .revogado .tudo }

XIII - a Junta de Serviço Militar – JSM;
{ .revogado .tudo }

XIV - os serviços cerimoniais, os de imprensa incluindo a produção e distribuição de material jornalístico e o de relações públicas.
{ .revogado .tudo }

**Art. 7º** A Assessoria Jurídica é órgão de assessoramento no âmbito da Secretaria de Governo, com a incumbência de organizar os trabalhos da área em conjunto com os advogados do município, abrangendo:
{ #art-7 .revogado }

I - a representação do Município perante o contencioso administrativo;
{ .revogado .tudo }

II - o assessoramento ao Poder Executivo na interpretação, aplicação e controle das normas jurídicas;
{ .revogado .tudo }

III - o assessoramento ao Prefeito Municipal na elaboração do processo legislativo e o controle da legalidade dos atos administrativos;
{ .revogado .tudo }

IV - o controle das desapropriações;
{ .revogado .tudo }

V - o controle documental da legislação municipal;
{ .revogado .tudo }

VI - a representação judicial e extrajudicial do Município em qualquer foro ou juízo;
{ .revogado .tudo }

VII - a propositura de ação declaratória de nulidade ou de anulação de quaisquer atos, havidos como ilegais ou inconstitucionais;
{ .revogado .tudo }

VIII - o controle da apresentação dos Precatórios Judiciais, na forma do art. l00 da Constituição Federal;
{ .revogado .tudo }

IX - a execução fiscal.
{ .revogado .tudo }

X - para o exercício inerente às ações do presente artigo, poderá o Prefeito Municipal utilizar-se do corpo efetivo de advogados da municipalidade, e ainda se necessário, criar cargos comissionados e/ou contratar, obedecendo à legislação pertinente, profissionais para realizar as tarefas descritas.
{ .revogado .tudo }

XX - produzir, editar, publicar, materiais da temática ambiental, de forma gratuita e/ou onerosa, com recursos destinados ao Fundo Municipal de Meio Ambiente;
{ .revogado .tudo }

XXI - elaborar estudos e Políticas Públicas com o objetivo de recuperar áreas de degradadas;
{ .revogado .tudo }

XXII - propor, gerenciar, elaborar, planejar, executar e avaliar, planos, projetos, parcerias, firmar protocolos, convênios de cooperação técnica, cientifica e de capacitação, com órgãos estadual e/ou federal e entidades internacionais e nacionais, governamentais e não governamentais e de âmbito local, regional ou global;
{ .revogado .tudo }

XXIII - fiscalizar e controlar a produção, comercialização, distribuição e o emprego de substancias, técnicas, métodos, e/ou transporte que comportem físico ao meio ambiente e a vida, em consonância com os demais órgãos da administração municipal;
{ .revogado .tudo }

XXIV - fiscalizar, monitorar, controlar e criar indicadores, dos usos dos recursos naturais e das formas de degradação ambiental;
{ .revogado .tudo }

XXV - aplicar multas ambientais e destiná-las ao Fundo Municipal de Meio Ambiente;
{ .revogado .tudo }

XXVI - definir, elaborar, promover e fiscalizar a Política Municipal de Resíduos Sólidos e de limpeza urbana, bem como o controle técnico dos aterros existentes na Municipalidade;
{ .revogado .tudo }

XXVII - nos casos de compensação ambiental de qualquer natureza serão destinados ao Fundo Municipal de Meio Ambiente;
{ .revogado .tudo }

XXVIII - Instituir no município o Conselho Municipal de Turismo:
{ .revogado .tudo }

XXIX - gerenciar a implementação do Plano Diretor do Turismo;
{ .revogado .tudo }

XXX - fomentar atividades de eco-turismo, turismo cultural e turismo de negócios em consonância com as deliberações pertinentes;
{ .revogado .tudo }

XXXI - realizar diagnóstico bem como propor obras e serviços visando infra-estrutura e apoio à atividade turística, levando-se em conta o potencial do setor para o desenvolvimento econômico e social da Cidade;
{ .revogado .tudo }

XXXII - realizar exposições de artes para valorização dos artistas, bem como a difusão cultural na Cidade;
{ .revogado .tudo }

XXXIII - propor e gerenciar convênios com instituições públicas ou privadas consoante os objetivos que definem as políticas de turismo;
{ .revogado .tudo }

XXXIV - Instituir, normatizar e gerenciar as atividades da Feira de Artes e Artesanato, em consonância com os demais órgãos da administração municipal;
{ .revogado .tudo }

XXXV - a administração, controle e fiscalização dos serviços inerentes à parte que integra o meio ambiente na agricultura, com preocupação na erosão e na política do sistema florestal no meio ambiente;
{ .revogado .tudo }

XXXVI - a integração do município no SISNAMA – Sistema Nacional de Meio Ambiente;
{ .revogado .tudo }

XXXVII - Coordenar outras atividades destinadas à consecução de seus objetivos.

## TÍTULO IV — DA CARACTERIZAÇÃO E DO FUNCIONAMENTO DOS SISTEMAS { .centro .revogado }

### CAPÍTULO I — DA CARACTERIZAÇÃO { .centro .revogado }

**Art. 17.** As atividades de planejamento, administração financeira, administração geral e de recursos humanos serão desenvolvidas, de forma centralizada, através dos seguintes sistemas:
{ #art-17 .revogado }

I - Sistema de Administração Geral e de Recursos Humanos;
{ .revogado .tudo }

II - Sistema de Planejamento Financeiro;
{ .revogado .tudo }

### CAPÍTULO II — DO FUNCIONAMENTO { .centro .revogado }

#### SEÇÃO I — DO SISTEMA DE ADMINISTRAÇÃO GERAL E DE RECURSOS HUMANOS { .centro .revogado }

**Art. 18.** Através dos Grupos Administrativos, a Secretaria Municipal de Administração, Finanças e Planejamento — SMAFIP- coordenará, junto aos demais órgãos, os seguintes serviços-meio:
{ #art-18 .revogado }

I - aquisição, recebimento, guarda, distribuição, controle e alienação de materiais;
{ .revogado .tudo }

II - registro, carga, tombamento, controle, manutenção e conservação de bens patrimoniais, móveis, inclusive as obras de arte e objetos decorativos;
{ .revogado .tudo }

III - aquisição, guarda, manutenção e alienação de veículos leves:
{ .revogado .tudo }

IV - reprografia, arquivo de documentação e manutenção de biblioteca;
{ .revogado .tudo }

V - acompanhamento e controle de protocolo, de tramitação de expediente, de telefonia, de portaria, de vigilância, de copa e manutenção e conservação da limpeza predial;
{ .revogado .tudo }

VI - estabelecimento de critérios para recrutamento, seleção, admissão e cadastramento de recursos humanos, com vistas a atender a demanda dos órgãos que compõem a Prefeitura Municipal;
{ .revogado .tudo }

VII - estabelecimento de critérios para movimentação de pessoal entre os órgãos da Administração Municipal, com ciência da Secretaria de origem do servidor;
{ .revogado .tudo }

VIII - controle centralizado dos cargos em comissão e de funções gratificadas, bem como ampliação do quadro permanente;
{ .revogado .tudo }

IX - coordenação do processo de avaliação de desempenho dos servidores.
{ .revogado .tudo }

#### SEÇÃO II — DO SISTEMA DE PLANEJAMENTO FINANCEIRO { .centro .revogado }

**Art. 19.** A gestão dos recursos financeiros, orçamentários e extra-orçamentários processar-se-á sob a coordenação e orientação centralizada da Secretaria Municipal de Administração, Finanças e Planejamento — SMAFIP-.
{ #art-19 .revogado }

**Art. 20.** Cabe à Secretaria Municipal de Administração, Finanças e Planejamento — SMAFIP - assegurar o controle interno e externo da administração municipal na aplicação dos recursos financeiros a ela destinados, através de:
{ #art-20 .revogado }

I - elaboração do cronograma financeiro de desembolso para os programas e atividades da Administração Municipal;
{ .revogado .tudo }

II - programação e execução dos pagamentos devidos pela Administração Municipal;
{ .revogado .tudo }

III - auditagem nos atos financeiros;
{ .revogado .tudo }

IV - observação dos programas contidos na lei orçamentária;
{ .revogado .tudo }

V - observação das prescrições legais contidas nas legislações específicas aplicáveis aos municípios.
{ .revogado .tudo }

VI - a formulação de implantação de sistemas advindos de normas constitucionais legalmente estabelecidas com o apoio do quadro de servidores efetivos, comissionados e se necessário assessorias e consultorias.
{ .revogado .tudo }

## TÍTULO V — DO PROCESSO DECISÓRIO { .centro .revogado }

**Art. 21.** O processo decisório, no âmbito da Administração Municipal, observará os seguintes critérios:
{ #art-21 .revogado }

I - controle de resultados;
{ .revogado .tudo }

II - coordenação funcional;
{ .revogado .tudo }

III - descentralização das decisões.
{ .revogado .tudo }

### CAPÍTULO I — DO CONTROLE DE RESULTADOS { .centro .revogado }

**Art. 22.** O controle de resultados dos programas e das ações dos Órgãos Municipais constitui responsabilidade de todos os níveis de chefia e será exercido, de forma sistemática e permanente, compreendendo:
{ #art-22 .revogado }

I - a avaliação da realização física de planos, programas e orçamentos;
{ .revogado .tudo }

II - a avaliação comparativa dos custos operacionais com os resultados obtidos;
{ .revogado .tudo }

III - o acompanhamento e controle de obras, serviços e materiais, de acordo com as especificações previstas em licitações;
{ .revogado .tudo }

IV - a otimização de tempo, de recursos financeiros, materiais e humanos, racionalizando métodos, processos e práticas de trabalho que configurem desperdício.
{ .revogado .tudo }

### CAPÍTULO II — DA COORDENAÇÃO FUNCIONAL { .centro .revogado }

**Art. 23.** A coordenação funcional na Administração Municipal tem por objetivo evitar a superposição de iniciativas, facilitar a complementaridade de esforço e desenvolver a comunicação entre Secretarias e entre estas e os servidores.
{ #art-23 .revogado }

Parágrafo único. A coordenação funcional, de que trata o ¨caput¨ deste artigo, será desenvolvida:
{ .revogado .tudo }

I - pelo Prefeito, Vice-Prefeito, Secretários Municipais e equivalentes;
{ .revogado .tudo }

II - pelos Assessores das Secretarias.
{ .revogado .tudo }

**Art. 24.** A coordenação funcional, em nível superior, cabe opinar sobre:
{ #art-24 .revogado }

I - medidas de incentivo ao desenvolvimento e fortalecimento da economia municipal;
{ .revogado .tudo }

II - diretrizes gerais dos planos de trabalho e respectiva escala de prioridades;
{ .revogado .tudo }

III - política de ação social voltada para a população de baixa renda;
{ .revogado .tudo }

IV - revisão, de acordo com a conjuntura administrativa e financeira do orçamento e da programação dos diferentes órgãos municipais;
{ .revogado .tudo }

V - conveniência ou não de endividamento através de contratação de empréstimo;
{ .revogado .tudo }

VI - alterações da política de vencimentos, de salários e de benefícios de pessoal da Administração Municipal.
{ .revogado .tudo }

Parágrafo único. As conclusões da coordenação funcional, em nível superior, poderão ter força normativa, se assim o decidir o Prefeito.
{ .revogado .tudo }

### CAPÍTULO III — DA DESCENTRALIZAÇÃO DAS DECISÕES { .centro .revogado }

**Art. 25.** Os servidores ocupantes de cargo de chefia, em todos os níveis, são responsáveis pela melhoria da qualidade dos serviços públicos e têm por atribuições:
{ #art-25 .revogado }

I - coordenar, supervisionar, controlar e avaliar a aplicação dos recursos financeiros, assegurando a racionalidade das atividades e serviços, evitando a duplicidade de ações, com vistas à consecução das metas e objetivos propostos;
{ .revogado .tudo }

II - divulgar os objetivos, metas e atividades contidas no plano de ação do órgão que chefia, com vistas ao comprometimento de todos com os propósitos estabelecidos;
{ .revogado .tudo }

III - estabelecer mecanismos de valorização do servidor, incentivando-o à participação efetiva e crítica no processo;
{ .revogado .tudo }

IV - coordenar, supervisionar, orientar e acompanhar a execução de planos, projetos e atividades, com vistas à consecução dos objetivos propostos;
{ .revogado .tudo }

V - incentivar o servidor à participação de cursos, encontros e treinamentos, com vistas à melhoria de seu desempenho.
{ .revogado .tudo }

**Art. 26.** As responsabilidades e atribuições específicas das chefias, em todos os níveis, será especificadas no regimento interno dos respectivos órgãos.
{ #art-26 .revogado }

## TÍTULO VI — DAS DISPOSIÇÕES GERAIS E TRANSITÓRIAS { .centro .revogado }

### CAPÍTULO I — DAS DISPOSIÇÕES GERAIS { .centro .revogado }

**Art. 27.** Por força das alterações da estrutura e das atribuições das Secretarias Municipais, fica o Poder Executivo autorizado a realizar, através de decreto, as alterações orçamentárias no presente exercício, necessárias para a operacionalização das novas unidades gestoras.
{ #art-27 .revogado }

**Art. 28.** Os Fundos Municipais serão geridos da forma prevista em seus atos constitutivos.
{ #art-28 .revogado }

**Art. 29.** O Controle Interno, instituído pela [Lei nº 941/2011](../2011/lei-941-2011.md), de 20 de dezembro de 2011, os Conselhos Municipais, órgãos de assessoramento de suas respectivas secretarias afins, ficam vinculados ao Gabinete do Prefeito.
{ #art-29 .revogado }

**Art. 30.** A Coordenadoria Especial da Mulher- CEMU, instituída pela [Lei nº 740/2007](../2007/lei-740-2007.md), de 23/08/2007, passa a ser vinculada na Secretaria Municipal de Assistência Social.
{ #art-30 .revogado }

**Art. 31.** Os Agentes Políticos, Prefeito, Vice-Prefeito, Secretários, Vereadores e os ocupantes de Cargos Comissionados passam a receber subsídio, composto de parcela única.
{ #art-31 .revogado }

**Art. 32.** Anualmente a Câmara Municipal estabelecerá a correção dos subsídios do Prefeito, Vice-Prefeito e Secretários.
{ #art-32 .revogado }

### CAPÍTULO II — DAS DISPOSIÇÕES TRANSITÓRIAS { .centro .revogado }

**Art. 33.** Fica o Poder Executivo autorizado a abrir Créditos Especiais no orçamento para o exercício de 2013, no limite dos saldos disponíveis das unidades orçamentárias extintas, fusionadas, incorporadas ou transformadas, e/ou ainda adequar todas as dotações orçamentárias de conformidade com as alterações nas unidades administrativas, constantes da presente Lei.
{ #art-33 .revogado }

**Art. 34.** Fica o Poder Executivo autorizado a delegar através de Decreto Municipal, poderes para os Secretários Municipais de ordenar conjuntamente ou isoladamente as despesas da sua Secretaria, bem como assinar cheques das Contas Bancárias referentes a Fundos Municipais, atendendo todas as normas constitucionais inerentes aos Fundos.
{ #art-34 .revogado }

**Art. 35.** O Poder Executivo Municipal regulamentará, no que couber, através de Decreto, as disposições desta Lei.
{ #art-35 .revogado }

**Art. 36.** Ficam criados os cargos comissionados constantes do **Anexo III** desta Lei.
{ #art-36 .revogado }

**Art. 37.** A distribuição dos cargos em comissão fica estabelecida pelo constante do **Anexo IV** desta Lei.
{ #art-37 .revogado }

**Art. 38.** Os Funcionários ocupantes dos cargos comissionados descritos acima, estarão sob a égide do Regime Estatutário.
{ #art-38 .revogado }

**Art. 39.** Revogam-se as disposições em contrário, e em especial a [Lei nº 867/2010](../2010/lei-867-2010.md), de 30 de julho de 2010.
{ #art-39 .revogado }

**Art. 40.** Esta Lei entra em vigor na data de sua publicação e/ou afixação, retroagindo seus efeitos a primeiro de janeiro de 2013.
{ #art-40 .revogado }

Prefeitura Municipal de Batayporã-MS., aos dezesseis dias do mês de janeiro de 2013.
