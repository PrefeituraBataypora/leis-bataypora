**LEI Nº-017/83, De 17 de novembro de 1983.**
{ .centro }

Dispõe sobre aumento dos vencimentos dos Servidores da Câmara Municipal de Bataiporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento de 30% (trinta por cento) sobre os vencimentos dos Servidores da Câmara Municipal, com efeito retroativo a partir de 1º de novembro do corrente ano, e mais uma majoração na ordem de 20% (vinte por cento) sobre o último vencimento a partir de 1º de janeiro de 1984.
{ #art-1 }

**Art. 2º** - As despesas com a execução da presente Lei correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de novembro de 1983.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos dezessete dias do mês de novembro de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Leis, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
