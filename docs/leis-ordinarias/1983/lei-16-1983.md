**LEI Nº-016/83, De 16 de novembro de 1983.**
{ .centro }

Dispõe sobre Declaração de Utilidade Pública a Associação Bataiporãense de Professores, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica declarada de Utilidade Pública a "ASSOCIAÇÃO BATAIPORÃENSE DE PROFESSORES", com sede nesta cidade, pelos relevantes serviços prestados em nosso Município no setor de Educação.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos dezesseis dias do mês de novembro de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Leis, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
