**LEI Nº-009/83. De 25 de agosto de 1983.**
{ .centro }

Dispõe sobre nova denominação da Rua Piauí, na cidade de Bataiporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - A Rua Piauí, localizada na cidade de Bataiporã-MS., passará a denominar-se Rua JONAS PEDRO NUNES.
{ #art-1 }

**Art. 2º** - As despesas provenientes com a execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e cinco dias do mês de agosto de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Leis, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
