**LEI Nº-004/83, De 25 de maio de 1983.**
{ .centro }

Dispõe sobre aquisição de imóvel.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a adquirir um imóvel urbano, com área de 420m² (14,00 m x 30,00 m) constante da Data nº-3 da Quadra nº-40, terreno este localizado na Rua Paraná, nesta.
{ #art-1 }

**Art. 2º** - Fica o Poder Executivo Municipal autorizado a pagar a quantia de Cr$-200.000,00 (duzentos mil cruzeiros) pela aquisição do referido terreno, conforme avaliação prévia realizada por Comissão Especial designada para tal finalidade.
{ #art-2 }

**Art. 3º** - O pagamento a que se refere o artigo anterior será feito em três parcelas, a primeira no ato da compra, na importância de Cr$-80.000,00 (oitenta mil cruzeiros), as duas restantes na importância de Cr$-60.000,00 (sessenta mil cruzeiros) cada uma, vencível a cada trinta dias, a partir da data da compra do referido imóvel.
{ #art-3 }

**Art. 4º** As despesas decorrentes da execução da presente Lei, correrão por conta de dotações orçamentárias do orçamento em vigor.
{ #art-4 }

**Art. 5º** Esta Lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e cinco dias do mês de maio de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

PREFEITO MUNICIPAL
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Lei, e afixado em local de costume, em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
