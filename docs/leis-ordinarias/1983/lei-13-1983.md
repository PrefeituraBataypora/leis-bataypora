**LEI Nº-013/83, De 21 de outubro de 1983.**
{ .centro }

Dispõe sobre Declaração de Utilidade Pública Municipal a União dos Vereadores de Mato Grosso do Sul.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica declarada de Utilidade Pública Municipal a UNIÃO DOS VEREADORES DE MATO GROSSO DO SUL, pelos relevantes serviços prestados a este Município.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS., aos vinte e um dias do mês de outubro de 1983.

DR. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Leis, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
