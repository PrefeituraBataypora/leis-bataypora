**LEI Nº-011/83, De 06 de setembro de 1983.**
{ .centro }

Dispõe sobre construções de calçadas e passeios na Av. Brasil.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Todos os proprietários de imóveis com frente ou testada para a avenida Brasil, são obrigados a construir as calçadas ou passeios de acordo com o padrão do Projeto adotado pela municipalidade.
{ #art-1 }

Parágrafo Único - A obra de que trata o presente artigo será construída com a orientação técnica do engenheiro responsável pela parte técnica da municipalidade.

**Art. 2º** - O Projeto adotado para a construção das calçadas ou passeios obedecerão as seguintes normas:
{ #art-2 }

a)-solo compactado;

b)-concreto 1:4:6, com espessura de 3 centímetros;

c)-areia e cimento 1:3, com espessura de 1 centímetro;

d)-junta de dilatação.

**Art. 3º** - As calçadas ou passeios terão a inclinação de 3% (três por cento).
{ #art-3 }

**Art. 4º** - A rampa para acesso aos veículos, obedecerá o Projeto com a inclinação de 3% (três por cento) e mais a percentagem necessária para a entrada do veículo com a extensão a partir do meio-fio de 45 centímetros, o concreto terá a espessura obrigatória de 5 centímetros.
{ #art-4 }

**Art. 5º** - As calçadas ou passeios terão suas larguras determinadas, em cada caso pelo Projeto das seções transversais das ruas em que vão ser construídas.
{ #art-5 }

**Art. 6º** - O prazo para construção das calçadas ou passeios é de 90 (noventa) dias, a partir da data da publicação da presente Lei, após os quais, não havendo construído, a municipalidade executará a obra com ônus para os proprietários dos imóveis.
{ #art-6 }

**Art. 7º** - As condições para o pagamento do custo da obra realizada pela municipalidade, serão as seguintes:
{ #art-7 }

a) - pagamento a vista, no ato da entrega da obra, sendo dividido em 3(três) parcelas iguais, uma pagável no ato, e outras duas vencíveis a cada 30(trinta) dias, sem acréscimo;

b) - pagamento a prazo, em até 8(oito) parcelas iguais vencíveis a cada 30(trinta) dias, de acordo com as Obrigações Reajustáveis do Tesouro Nacional - ORTN.

**Art. 8º** - As construções de calçadas ou passeios executadas pela Municipalidade, serão cobrados os custos dos materiais e a mão-de-obra, pelo preço da época da execução da referida obra.
{ #art-8 }

**Art. 9º** - Todas as calçadas ou passeios existentes, deverão ser demolidos e reconstruídos de conformidade com o disposto no artigo 2º da presente Lei.
{ #art-9 }

**Art. 10.** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-10 }

**Art. 11.** - Revogam-se as disposições em contrário.
{ #art-11 }

Prefeitura Municipal de Bataiporã-MS., aos seis dias do mês de setembro de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }
