**LEI Nº-003/83, De 27 de abril de 1983**
{ .centro }

Dispõe sobre nova denominação da Rua Rio Grande do Norte, na cidade de Bataiporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.
Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte lei:

**Art. 1º** - A Rua Rio Grande do Norte, localizada na cidade de Bataiporã-MS, passará a denominar-se RUA PASCHOAL JOSE DA SILVA.
{ #art-1 }

**Art. 2º** - As despesas provenientes com a execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS., aos vinte e sete dias do mês de abril de 1983.

Dr. João Jamil Mella
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria no livro nº-06 (seis) de lei, afixada em local de costume em data acima citada.

José Antonio Frutuoso
{ .centro }

Secretário
{ .centro }
