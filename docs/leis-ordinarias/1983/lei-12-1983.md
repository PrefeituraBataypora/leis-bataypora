**LEI Nº-012/83, De 05 de Outubro de 1983.**
{ .centro }

Dispõe sobre abertura adicional suplementar no Orçamento Vigente e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a abrir crédito adicional suplementar, para reforço da seguinte dotação do Orçamento vigente.
{ #art-1 }

I - CÂMARA MUNICIPAL — 3100 - Despesas de Custeio — 01 - Pessoal Civil: Cr$ 3.405.000,00

II - CÂMARA MUNICIPAL — 3100 - Despesas de Custeio — 02 - Outros: Cr$ 1.800.000,00

TOTAL DAS SUPLEMENTAÇÕES: Cr$ 5.205.000,00

**Art. 2º** - Para cobertura das despesas decorrentes do artigo 1º desta lei, fica o Poder Executivo autorizado a recorrer pela anulação parcial das dotações do orçamento vigente.
{ #art-2 }

I - SECRETARIA DA ADMINISTRAÇÃO — Departamento de Obras e Serviços Urbanos — 4000 - Despesas de Capital — 4100 - Investimentos: Cr$ 5.205.000,00

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS., aos cinco dias do mês de outubro de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Leis, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
