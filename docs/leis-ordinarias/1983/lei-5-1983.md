**LEI Nº-005/83, De 01 de junho de 1983.**
{ .centro }

Dispõe sobre o aumento e fixação de salários dos Servidores Públicos Municipais de Bataiporã-MS, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica aumentado e fixado os salários dos Servidores Públicos Municipais de Bataiporã de conformidade com o anexo nº-1.
{ #art-1 }

**Art. 2º** - As despesas decorrentes com a execução da presente lei, correrão por conta de dotações orçamentárias constante do orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de primeiro de maio de 1983.
{ #art-3 }

**Art. 4º** Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, ao primeiro dia do mês de junho de 1983.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro nº-06 (seis) de Lei, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
