# Lei nº 716/2006

> Dispõe sobre doação de imóveis, e dá outras providências.

!!! warning "Texto em revisão"
    Transcrito do arquivo .doc da prefeitura e **ainda em revisão**. Esta lei não está publicada na [página de legislação da prefeitura](https://bataypora.ms.gov.br/cidadao/legislacao-municipal); por isso não há PDF para conferir.

!!! info "Alterada pela Lei nº 827/2009"
    A [Lei nº 827/2009](../2009/lei-827-2009.md), de 27 de outubro de 2009, autorizou a permuta do imóvel doado por esta lei, mantendo as obrigações aqui previstas.

!!! danger "Lei revogada"
    Esta lei foi revogada pelo [art. 2º da Lei nº 1014/2013](../2013/lei-1014-2013.md#art-2), de 12 de junho de 2013.

**Lei nº. 716/2006 de 06 de dezembro de 2006.**
{ .centro .revogado .tudo }

“Dispõe sobre doação de imóveis, e dá outras providências”.
{ .revogado .tudo }

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Fica o Poder Executivo autorizado a doar o imóvel urbano localizado a Rua Horaciano Soares de Oliveira (antiga Rua Paraná), com área de 630m² (seiscentos e trinta metros quadrados), Data 19, Quadra 49, de propriedade desta municipalidade, para a Empresa **JOSÉ APARECIDO ZACCHI – ME*,*** inscrita no CNPJ sob o nº 08.097934/0001-03, estabelecida à Rua José Adelino da Rocha, 1329, Centro, Batayporã-MS; destinada a construção de sede própria, para a execução das atividades de fabricação de esquadrias de metal.
{ #art-1 .revogado }

**Art. 2º** À empresa beneficiada pelo artigo anterior fica assegurada o prazo de 06 (seis) meses para o inicio da construção e instalação de sua Sede, acrescido o prazo de 03 (três) meses de carência.
{ #art-2 .revogado }

**Art. 3º** Fica determinado que a Empresa **JOSÉ APARECIDO ZACCHI – ME**, não poderá em hipótese alguma, mudar a finalidade do imóvel.
{ #art-3 .revogado }

**Art. 4º** Não cumpridas as determinações constantes dos Artigos 2º e 3º, da presente Lei, o imóvel retornará ao domínio do município, sem nenhuma indenização.
{ #art-4 .revogado }

**Art. 5º** Fica também o Poder Executivo autorizado a efetuar baixa do Patrimônio Municipal da referida área, obedecendo ao valor constante no Balanço Patrimonial da municipalidade.
{ #art-5 .revogado }

**Art. 6º** O Município fornecerá toda documentação necessária para o fiel desempenho da presente doação acima autorizada.
{ #art-6 .revogado }

**Art. 7º** Esta Lei entrará em vigor na data de sua publicação e/ou afixação, revogadas as disposições em contrário.
{ #art-7 .revogado }

Prefeitura Municipal de Batayporã-MS, aos seis dias do mês de dezembro de 2006.
{ .revogado .tudo }

**Dr. Jercé Eusébio de Souza**
