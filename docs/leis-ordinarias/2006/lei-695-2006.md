**Lei nº. 695/2006 de 26 de abril de 2006.**
{ .centro }

“Reajusta os salários dos Servidores Públicos Municipais, e dá outras providências”.

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso de suas atribuições legais;

Faz saber que a Câmara Municipal aprovou e ele sanciona e promulga a seguinte lei:

**Art. 1º** Fica reajustado para R$ 350,00 (trezentos e cinqüenta reais) todas as referências até R$ 350,00 e as demais em 4,85% (quatro virgula oitenta e cinco por cento) para todos os Servidores Públicos do Poder Executivo do Município de Batayporã-MS, a partir de primeiro de abril do corrente ano.
{ #art-1 }

**Art. 2º** O Poder Executivo Municipal regulamentará, no que couber, através de Decreto Municipal, as disposições desta Lei.
{ #art-2 }

**Art. 3º** As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes do Orçamento Municipal.
{ #art-3 }

**Art. 4º** Revogam-se as disposições em contrário.
{ #art-4 }

**Art. 5º** Esta Lei entrará em vigor na data de sua publicação e/ou afixação, retroagindo seus efeitos a primeiro de abril de 2006.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos vinte e seis dias do mês de abril de 2006.

**Dr. Jercé Eusébio de Souza**
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio da Secretaria de Administração, Finanças e Planejamento, e afixado em local de costume em data acima citada.

**José Antonio Frutuoso**

Secretário
