**LEI Nº-388/98, De 16 de abril de 1998.**
{ .centro }

Dispõe sobre aquisição de imóvel urbano, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica o Poder Público Municipal autorizado a adquirir o imóvel descrito seguinte: terreno urbano, constante da data nº 22, da quadra nº 34, com área total de 420,00 metros quadrados, contendo uma casa de alvenaria coberta de telhas francesas.
{ #art-1 }

Parágrafo único - o imóvel a ser adquirido, respeitando a avaliação prévia, pertence a Agropecuária Jubran S/A, conforme Registro Imobiliário, livro 02, matrícula 11.008 de 29-01-88.

**Art. 2º** - As despesas decorrentes da aquisição do referido imóvel, correrão por conta de dotações próprias consignados no orçamento vigente, suplementadas, se necessário for.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos dezesseis dias do mês de abril de um mil novecentos e noventa e oito.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
