**LEI Nº-392/98, De 30 de abril de 1998.**
{ .centro }

Autoriza pagamentos de diárias ao vice-prefeito do Município, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica concedido ao vice-prefeito do Município, diárias, quando em serviço do município, ou quando representante do Prefeito Municipal.
{ #art-1 }

**Art. 2º** - Fica vetado, pagamentos de outras despesas, sob qualquer título, para o exercício de representante do município, autorizado pelo Prefeito Municipal.
{ #art-2 }

**Art. 3º** - A diária será concedida em UFERMS (Unidade Fiscal de Referência do Estado de Mato Grosso do Sul), conforme os parâmetros seguintes:
{ #art-3 }

I- Para dentro do Estado......31,50 UFERMS

II- Para outros Estados e Distrito Federal........57,20 UFERMS

**Art. 4º** - Esta Lei será regulamentada no prazo de 30 (trinta) dias.
{ #art-4 }

**Art. 5º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogando-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã aos trinta dias do mês de abril de um mil novecentos e noventa e oito.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
