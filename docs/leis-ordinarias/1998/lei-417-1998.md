**LEI Nº-417/98, De 10 de dezembro de 1998.**
{ .centro }

Promove doação com encargos de linhas telefônicas, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Município autorizado a promover doações com encargos de todas as linhas telefônicas em uso e em caráter de empréstimo.
{ #art-1 }

**Art. 2º** - As linhas telefônicas de propriedade do Município, em uso por terceiros são dos seguintes prefixos: 443 1305 (Empaer); 443 1086 (F.N.S – Fundação Nacional de Saúde); 443 1093 (Clínica da Mulher); 443 1278 (Escola Jan Antonin Bata).
{ #art-2 }

**Art. 3º** - Os prefixos doados, não poderão serem alienados pelo período de um ano.
{ #art-3 }

Parágrafo Único – Se houver extinção, ou transferência das linhas telefônicas no prazo deste artigo, as mesmas se reverterão para o município sem quaisquer ônus.

**Art. 4º** - A listagem das linhas doadas e outros documentos serão remetidos a TELEMS, para efeito da transferência.
{ #art-4 }

**Art. 5º** - Esta Lei entra em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos dez dias do mês de dezembro de 1998

AGENOR GAMBA
{ .centro }

Prefeio Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
