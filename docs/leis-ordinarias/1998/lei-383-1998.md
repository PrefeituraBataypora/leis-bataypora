**LEI Nº-383/98, De 09 de março de 1998.**
{ .centro }

Dispõe sobre Subvenção Social a APAE de Nova Andradina, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - O Poder Executivo Municipal fica autorizado a conceder Subvenção Social a APAE (Associação de Pais e Amigos dos Excepcionais de Nova Andradina-MS), no valor de R$ 960,00 (Novencentos e sessenta reais) mensais, durante o corrente exercício financeiro.
{ #art-1 }

**Art. 2º** - A entidade beneficiada, constante do artigo 1º, desta lei, fica obrigada a prestação de contas à municipalidade, constante das normas do Tribunal de Contas
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente lei, correrão por conta de dotação orçamentária específica.
{ #art-3 }

**Art. 4º** - Esta lei entrará em vigor na data de sua publicação, retroagindo seus efeitos a partir de 01 de fevereiro de 1998.
{ #art-4 }

**Art. 5º** - Ficam revogadas as disposições em contrário, especialmente todos os termos da [Lei nº 355/97](../1997/lei-355-1997.md), de 19-03-97.
{ #art-5 }

Prefeitura Municipal de Batayporã aos nove dias do mês de março de um mil novecentos e noventa e oito.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
