**LEI Nº-405/98, De 20 de agosto de 1998.**
{ .centro }

Autoriza a abertura de Créditos Suplementares, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - O Poder Executivo Municipal, fica autorizado a abrir Créditos Suplementares até o limite de 40% (quarenta por cento) do Orçamento Geral da Despesa, constante da [Lei Municipal nº 374/97](../1997/lei-374-1997.md) de 15-12-97, (Estima a Receita e fixa a Despesa do Município de Batayporã-MS, para o execício de 1998), nos termos do artigo 7º da Lei 4.320/64 de 17/03/1964.
{ #art-1 }

**Art. 2º** - Esta Lei entra em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, 20 de agosto de 1998

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Resgistrada em livro próprio da Secretaria de Administração, e afixada em local de costume supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
