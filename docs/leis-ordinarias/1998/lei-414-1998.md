**LEI Nº-414/98, De 10 de dezembro de 1998.**
{ .centro }

Autoriza a aquisição dos imóveis que especifica, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Poder Público Municipal, autorizado a adquirir os lotes nº 13 e 14, da quadra 6, localizada à Rua Luiz Antonio da Silva, nesta cidade, com área de 420,00 m² cada lote.
{ #art-1 }

**Art. 2º** - As despesas decorrentes da presente lei, correrão por conta de dotações próprias consignadas no orçamento vigente, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos dez dias do mês de dezembro de 1998.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
