**LEI Nº-389/98, De 16 de abril de 1998.**
{ .centro }

Concede prazo para edificação nos lotes urbanos doados, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica concedido o prazo de 60 (sessenta) dias, para que os proprietários dos lotes territorial urbanos, doados pela municipalidade, promovam o início da construção das moradias.
{ #art-1 }

§1º - A partir da publicação da presente lei, durante o prazo fixado no "caput" desse artigo, fica expressamente proibida a venda e/ou transferência de imóveis, objeto de doação através da municipalidade.

§2º - O Executivo Municipal encaminhará ao Cartório e aos escritórios locais, cópia da presente lei, bem como os comunicará sobre tal proibição.

§3º - As vendas e/ou transferências efetuadas durante o prazo fixado no artigo 1º da presente lei, serão consideradas nulas, e o imóvel retornará ao domínio do Município.

**Art. 2º** - A construção das moradias, terão o prazo para o término, até trinta de julho de 1998, para o cumprimento da lei de doação e de seus respectivos encargos.
{ #art-2 }

**Art. 3º** - A presente Lei é extensiva a todas as denominações de vilas da sede do município.
{ #art-3 }

**Art. 4º** - Após a data limite para construção das moradias, não havendo o cumprimento das exigências, os terrenos urbanos inadimplentes, voltarão a posse direta da municipalidade unilateralmente, para posteriores doações e edificações.
{ #art-4 }

**Art. 5º** - Todos os donatários dos lotes com os encargos impostos nas doações anteriores e posteriores, como exemplos: prazo de edificação, proibição de transferência a terceiros, etc., deverão fazer parte da ficha cadastral, para o controle dos terrenos doados.
{ #art-5 }

**Art. 6º** - Esta Lei poderá ser regulamentada, se necessário for, dentro de 30 (trinta) dias.
{ #art-6 }

**Art. 7º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Batayporã aos dezesseis dias do mês de abril de um mil novecentos e noventa e oito.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }
