**LEI Nº-394/98, De 13 de maio de 1998.**
{ .centro }

Cria o balcão de emprego do bóia fria e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a criar o Balcão de Emprego do Bóia Fria, no Município de Batayporã-MS.
{ #art-1 }

Parágrafo único - O Balcão de Emprego criado através do Caput desse artigo, ficará subordinado a Secretária Municipal de Agricultura.

**Art. 2º** - O Balcão de Emprego do Bóia Fria, terá como finalidade, cadastrar as pessoas que pretendem trabalhar no âmbito da Agricultura, e encaminhá-las aos respectivos serviços.
{ #art-2 }

**Art. 3º** - O Executivo Municipal dotará o referido Balcão de Emprego, de uma estrutura básica para o seu funcionamento, tais como: - pessoal, locais de embarque e desembarque das pessoas, com o respectivo abrigo de proteção, espaço físico, etc.
{ #art-3 }

**Art. 4º** - A Secretaria Municipal de Agricultura, através do Balcão de Emprego do Bóia Fria, promoverá uma ampla divulgação dos objetivos de tal órgão, incentivando-os a se cadastrarem.
{ #art-4 }

**Art. 5º** - As despesas decorrentes da execução da presente lei correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-5 }
