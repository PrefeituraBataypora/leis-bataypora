**LEI Nº-382/98, De 09 de março de 1998.**
{ .centro .revogado .tudo }

Autoriza a contratação de pessoal, por prazo determinado nos termos do Artigo 37, Inciso IX, da Constituição Federal, e dá outras providências.
{ .revogado .tudo }

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica o Poder Público Municipal autorizado a promover a contratação, por prazo determinado de pessoal, para atender a necessidade temporária de excepcional interesse público, conforme alude o art. 37 inciso IX, da Constituição Federal.
{ #art-1 .revogado }

**Art. 2º** - Ficam estabelecidos os casos de contratações por tempo determinado, plenamente justificáveis, o quanto segue:
{ #art-2 .revogado }

I. de emergência, quando caracterizada a urgência, e a inadiabilidade de atendimento em situação que possa comprometer a realização de eventos, ou ocasionar prejuízos à segurança e a saúde das pessoas, obras, serviços, equipamentos e outros bens públicos;
{ .revogado .tudo }

II. de pessoal em casos de demissão, exoneração, falecimentos, aposentadorias, nos serviços essenciais, não podendo ultrapassar a limitação de 30% (trinta por cento) do total do Quadro dos Cargos Efetivos, constituídos por lei;
{ .revogado .tudo }

III.de substituição de professores, e pessoal para prestação de serviços, para o ensino fundamental;
{ .revogado .tudo }

IV.de campanhas de saúde pública.
{ .revogado .tudo }

Parágrafo único - a contratação de pessoa, nos casos de necessidade e de excepcional interesse público comprovado terá validade, até a realização de concurso público.
{ .revogado .tudo }

**Art. 3º** - As hipóteses das contratações terá vigência no máximo do corrente exercício.
{ #art-3 .revogado }

Parágrafo único - O Executivo Municipal deverá no prazo máximo de 06 (seis) meses realizar o concurso público para preenchimento das necessidades.
{ .revogado .tudo }

**Art. 4º** - Nas contratações para atendimento a funções que correspondem a cargos, serão observadas as seguintes condições:
{ #art-4 .revogado }

I. fixação de remuneração com base na referência inicial do cargo;
{ .revogado .tudo }

II.prestação de horas semanais de trabalho correspondentes às previstas para as funções a serem desempenhadas.
{ .revogado .tudo }

**Art. 5º** - O Poder Público Municipal, durante o corrente exercício, estabelecerá sua reforma administrativa, com seu organograma, para a realização de concurso público, no preenchimento de cargos e vagas estabelecidas.
{ #art-5 .revogado }

**Art. 6º** - As despesas decorrentes com a execução da presente lei, correrão por conta de dotação orçamentária própria constante do orçamento em vigor.
{ #art-6 .revogado }

**Art. 7º** - Esta lei entrará em vigor na data de sua publicação, revogando as disposições em contrário.
{ #art-7 .revogado }

Prefeitura Municipal de Batayporã aos nove dias do mês de março de um mil novecentos e noventa e oito.
{ .revogado .tudo }

AGENOR GAMBA
{ .centro .revogado .tudo }

Prefeito Municipal
