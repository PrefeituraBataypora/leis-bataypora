**LEI Nº-402/98, De 20 de agosto de 1998.**
{ .centro }

Autoriza a aquisição e doação do imóvel que especifica ao DETRAN, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Município autorizado a adquirir o seguinte imóvel territorial urbano, que pertence a José Jorge Gonçalves e sua mulher:
{ #art-1 }

"Imóvel territorial urbano constante da data 10, quadra 37, da planta geral, medindo 14,00 metros de frente com a Avenida Brasil, por 30,00 metros de frente ao fundo, no total de 420,00 metros quadrados".

**Art. 2º** - Fica igualmente o Município autorizado a doar o imóvel constante do artigo 1º, desta Lei, ao Departamento Estadual de Trânsito – DETRAN-MS, para edificação de prédio próprio.
{ #art-2 }

**Art. 3º** - A aquisição do imóvel, será de até pelo valor de sua avaliação, nomeada especialmente para este fim.
{ #art-3 }

**Art. 4º** - As despesas serão suportadas pela dotação orçamentária consignadas no Orçamento vigente suplementadas se necessário.
{ #art-4 }

**Art. 5º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos vinte dias do mês de agosto de 1998.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
