**LEI Nº-411/98, De 26 de novembro de 1998.**
{ .centro }

Dispõe sobre a proibição de depósitos de materiais de qualquer espécie, que retenha água estocada ou empoçada, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica expressamente proibido neste Município, o depósito ao ar livre, de materiais de qualquer espécie, que retenham água estocada ou empoçada.
{ #art-1 }

Parágrafo único - Excetuam-se das proibições constante no "caput" deste artigo, as caixas d'águas das borracharias, cuja água é trocada constantemente.

**Art. 2º** - Os infratores do disposto nesta lei, serão multados em 100 (cem) UFIR.
{ #art-2 }

Parágrafo único - Em caso de reincidência, será aplicada multa em dobro.

**Art. 3º** - O Executivo Municipal regulamentará a presente lei, dentro de 60 (sessenta) dias, a contar da data de publicação desta lei.
{ #art-3 }

**Art. 4º** - Esta lei entra em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos vinte e seis dias do mês de novembro de 1998.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
