**LEI Nº-399/98, De 15 de junho de 1998.**
{ .centro }

Estabelece ponto de táxi no Terminal Rodoviário, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei;

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica criado no Terminal Rodoviário, o Ponto de Táxi nº 3, com o máximo dois veículos.
{ #art-1 }

**Art. 2º** - Não havendo interessados na permissão do referido ponto de táxi, poderá a critério da Administração autorizar o rodízio entre os taxistas do Ponto 1 e 2.
{ #art-2 }

**Art. 3º** - Esta Lei será regulamentada se necessário for.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos quinze dias do mês de junho de 1998

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
