**LEI Nº-408/98, De 30 de setembro de 1998.**
{ .centro }

Autoriza abertura de Crédito Adicional, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Poder Público Municipal autorizado a abrir Crédito Adicional no valor de R$ 100.000,00 (cem mil reais) para cobertura de dotações orçamentárias do Fundo Municipal de Saúde – FMS.
{ #art-1 }

**Art. 2º** - A cobertura das despesas oriundas do artigo 1º desta lei, correrão por conta do excesso de arrecadação que se verificou no corrente exercício, do Município.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos trinta dias do mês de setembro de 1998

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
