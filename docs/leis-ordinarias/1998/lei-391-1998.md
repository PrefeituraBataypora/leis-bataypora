**LEI Nº-391/98, De 30 de abril de 1998.**
{ .centro }

Estabelece subvenção social a Entidade Assistencial, que especifica e dá outra providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica concedido ao "Lar Alternativo São José" de Nova Andradina-MS, a subvenção social no valor de R$ 360,00 (trezentos e sessenta reais) por mês.
{ #art-1 }

**Art. 2º** - Nos orçamentos futuros constarão da dotação específica, bem como a sua inclusão nas Diretrizes Orçamentárias do Município.
{ #art-2 }

**Art. 3º** - As despesas constantes do artigo 1º desta Lei, correrão por conta de dotação própria, consignada no orçamento vigente.
{ #art-3 }

**Art. 4º** - Esta lei entra em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã aos trinta dias do mês de abril de um mil novecentos e noventa e oito.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
