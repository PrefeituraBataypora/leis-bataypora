**LEI Nº-395/98, De 26 de maio de 1998.**
{ .centro }

Declara de utilidade Pública Municipal a Associação Comunitária Rádio Educativa Cidade FM, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica declarado de Utilidade Pública Municipal para todos os efeitos legais a "ASSOCIAÇÃO COMUNITÁRIA RÁDIO CIDADE FM, entidade sem fins lucrativos, com sede na cidade de Batayporã-MS, `a Rua Jair de Abranches Mella, 1350.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação, ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã aos vinte e seis dias do mês de maio de um mil novecentos e noventa e oito.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração
{ .centro }
