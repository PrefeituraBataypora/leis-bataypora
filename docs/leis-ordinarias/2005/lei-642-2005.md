**Lei nº. 642/2005, de 11 de fevereiro de 2005.**
{ .centro .revogado .tudo }

“Dispõe sobre a criação do Fundo Municipal de Incentivo à Cultura e Esportes no Município de Batayporã-MS, e dá outras providências”.
{ .revogado .tudo }

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e Eu sanciono e promulgo a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Fica criado o Fundo Municipal de Incentivo à Cultura e Esporte – FMICE, destinado a apoiar projetos estritamente culturais e esportivos de iniciativa de pessoas físicas e ou jurídicas de direito privado, com a finalidade de estimular e fomentar a produção histórico-artistico-esportiva do Município de Batayporã-MS.
{ #art-1 .revogado }

**Art. 2º** As receitas do Fundo Municipal de Incentivo à Cultura e Esporte – FMICE serão oriundas das seguintes fontes:
{ #art-2 .revogado }

I - Dotações orçamentárias do Município;
{ .revogado .tudo }

II\. Patrocínios e doações;
{ .revogado .tudo }

III\. Rendimentos provenientes da aplicação dos recursos do FMICE;
{ .revogado .tudo }

IV\. Recursos oriundos de eventos promovidos pelo FMICE;
{ .revogado .tudo }

V - Transferências intergovernamentais para esta finalidade;
{ .revogado .tudo }

VI\. Multas decorrentes de danos ao patrimônio histórico e bens-culturais e esportivos;
{ .revogado .tudo }

VI\. Contribuição de empresas, observando o disposto no parágrafo único;
{ .revogado .tudo }

VIII\. Outros recursos eventuais.
{ .revogado .tudo }

Parágrafo único. As empresas e os profissionais liberais que contribuírem para o FMICE poderão deduzir o saldo devedor do Imposto Sobre Serviço e qualquer Natureza, apurado em cada período, os valores efetivamente depositados em beneficio do fundo.
{ .revogado .tudo }

**Art. 3º** Os projetos de produção cultural e esportivo das áreas abaixo relacionadas serão abrangidos por esta Lei:
{ #art-3 .revogado }

I - Música;
{ .revogado .tudo }

II\. Artes plásticas;
{ .revogado .tudo }

III\. Cinema;
{ .revogado .tudo }

IV\. Vídeo;
{ .revogado .tudo }

V - Fotografia;
{ .revogado .tudo }

VI\. Literatura;
{ .revogado .tudo }

VII\. Artesanato;
{ .revogado .tudo }

VIII\. Pesquisa;
{ .revogado .tudo }

IX\. Artes cênicas (teatro, circo, dança e ópera);
{ .revogado .tudo }

X - Documentação;
{ .revogado .tudo }

XI\. Preservação e restauração do patrimônio histórico, artístico, cultural e arquitetônico.
{ .revogado .tudo }

XII\. Esporte em geral.
{ .revogado .tudo }

**Art. 4º** O FMICE será administrado por uma Comissão Gestora composta por 08 (oito) membros, cujos 04(quatro) nomes deverão serão indicados pelo Conselho Municipal de Cultura e 04 (quatro) indicados nos seguintes termos: 01(um) representante das escolas estaduais, 01(um) representante das escolas municipais, 01(um) representante da Escola de Educação Especial Luz do Amanhã – APAE e 01(um) representante do Poder Legislativo.
{ #art-4 .revogado }

**Art. 5º** À Comissão Gestora, na aplicação dos recursos oriundos do FMICE compete:
{ #art-5 .revogado }

I - Definir as diretrizes para destinação do FMICE;
{ .revogado .tudo }

II\. Estabelecer os limites financeiros a serem utilizados por programas ou área a ser beneficiada pelo FMICE;
{ .revogado .tudo }

III\. Fixar e revisar normas e critérios referente das propostas culturais, com a devida publicidade;
{ .revogado .tudo }

IV\. Instituir Comissões Julgadoras para selecionar e aprovar as propostas inscritas junto ao FMICE, de acordo com as finalidades e áreas previstas nesta lei e as disponibilidades financeiras do Fundo;
{ .revogado .tudo }

V - Acompanhar e avaliar a execução das propostas culturais e esportivas aprovadas;
{ .revogado .tudo }

VI\. Receber e apreciar pareceres.
{ .revogado .tudo }

**Art. 6º** As empresas e profissionais liberais que contribuírem para o Fundo poderão divulgar seus nomes nos materiais de publicidade dos eventos patrocinados pelo FMICE.
{ #art-6 .revogado }

**Art. 7º** O Poder Executivo regulamentará esta Lei no prazo de 60 (sessenta) dias, no que se fizer necessários à sua perfeita execução.
{ #art-7 .revogado }

**Art. 8º** Fica o Poder Executivo Municipal autorizado a disponibilizar se necessário recursos oriundos do Orçamento Municipal vigente para custear as despesas com a execução da presente Lei.
{ #art-8 .revogado }

**Art. 9º** Esta Lei entrará em vigor na data de sua publicação e ou afixação, revogadas as disposições em contrário, retroagindo seus efeitos a primeiro de fevereiro do corrente ano.
{ #art-9 .revogado }

Prefeitura Municipal de Batayporã-MS, aos onze dias do mês de fevereiro de 2005.
{ .revogado .tudo }
