**Lei nº. 627/2004 de 02 de abril de 2004.**
{ .centro }

“Reajusta os salários dos Servidores Públicos Municipais, e dá outras providências”.

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso de suas atribuições legais;

Faz saber que a Câmara Municipal aprovou e ele sanciona e promulga a seguinte lei:

**Art. 1º** Fica reajustado em 10% (dez por cento) os salários dos Servidores Públicos do Município de Batayporã, a partir de primeiro de abril do corrente ano.
{ #art-1 }

**Art. 2º** O Poder Executivo Municipal regulamentará, no que couber, através de Decreto Municipal, as disposições desta Lei.
{ #art-2 }

**Art. 3º** As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes do Orçamento Municipal.
{ #art-3 }

**Art. 4º** Revogam-se as disposições em contrário.
{ #art-4 }

**Art. 5º** Esta Lei entrará em vigor a partir da data de sua publicação e ou afixação.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos dois dias do mês de abril de 2004.

**Dr. Jercé Eusébio de Souza**
Prefeito Municipal
{ .centro }

Registrado em livro próprio da Secretaria de Administração, Finanças e Planejamento, e afixado em local de costume em data acima citada.

**José Antonio Frutuoso**
Secretário
