# Lei nº 752/2008

> Altera o Art. 1º da Lei nº 689/2006 de 09/03/2006, e dá outras providências.

**Lei nº. 752/2008 de 14 de fevereiro de 2008.**
{ .centro .revogado .tudo }

“Altera o Art. 1º da [Lei nº 689/2006](../2006/lei-689-2006.md#art-1) de 09/03/2006, e dá outras providências”.
{ .revogado .tudo }

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** O artigo 1º da [Lei nº 689/2006](../2006/lei-689-2006.md#art-1), de 09/03/2006, passa a vigorar com a seguinte redação:
{ #art-1 .revogado }

> “Art. 1º. Fica o Poder Executivo Municipal autorizado a conceder subvenção social à Associação de Pais e Amigos dos Excepcionais – APAE, pessoa jurídica de direito privado sem fins lucrativos, inscrita no CNPJ sob nº 01.239.173/0001-20, com sede à Rua Jair de Abranches Mella, nº 1027, município de Batayporã-MS, no valor de R$ 7.000,00 (sete mil reais) mensais, a partir do mês de fevereiro do corrente ano.”
> { .revogado .tudo }

**Art. 2º** Esta lei entrará em vigor na data de sua publicação e afixação, revogadas as disposições em contrário.
{ #art-2 .revogado }

Prefeitura Municipal de Batayporã-MS, aos catorze dias do mês de fevereiro de 2008.
{ .revogado .tudo }

**Dr. Jercé Eusébio de Souza**
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrado em livro próprio da Secretaria de Administração, Finanças e Planejamento, e afixado em local de costume em data acima citada.
{ .revogado .tudo }

**José Antonio Frutuoso**
{ .centro .revogado .tudo }

Secretário
