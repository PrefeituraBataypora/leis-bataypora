# Lei nº 1068/2014

> Altera o art. 1º da Lei nº 1017/2013 de 11 de julho de 2013, e dá outras providências.

**Lei nº. 1068/2014 de 01 de julho de 2014.**
{ .centro .revogado .tudo }

“Altera o art. 1º da [Lei nº 1017/2013](../2013/lei-1017-2013.md) de 11 de julho de 2013, e dá outras providências”.
{ .revogado .tudo }

**ALBERTO LUIZ SÃOVESSO**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e ele sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** O art. 1º da [Lei nº 1017/2013](../2013/lei-1017-2013.md), de 11 de julho de 2013 passa a vigorar com a seguinte redação:
{ #art-1 .revogado }

> “Art. 1º. Fica o Poder Executivo Municipal autorizado a conceder Subvenção Social no valor de R$ 23.100,00 (vinte e três mil e cem reais) mensais para a SOCIEDADE HOSPITALAR SÃO LUCAS (Entidade Filantrópica, conforme Resolução do Conselho Nacional de Assistência Social nº 156 de 29/09/97), inscrita no CNPJ nº 03.211.935/0001-05, estabelecida à Rua João Antônio da Silva, nº 400, município de Batayporã-MS, a partir do mês de junho de 2014.”
> { .revogado .tudo }

**Art. 2º** Revogam-se as disposições em contrário.
{ #art-2 .revogado }

**Art. 3º** Esta lei entra em vigor na data de sua publicação e/ou afixação, retroagindo seus efeitos a partir de primeiro de junho de 2014.
{ #art-3 .revogado }

Prefeitura Municipal de Batayporã-MS., ao primeiro dia do mês de julho de 2014.
{ .revogado .tudo }

**Alberto Luiz Sãovesso**
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio, publicado e afixado na forma da Lei.
