**LEI Nº-123/89, De 30 de novembro de 1989.**
{ .centro }

Dispõe sobre a contratação de um Advogado para resolver problemas jurídicos da população carente, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS, faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a contratar um Advogado para resolver os problemas jurídicos da população carente e de baixa renda, do Município.
{ #art-1 }

**Art. 2º** - A contratação prevista no artigo anterior, somente poderá ser efetivada com profissional com banca no Município.
{ #art-2 }

**Art. 3º** - Efetivada a contratação, o mesmo só poderá atuar em área de: desquite, divórcio, aposentadoria e pensão alimentícia.
{ #art-3 }

**Art. 4º** - É vedado ao defensor municipal, assumir causas com relação a área criminal.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos trinta dias do mês de novembro de 1989.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }
