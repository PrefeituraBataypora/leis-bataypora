**LEI Nº-114/89, De 21 de julho de 1989.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento salarial aos Servidores Públicos Municipais sobre os seus vencimentos de 40% (quarenta por cento).
{ #art-1 }

**Art. 2º** - Havendo majoração do Piso Nacional de Salários, fica o Poder Executivo autorizado a conceder aumento aos Servidores Públicos até o limite do IPC-Índice de Preço ao Consumidor, do mês anterior, podendo também adotar as normas previstas na Lei nº-7.788, de 03.07.89, do Governo Federal, obedecendo a situação econômica do Município.
{ #art-2 }

Parágrafo Único - Toda vez que for aumentado os salários constantes deste artigo, o Poder Executivo fica obrigado a encaminhar cópia do decreto ao Poder Legislativo, para homologação.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes do orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de julho de 1989.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e um dias do mês de julho de 1989.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
