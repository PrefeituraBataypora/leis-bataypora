**LEI Nº-120/89, De 25 de outubro de 1989.**
{ .centro }

Dispõe sobre abertura de créditos suplementares no Orçamento do Município para o exercício financeiro de 1989, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS, Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido os limites constantes das Leis nº-[101/88](../1988/lei-101-1988.md) e [117/89](lei-117-1989.md), de 30.11.88 e 16.08.89, fica o Poder Executivo autorizado a suplementar mais 40% (quarenta por cento) da despesa orçada.
{ #art-1 }

Parágrafo Único - São recursos para abertura de créditos suplementares constantes neste artigo, os da Lei nº 4.320/64, artigo 43.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e cinco dias do mês de outubro de 1989.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
