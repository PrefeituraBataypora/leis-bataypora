**LEI Nº-105/89, De 17 de janeiro de 1989.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento salarial aos Servidores Públicos Municipais sobre os seus vencimentos de 34.50% (trinta e quatro vírgula cinquenta por cento).
{ #art-1 }

**Art. 2º** - Havendo aumento do Piso Salarial ou Salário Mínimo Referência vigente nesta data, fica o Prefeito Municipal autorizado a decretar reajustes ou reposições salariais no presente exercício, obedecendo a legislação Federal e a situação econômica municipal.
{ #art-2 }

Parágrafo Único - Toda vez que for decretado reajuste ou reposição constantes deste artigo, o Executivo Municipal fica obrigado a encaminhar cópia do Decreto ao Poder Legislativo.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação, retroagindo seus efeitos a partir de 1º de janeiro de 1989.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos dezessete dias do mês de janeiro de 1989.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio do Deptº Geral de Administração e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
