**LEI Nº-112/89, De 28 de junho de 1989.**
{ .centro .revogado .tudo }

Dispõe sobre alteração do Anexo I, da Lei nº-81/87; reajusta salários, e dá outras providências.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS.
{ .revogado .tudo }

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica fixado o valor e alterado as referências e grupos da Lei nº-81/87, que criou a Estrutura Administrativa Básica da Prefeitura, de conformidade com o anexo I.
{ #art-1 .revogado }

**Art. 2º** - Ficam também fixados os vencimentos dos Servidores Municipais, de conformidade com cada referência e nível, constantes dos anexos I, II e III.
{ #art-2 .revogado }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, serão atendidas no decorrente exercício, por conta das dotações próprias consignadas no orçamento vigente.
{ #art-3 .revogado }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de junho de 1989.
{ #art-4 .revogado }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 .revogado }

Prefeitura Municipal de Bataiporã-MS., aos vinte e oito dias do mês de junho de 1989.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
{ .centro .revogado .tudo }
