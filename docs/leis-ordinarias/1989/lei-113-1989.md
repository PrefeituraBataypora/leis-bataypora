**LEI Nº-113/89, De 28 de junho de 1989.**
{ .centro }

Dispõe sobre alteração salarial e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica alterado os salários e vencimentos dos Servidores da Câmara Municipal de Bataiporã-MS., em conformidade com o anexo único da presente Lei.
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de junho de 1989.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e oito dias do mês de junho de 1989.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
