**LEI Nº-109/89, De 03 de maio de 1989.**
{ .centro }

Dispõe sobre Subvenção Social, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a conceder Subvenção Social no valor de 01 (um) Piso Nacional de Salário mensal, à APAE-Associação de Pais e Amigos dos Excepcionais de Nova Andradina.
{ #art-1 }

**Art. 2º** - A Associação beneficiada constante do artigo 1º, fica obrigada a prestar contas de conformidade com as normas do Tribunal de Contas Estadual, à Contabilidade Municipal.
{ #art-2 }

**Art. 3º** - A contribuição concedida pelo artigo 1º, será paga de 1 a 15 do mês subsequente ao seu vencimento.
{ #art-3 }

**Art. 4º** - As despesas decorrentes da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de abril de 1989.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Bataiporã-MS, aos três dias do mês de maio de 1989.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
