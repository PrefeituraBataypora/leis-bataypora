**LEI Nº-110/89, De 24 de maio de 1989.**
{ .centro .revogado .tudo }

Dispõe sobre aquisição e doação de imóveis, e dá outras providências.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Bataiporã-MS.
{ .revogado .tudo }

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir imóvel rural com área até 4,84ha no valor até NCZ$-12.000,00 (doze mil cruzados novos).
{ #art-1 .revogado }

**Art. 2º** - Adquirido o imóvel na forma do artigo anterior, fica também autorizado a efetuar a doação de até 4,84ha, para o empresário interessado em construir e instalar granja de suinicultura e frigorífico de seus derivados.
{ #art-2 .revogado }

Parágrafo Único - O prazo para a construção será de 12 (doze) meses, com 06 (seis) de carência, a partir da aprovação da presente Lei.
{ .revogado .tudo }

**Art. 3º** - Não cumpridas as exigências do artigo 2º e seu parágrafo único, retornará ao domínio do município o imóvel doado.
{ #art-3 .revogado }

Parágrafo Único - O não funcionamento das atividades constantes do Art. 2º da presente Lei, retornará ao domínio do Município o imóvel objeto de doação.
{ .revogado .tudo }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de doações orçamentárias constantes no orçamento em vigor.
{ #art-4 .revogado }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 .revogado }

Prefeitura Municipal de Bataiporã-MS., aos vinte e quatro dias do mês de maio de 1989.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração e afixado em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
