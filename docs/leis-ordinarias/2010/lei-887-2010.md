# Lei nº 887/2010

> Altera o Art. 2º da Lei nº 709/2006, de 28/09/2006, com alterações introduzidas pela Lei nº 717/2006, de 06/12/2006, e dá outras providências.

**Lei nº. 887/2010 de 15 de dezembro de 2010.**
{ .centro .revogado .tudo }

“Altera o Art. 2º da Lei nº 709/2006, de 28/09/2006, com alterações introduzidas pela Lei nº 717/2006, de 06/12/2006, e dá outras providências”.
{ .revogado .tudo }

**EDSON PERES IBRAHIM**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** O [artigo 2º da Lei nº 709/2006](../2006/lei-709-2006.md#art-2), de 28 de setembro de 2006, passa a vigorar com a seguinte redação:
{ #art-1 .revogado }

> “Art. 2º. O beneficiado pelo artigo anterior fica assegurado o prazo de até 30 de junho de 2011 para o inicio da construção e instalação da Clinica Médica e Residência.”
{ .revogado .tudo }

**Art. 2º** Revogam-se as disposições em contrário.
{ #art-2 .revogado }

**Art. 3º** Esta lei entra em vigor na data de sua publicação e/ou afixação, retroagindo seus efeitos a 28 de setembro de 2006.
{ #art-3 .revogado }

Prefeitura Municipal de Batayporã-MS., aos quinze dias dos mês de dezembro de 2010.
{ .revogado .tudo }

**Edson Peres Ibrahim**
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrado em livro próprio da Secretaria de Administração, Finanças e Planejamento, e afixado em local de costume em data acima citada.
