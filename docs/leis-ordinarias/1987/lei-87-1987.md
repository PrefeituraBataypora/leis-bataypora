**LEI Nº-87/87, De 28 de outubro de 1987.**
{ .centro }

Incorpora ao Calendário de festividades do Município, a FESTA DO HORIZONTE, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica incorporado ao Calendário de festividades do Município de Bataiporã-MS., a **FESTA DO HORIZONTE**.
{ #art-1 }

**Art. 2º** - A Festa do Horizonte será realizada no segundo domingo do mês de setembro, nos mesmos moldes ocorridos nas versões anteriores.
{ #art-2 }

**Art. 3º** - Para a Festa do Horizonte será instituída uma Comissão, sob a Presidência da Primeira Dama do Município, composta de 3 à 5 membros, que ficará responsável pela organização e promoção do referido evento.
{ #art-3 }

**Art. 4º** - Fica o Poder Executivo Municipal, autorizado a oferecer apoio administrativo e financeiro, para a realização do referido evento.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e oito dias do mês de outubro de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
