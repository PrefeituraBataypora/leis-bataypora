**LEI Nº-89/87, De 11 de novembro de 1987.**
{ .centro }

Dispõe sobre auxílio para Casa do Albergado desta Comarca e dá outras previdências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a conceder um auxílio de Cz$-15.000,00 (quinze mil cruzados) para construção da Casa do Albergado da Comarca de Nova Andradina-MS.
{ #art-1 }

Parágrafo Único - O auxílio constante deste artigo será pago para a entidade responsável pela construção da obra.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos onze dias do mês de novembro de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
