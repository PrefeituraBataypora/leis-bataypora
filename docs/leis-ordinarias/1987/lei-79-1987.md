**LEI Nº-79/87, De 31 de março de 1987.**
{ .centro }

Dispõe sobre realinhamento salarial dos Servidores Públicos Municipais, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica fixado os vencimentos dos Servidores Públicos Municipais, de conformidade com o [anexo I](#anexo-i).
{ #art-1 }

**Art. 2º** - Fica reajustado em 20% (vinte por cento) os vencimentos dos Servidores regidos pelo Estatuto do Magistério Público Municipal.
{ #art-2 }

**Art. 3º** - Fica concedido uma gratificação de insalubridade de 10% (dez por cento) sobre os vencimentos dos Servidores que desempenham a função de:
{ #art-3 }

a. Médico-Veterinário;

b. Coleta de Lixo;

c. Lavador de Veículos;

d. Serviços no Abatedouro Municipal;

e. Auxiliar de Campo;

f. Coveiro.

**Art. 4º** - Havendo aumento do salário mínimo vigente nesta data, fica o Prefeito Municipal autorizado a decretar reajustes salariais no presente exercício, obedecido a legislação legal e a situação econômica municipal.
{ #art-4 }

Parágrafo Único - Toda vez que for decretado reajuste constante deste artigo, o Executivo Municipal fica obrigado a encaminhar cópia do Decreto ao Poder Legislativo.

**Art. 5º** - As despesas decorrentes com a execução da presente Lei correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-5 }

**Art. 6º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de março do corrente ano.
{ #art-6 }

**Art. 7º** - Revogam-se as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Bataiporã-MS, aos trinta e um dias do mês de março de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }
