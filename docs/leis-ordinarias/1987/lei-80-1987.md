**LEI Nº-80/87, De 31 de março de 1987.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores da Câmara Municipal, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento salarial aos servidores da Câmara Municipal de Bataiporã-MS., sobre seus vencimentos, na ordem de 40% (quarenta por cento).
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de março de 1987.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos trinta e um dias do mês de março de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
