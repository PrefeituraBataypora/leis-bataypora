TÍTULO I11 DOS VENCIMENTOS E VANTAGENS

**Art. 17.** Ficam fixados os vencimentos dos Servidores Municipais, de conformidade com cada referência e nível constante do anexo I, I1 e 111.
{ #art-17 }

**Art. 18.** Ficam assegurados aos Servidores, todas as vantagens constantes na Legislaçao Municipal.
{ #art-18 }

**Art. 19.** Fica o Poder Executivo autorizado a conceder função gratificada ate 40% (quarenta por cento) sobre o vencimento do Servidor, de acordo com o Organograma de Administraçao.
{ #art-19 }

**Art. 20.** As despesas decorrentes com a execução da ' presente Lei, serao atendidas no corrente exercício per conta das dotaçoes proprias consignadas no orçamento vigente.
{ #art-20 }
