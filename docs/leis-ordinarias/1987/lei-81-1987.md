**LEI Nº-81/87, De 01 de julho de 1987.**
{ .centro }

Dispõe sobre a Estrutura Administrativa e criação de cargos ou funções da Prefeitura Municipal de Bataiporã-MS, nos termos do artigo 89, ítem XXXII, da Lei Complementar nº-7, de 20.11.81, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

## TÍTULO I — DA ESTRUTURA ADMINISTRATIVA { .centro }

**Art. 1º** - Fica criada a Estrutura Administrativa Básica da Prefeitura, compondo-se dos seguintes órgãos:
{ #art-1 }

I - Gabinete do Prefeito;

II - Departamento Geral de Administração;

III - Departamento Pessoal;

IV - Departamento de Contabilidade;

V - Departamento de Finanças;

VI - Departamento de Almoxarifado;

VII - Departamento de Educação e Cultura;

VIII - Departamento Social e Saúde;

IX - Departamento Rodoviário;

X - Departamento de Obras e Serviços Urbanos

## TÍTULO II — DOS CARGOS OU FUNÇÕES { .centro }

{ #art-2 }

I-a, 01 (um) Motorista de veículo pequeno.

**Art. 12** - Os cargos ou funções criados pela presente Lei, serão providos mediante livre escolha do Prefeito, por Servidores ou não que satisfaçam as qualificações exigidas para sua investidura.
{ #art-12 }

Parágrafo Único - O pessoal contratado não concursado, obedecerão o disposto na C.L.T. (Consolidação das Leis do Trabalho) e os concursados, os Estatutos do Servidor Público e Magistério Público Municipal.

**Art. 13** - A contratação do pessoal na forma prevista no artigo anterior e seu parágrafo único, só poderá ser feita quando existir dotação orçamentária que permita a cobertura das despesas.
{ #art-13 }

**Art. 14** - As atribuições inerentes aos cargos ou funções ora criados, deverão ser regulamentados se necessário for, por Decreto Municipal.
{ #art-14 }

**Art. 15** - No prazo de 90 (noventa) dias, o Prefeito fixará por Portaria, os cargos ou funções correspondentes à presente Lei, sem prejuízos ou vantagens aos Servidores Municipais.
{ #art-15 }

Parágrafo Único - O pessoal contratado que coincidir com a lotação, não haverá necessidade de fixação de nova Portaria.

**Art. 16** - O Prefeito poderá transferir ou designar, os Servidores para outros cargos ou funções, de conformidade com as necessidades administrativas.
{ #art-16 }

## TÍTULO III — DOS VENCIMENTOS E VANTAGENS { .centro }

**Art. 17** - Ficam fixados os vencimentos dos Servidores Municipais, de conformidade com cada referência e nível constante do anexo I, II e III.
{ #art-17 }

**Art. 18** - Ficam assegurados aos Servidores, todas as vantagens constantes na Legislação Municipal.
{ #art-18 }

**Art. 19** - Fica o Poder Executivo autorizado a conceder função gratificada até 40% (quarenta por cento) sobre o vencimento do Servidor, de acordo com o Organograma de Administração.
{ #art-19 }

## TÍTULO IV — DAS DISPOSIÇÕES FINAIS { .centro }

**Art. 20** - As despesas decorrentes com a execução da presente Lei, serão atendidas no corrente exercício por conta das dotações próprias consignadas no orçamento vigente.
{ #art-20 }

**Art. 21** - Esta Lei entrará em vigor a partir de primeiro de julho de 1987, revogadas as disposições em contrário.
{ #art-21 }

Prefeitura Municipal de Bataiporã-MS, ao primeiro dia do mês de julho de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }
