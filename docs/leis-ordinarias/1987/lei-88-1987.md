**LEI Nº-88/87, De 28 de outubro de 1987.**
{ .centro }

Dispõe sobre a abertura de créditos suplementares no orçamento do Município para o exercício financeiro de 1987, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido os limites constantes da Lei Orçamentária [nº-74/86, de 27.11.86](../1986/lei-74-1986.md), art. 4º, ítem II, e da [Lei nº-83/87, de 12.08.87](lei-83-1987.md), fica o Poder Executivo autorizado a suplementar mais 30% (trinta por cento) da despesa orçada.
{ #art-1 }

Parágrafo Único - São recursos para abertura de créditos suplementares, os constantes do artigo 43, da Lei nº-4.320/64, de 17.03.64.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e oito dias do mês de outubro de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
