**LEI Nº-85/87, De 07 de outubro de 1987.**
{ .centro }

Dispõe sobre declaração de utilidade pública da SOCIEDADE HOSPITALAR SÃO LUCAS, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica declarado de utilidade pública para todos os efeitos legais a "SOCIEDADE HOSPITALAR SÃO LUCAS" entidade de caráter beneficente de assistência social e a saúde, com séde à Rua Jair de Abranches Mella, nº-1.072, nesta cidade.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-2 }

Prefeitura Municipal de Bataiporã-MS, aos sete dias do mês de outubro de 1987.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
