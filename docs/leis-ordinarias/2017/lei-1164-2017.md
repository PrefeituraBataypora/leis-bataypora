**Lei nº. 1.164/2017 de 20 de dezembro de 2017.**
{ .centro }

“Altera o artigo 2º da [Lei nº 709/2006](../2006/lei-709-2006.md#art-2), de 28 de setembro de 2006, e dá outras providências”.

**JORGE LUIZ TAKAHASHI, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL**, no uso e gozo de suas atribuições legais, conforme artigo 26 da Lei Orgânica do Município.

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:

**Art. 1º** O artigo 2º da [Lei nº 709/2006](../2006/lei-709-2006.md#art-2), de 28 de setembro de 2006, passa a vigorar com a seguinte redação:
{ #art-1 }

> “Art. 2º. O beneficiado pelo artigo anterior fica assegurado o prazo de até 30 de novembro de 2019 para a conclusão da construção das obras de instalação da Clinica Médica e residência, com o prazo de até 31 de dezembro de 2017 para o início das construções.”

**Art. 2º** Revogam-se as disposições em contrário.
{ #art-2 }

**Art. 3º** Esta lei entrará em vigor na data de sua publicação, e/ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Batayporã-MS, 20 de dezembro de 2017.

**Jorge Luiz Takahashi**
{ .centro }

Prefeito Municipal
{ .centro }

Publicado e afixado na forma da Lei.

**Dilmo Mathias Teixeira**
{ .centro }
