**Lei nº 994/2012 de 05 de dezembro de 2012.**
{ .centro .revogado .tudo }

“Dispõe sobre a criação, composição e funcionamento do Conselho Municipal de Educação do município de Batayporã-MS, e dá outras providências”.
{ .revogado .tudo }

**EDSON PERES IBRAHIM**, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso e gozo de suas atribuições legais;
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Fica Criado o **Conselho Municipal de Educação – CME**, do município de Batayporã-MS .
{ #art-1 .revogado }

**Art. 2º** O **Conselho Municipal de Educação – CME**, exercerá funções consultiva, deliberativa e normativa, conforme legislação federal, estadual e municipal e seu regimento será aprovado pela Secretaria Municipal de Educação, no prazo de 60 (sessenta) dias de sua implantação.
{ #art-2 .revogado }

**Art. 3º** O **Conselho Municipal de Educação – CME** será constituído por 08 (oito) membros titulares e os seus respectivos suplentes, nomeados por decreto do Prefeito Municipal,
{ #art-3 .revogado }

§ 1º Na composição do Conselho deverá garantir a participação de:
{ .revogado .tudo }

a) 02 (dois) representantes da Secretaria Municipal de Educação;
{ .revogado .tudo }

b) 01 representante da educação infantil do ensino público municipal;
{ .revogado .tudo }

c) 01 representante do ensino fundamental público municipal;
{ .revogado .tudo }

d) 01 representante da educação especial do ensino público municipal;
{ .revogado .tudo }

e) 01 representante da entidade classista dos professores público municipal;
{ .revogado .tudo }

f) 01 representante do Conselho Municipal dos Direitos da Criança e do Adolescente. – CMDCA
{ .revogado .tudo }

§ 2º Ao ser constituído o Conselho, 1/3(um terço) de seus membros terá mandato de 02 anos e 2/3(dois terços) de 04 anos, após o que, bienal e alternadamente haverá renovação dos mandatos.
{ .revogado .tudo }

§ 3º Para os fins do disposto no parágrafo anterior, na primeira composição do Conselho, o Chefe do Poder Executivo ao nomear os conselheiros atribuirá à respectiva duração dos mandatos, atendendo a conveniência administrativa, respeitada a representatividade prevista nesta Lei.
{ .revogado .tudo }

§ 4º Havendo vaga no Conselho, será nomeado um substituto para completar o mandato do antecessor.
{ .revogado .tudo }

§ 5º Na renovação do Conselho, será permitido apenas uma recondução de seus membros titulares e suplentes.
{ .revogado .tudo }

§ 6º O membro suplente será convocado para substituir o titular quando de sua falta ou impedimento.
{ .revogado .tudo }

**Art. 4º** Os Conselheiros exercem funções consideradas de interesse público relevante, com prioridade sobre o de quaisquer cargos público de que sejam titulares.
{ #art-4 .revogado }

§ 1º Na primeira investidura do Conselho, os Conselheiros serão empossados pelo Prefeito.
{ .revogado .tudo }

§ 2º O Presidente e o Vice Presidente serão eleitos dentre seus pares para o cumprimento de mandato de 02 (dois) anos, permitida uma recondução.
{ .revogado .tudo }

§ 3º A primeira sessão será exercida sob a Presidência do Conselheiro, representando a Secretaria Municipal de Educação e Cultura.
{ .revogado .tudo }

§ 4º A primeira sessão plenária será instalada com a presença de 2/3 dos membros do Colegiado para conduzir o processo eletivo para escolha do Presidente e Vice Presidente.
{ .revogado .tudo }

§ 5º Os Conselheiros serão empossados pelo Presidente do Conselho na primeira sessão em seguida à nomeação, respeitado o disposto do parágrafo 1º deste artigo.
{ .revogado .tudo }

**Art. 5º** No exercício de suas funções consultiva, deliberativa e normativa, o Conselho Municipal de Educação do Município de Batayporã, tem por finalidade supervisionar o processo de desenvolvimento da educação no Município, em consonância com as diretrizes e planos nacionais de educação, bem como autorizar, credenciar e supervisionar os estabelecimentos de ensino público e privado do sistema municipal de ensino.
{ #art-5 .revogado }

Parágrafo único. As competências do Conselho serão estabelecidas em Regimento próprio, aprovado na conformidade do artigo 2º desta Lei, o qual obedecerá as normas e procedimentos definidos em ato do Poder Executivo.
{ .revogado .tudo }

**Art. 6º** O número máximo de reuniões será de o limite máximo de 04 (quatro) sessões mensais.
{ #art-6 .revogado }

**Art. 7º** Os Conselheiros receberão “jeton” de presença por sessão a que comparecerem, bem como transporte e diárias em caso de deslocamento de Batayporã, a fim de participar de trabalhos de interesse do Conselho.
{ #art-7 .revogado }

Parágrafo único. Os valores dos “jetons” e diárias serão estabelecidos em ato do Poder Executivo.
{ .revogado .tudo }

**Art. 8º** A manutenção do Conselho Municipal de Educação correrá à conta de dotações orçamentárias da Secretaria Municipal de Educação e Cultura, mediante aprovação do (a) Secretário (a) Municipal de Educação e Cultura.
{ #art-8 .revogado }

**Art. 9º** Esta lei entrará em vigor na data de sua publicação e/ou afixação, revogadas as disposições em contrário.
{ #art-9 .revogado }

Prefeitura Municipal de Batayporã-MS, aos cinco dias do mês de dezembro de 2012.
{ .revogado .tudo }
