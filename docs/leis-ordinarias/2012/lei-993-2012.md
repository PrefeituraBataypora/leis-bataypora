> Dispõe sobre a criação do Sistema Municipal de Ensino, e dá outras providências.

**Lei nº.993/2012 de 05 de dezembro de 2012.**
{ .centro .revogado .tudo }

“Dispõe sobre a criação do Sistema Municipal de Ensino, e dá outras providências”.
{ .revogado .tudo }

**EDSON PERES IBRAHIM**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Fica criado o **Sistema Municipal de Ensino no Município de Batayporã/MS**, conforme dispõe a Constituição Federal em seu art.211, a Lei de Diretrizes e Base da Educação Nacional nº 9.394, de 20 de dezembro de 1996.
{ #art-1 .revogado }

**Art. 2º** O **Sistema Municipal de Ensino de Batayporã/MS** tem por objetivo promover melhorias no âmbito educacional, orientar, coordenar e controlar a operacionalização de todas as atividades relacionadas ao ensino no Município, em consonância com as diretrizes da legislação vigente e plano de ação do gestor municipal, garantindo o desenvolvimento pleno do educando, e o preparo para o exercício da cidadania.
{ #art-2 .revogado }

**Art. 3º** O **Sistema Municipal de Ensino** será composto da seguinte forma:
{ #art-3 .revogado }

I - Órgão Central;
{ .revogado .tudo }

a) Secretaria Municipal de Educação e Cultura;
{ .revogado .tudo }

II - Órgão Colegiado
{ .revogado .tudo }

a) Conselho Municipal de Educação;
{ .revogado .tudo }

b) Conselho Municipal de Acompanhamento e Controle Social do Fundo de Manutenção e Desenvolvimento da Educação Básica e de Valorização dos Profissionais de Educação – FUNDEB;
{ .revogado .tudo }

c) As instituições de Ensino Fundamental e Educação Infantil públicas e privadas;
{ .revogado .tudo }

d) Outros órgãos e serviços municipais da área educacional de caráter administrativo e de apoio técnico.
{ .revogado .tudo }

**Art. 4º** A educação dever da família e do poder público, inspirada nos princípios de liberdade e nos ideais de solidariedade humana, tem por finalidade o pleno desenvolvimento do educando, com vistas ao exercício da cidadania e sua preparação para o trabalho.
{ #art-4 .revogado }

**Art. 5º** O acesso ao ensino fundamental é direito público subjetivo, podendo qualquer cidadão, grupo de cidadãos, associação comunitária, organização sindical, entidade de classe ou instituição legalmente constituída, acionar o Poder Público para exigi-lo.
{ #art-5 .revogado }

**Art. 6º** O regime de colaboração com o Estado e a União, deverá:
{ #art-6 .revogado }

I - recensear a população em idade escolar da educação infantil, ensino fundamental e educação de jovens e adultos;
{ .revogado .tudo }

II - efetuar chamada pública.
{ .revogado .tudo }

**Art. 7º** É dever dos pais ou responsáveis, efetuar a matrícula de seus filhos a partir de quatro anos na educação infantil e dos seis, no ensino fundamental.
{ #art-7 .revogado }

**Art. 8º** A educação escolar no Sistema Municipal de Ensino terá por base, os seguintes princípios:
{ #art-8 .revogado }

I - igualdade de condições para o acesso e permanência na escola;
{ .revogado .tudo }

II - liberdade de aprender, ensinar, pesquisar e divulgar o pensamento, a arte e o saber;
{ .revogado .tudo }

III - pluralismo de ideias e de concepções pedagógicas e coexistência de instituições públicas e privadas de ensino;
{ .revogado .tudo }

IV - gratuidade do ensino público;
{ .revogado .tudo }

V - valorização dos profissionais da educação escolar, garantidos, na forma da Lei, plano de cargo e carreira, com ingresso exclusivamente por concurso público de provas e títulos aos da rede municipal de ensino;
{ .revogado .tudo }

VI - gestão democrática do ensino público, em conformidade com a legislação vigente;
{ .revogado .tudo }

VII - garantia de padrão de qualidade;
{ .revogado .tudo }

IX - promoção da interação escola e organizações da sociedade civil;
{ .revogado .tudo }

X - promoção da justiça social, da igualdade e da solidariedade;
{ .revogado .tudo }

XI - respeito à liberdade, aos valores, à diversidade, às características e capacidades individuais, apreço à tolerância estimula e propagação dos valores coletivos, comunitários e defesa dos bens públicos;
{ .revogado .tudo }

XII - expansão das oportunidades educacionais em todos os níveis e modalidades de ensino e do período de permanência do aluno nas instituições oficiais;
{ .revogado .tudo }

XIII - vinculação da educação escolar ao mundo do trabalho e à prática social, valorizando e preservando a cultura local;
{ .revogado .tudo }

XIV - garantia da educação básica a toda criança e adolescente do município;
{ .revogado .tudo }

**Art. 9º** As instituições de ensino dos diferentes níveis classificam-se em públicas e privadas:
{ #art-9 .revogado }

I - públicas, as criadas ou incorporadas, mantidas e administradas pelo Poder Público;
{ .revogado .tudo }

II - privadas, as mantidas e administradas por pessoas físicas ou jurídicas de direito privado, sendo enquadradas na forma da Lei como: particulares, comunitárias, confessionais ou filantrópicas;
{ .revogado .tudo }

**Art. 10.** O oferecimento da Educação Infantil é livre à iniciativa privada, condicionado o seu funcionamento ao atendimento às normas gerais da educação nacional, estadual e municipal.
{ #art-10 .revogado }

**Art. 11.** As instituições de ensino, respeitadas as normas comuns, terão a incumbência de:
{ #art-11 .revogado }

I - elaborar e executar sua proposta pedagógica:
{ .revogado .tudo }

II - administrar seu pessoal e seus recursos materiais e financeiros:
{ .revogado .tudo }

III - assegurar o cumprimento dos dias letivos e horas-aula estabelecidas:
{ .revogado .tudo }

IV - velar pelo cumprimento de trabalho de cada docente
{ .revogado .tudo }

V - prover meios para recuperação da aprendizagem dos alunos de menor rendimento;
{ .revogado .tudo }

VI - articular-se com as famílias e a comunidade, criando processos de integração da sociedade com a escola:
{ .revogado .tudo }

VII - informar os pais e responsáveis sobre a frequência e o rendimento dos alunos, bem como sobre a execução de suas propostas pedagógica:
{ .revogado .tudo }

VIII - notificar ao Conselho Tutelar do Município, ao juiz competente da Comarca e ao respectivo representante do Ministério Público a relação dos alunos que apresentem quantidade de faltas acima de 50% (cinquenta por cento) do percentual permitido por Lei.
{ .revogado .tudo }

**Art. 12.** O dever do Poder Público Municipal com a educação será efetivado por meio do órgão municipal competente, mediante a garantia de:
{ #art-12 .revogado }

I - ensino fundamental, prioridade do município, obrigatório e gratuito, assegurada, inclusive, sua oferta gratuita para todos os que a ele não tiverem acesso na idade própria:
{ .revogado .tudo }

II - oferta de educação infantil para crianças à partir do 4 (quatro) anos de idade e das séries iniciais do ensino fundamental para crianças à partir dos 6 (seis) anos de idade.
{ .revogado .tudo }

III - atendimento educacional especializado aos alunos com necessidades específicas, deficiência, transtornos globais do desenvolvimento e altas habilidades/superdotação, preferencialmente no ensino regular;
{ .revogado .tudo }

IV - oferta de educação escolar para jovens e adultos, com características e modalidades adequadas às suas necessidades, garantindo condições de acesso e permanência;
{ .revogado .tudo }

V - oferta adequada da educação infantil e séries iniciais do ensino fundamental, para a população do campo;
{ .revogado .tudo }

VI - ampliação progressiva do período de permanência na escola, na educação infantil e no ensino fundamental, com a oferta de atividades culturais, esportivas e de formação para o exercício da cidadania;
{ .revogado .tudo }

VII - quadro de profissionais da educação, em número suficiente e permanentemente qualificado, para atender à demanda escolar, possibilitando a todos acesso à formação continuada;
{ .revogado .tudo }

VIII - viabilização de ações com vista à erradicação ou a diminuição dos índices de analfabetismo no Município;
{ .revogado .tudo }

IX - atendimento ao educando, no ensino fundamental, por meio de projetos suplementares de material didático escolar, uniforme, transporte, alimentação e assistência à saúde;
{ .revogado .tudo }

X - implantação do Sistema Municipal de Avaliação Educacional;
{ .revogado .tudo }

XI - manutenção de cadastro atualizado de todas as instituições de ensino público e privado que atuam no município;
{ .revogado .tudo }

XII - coordenação, acompanhamento e supervisão das instituições de ensino de seu sistema de ensino;
{ .revogado .tudo }

IX - administração, acompanhamento e avaliação das ações de sua própria rede;
{ .revogado .tudo }

X - coordenação da elaboração, acompanhamento e avaliação do Plano Municipal de Educação;
{ .revogado .tudo }

XI - integração de todas as instituições de ensino fundamental ao Sistema de Avaliação do Rendimento Escolar;
{ .revogado .tudo }

XII - ação redistributiva em relação às escolas do Sistema Municipal de Ensino.
{ .revogado .tudo }

**Art. 13.** São objetivos do Sistema Municipal de Ensino:
{ #art-13 .revogado }

I - definir normas de gestão democrática para o ensino público municipal, conforme normas vigentes:
{ .revogado .tudo }

II - assegurar progressivo grau de autonomia pedagógica, administrativa e de gestão financeira às instituições de ensino públicas de educação básica que o integram;
{ .revogado .tudo }

III - buscar articulações e parcerias com outros sistemas para atender às necessidades do Município que extrapolem sua área de competência;
{ .revogado .tudo }

IV - integrar seus órgãos e instituições de ensino às políticas e planos educacionais da União e do Estado;
{ .revogado .tudo }

V - alcançar relação adequada entre o número de alunos e de professor, a carga horária e as condições materiais da instituição de ensino.
{ .revogado .tudo }

Parágrafo único. Cabe ao Sistema Municipal de Ensino, verificar as condições disponíveis, as características regionais e locais e estabelecer parâmetros para o atendimento do disposto neste artigo.
{ .revogado .tudo }

**Art. 14.** O Conselho Municipal de Educação, órgão consultivo, deliberativo e normativo do Sistema Municipal de Ensino, é regido por norma própria e, tem as seguintes competências:
{ #art-14 .revogado }

I - participar da discussão e definição da política municipal de educação;
{ .revogado .tudo }

II - participar do processo de elaboração, acompanhamento e avaliação do Plano Municipal de Educação;
{ .revogado .tudo }

III - pronunciar se previamente quanto à execução de planos, programas, projetos e experiências pedagógicas na área da educação municipal;
{ .revogado .tudo }

IV - acompanhar e controlar a aplicação dos recursos públicos destinados à educação municipal;
{ .revogado .tudo }

V - promover sindicâncias nas instituições de ensino sob sua jurisdição;
{ .revogado .tudo }

VI - dispor sobre seu regimento interno e submetê-lo à homologação do Secretário Municipal de Educação e Cultura;
{ .revogado .tudo }

VII - apresentar ao Secretario Municipal de Educação e Cultura planejamento financeiro para compor o orçamento da pasta;
{ .revogado .tudo }

VIII - baixar normas complementares para o Sistema Municipal de Ensino;
{ .revogado .tudo }

IX - autorizar, credenciar e supervisionar as instituições de ensino do Sistema Municipal de Ensino.
{ .revogado .tudo }

**Art. 15.** O Sistema Municipal de Ensino, em articulação com os demais sistemas de ensino que atuam no Município, definirá formas de colaboração entre si, de modo a assegurar.
{ #art-15 .revogado }

I - erradicação do analfabetismo;
{ .revogado .tudo }

II - universalização do atendimento escolar;
{ .revogado .tudo }

III - melhoria da qualidade do ensino;
{ .revogado .tudo }

IV - formação para o trabalho;
{ .revogado .tudo }

V - promoção humanística cientifica e tecnológica do município;
{ .revogado .tudo }

**Art. 16.** A educação escolar, no Sistema Municipal de Ensino, consiste na educação básica, que tem como finalidade desenvolver o educando, assegurar-lhe a formação comum, indispensável para o exercício da cidadania e fornecer lhe meios para progredir no trabalho e em estudos posteriores.
{ #art-16 .revogado }

Parágrafo único. A educação básica é formada pela educação infantil e séries iniciais do ensino fundamental.
{ .revogado .tudo }

**Art. 17.** A educação infantil será oferecida em:
{ #art-17 .revogado }

I - creches ou entidades equivalentes, para crianças de 0(zero) a 3(três) anos de idade;
{ .revogado .tudo }

II - pré-escolas, para crianças de 4(quatro) a 6(seis) anos de idade.
{ .revogado .tudo }

**Art. 18.** O ensino fundamental obrigatório a partir de 6(seis) anos de idade, com duração de 9(nove) anos será gratuito na escola pública, tem por objetivo a formação básica do cidadão.
{ #art-18 .revogado }

**Art. 19.** Na educação básica, deverá ser previsto o oferecimento das modalidades de ensino na forma da lei;
{ #art-19 .revogado }

I - Educação de Jovens e Adultos, destinada àqueles que não tiveram acesso ou continuidade de estudos no ensino fundamental na idade própria;
{ .revogado .tudo }

II - Educação Especial oferecida preferencialmente, nas escolas da rede, em sala comum para alunos com necessidades específicas, deficiência, transtornos globais do desenvolvimento e altas habilidades/superdotação;
{ .revogado .tudo }

III - Educação a distância, oferecida por instituições especializadas, credenciadas pelo órgão competente, organizada com abertura e regimes especiais, devendo o Poder Público incentivar o desenvolvimento e a veiculação de programas de ensino a distância e de educação continuada.
{ .revogado .tudo }

**Art. 20.** O aluno matriculado ou egresso do ensino fundamental, médio e superior, bem como o trabalhador em geral, jovem e adulto, contará com a possibilidade de acesso à educação profissional, que deverá desenvolver-se de maneira articulada às diferentes formas de educação, ao trabalho, à ciência e à tecnologia, conduzindo ao permanente desenvolvimento de aptidões para a vida produtiva.
{ #art-20 .revogado }

**Art. 21.** A oferta da educação básica à população do campo deverá promover as adaptações necessárias às peculiaridades locais e regionais, no que se refere a conteúdos curriculares, metodologias, organização escolar, calendário escolar e adequado à natureza do trabalho na zona rural.
{ #art-21 .revogado }

**Art. 22.** Para atuar na educação básica exigir-se-á do docente a formação em nível superior de licenciatura plena observando-se a respectiva habilitação.
{ #art-22 .revogado }

**Art. 23.** A valorização dos profissionais da educação pública será assegurada por meio de:
{ #art-23 .revogado }

I - ingresso exclusivamente por concurso.
{ .revogado .tudo }

II - aperfeiçoamento profissional continuado em instituições oficiais, com possibilidade de licenciamento periódico remunerado para cursos em nível de especialização e cursos de qualificação profissional;
{ .revogado .tudo }

III - piso salarial profissional;
{ .revogado .tudo }

IV - progressão funcional baseada na habilitação, na titulação e na avaliação de desempenho;
{ .revogado .tudo }

V - período reservado a estudos, planejamento e avaliação, incluído na carga de trabalho;
{ .revogado .tudo }

VI - condições adequadas de trabalho;
{ .revogado .tudo }

VII - remuneração condigna, conforme a titulação.
{ .revogado .tudo }

**Art. 24.** Serão recursos públicos destinados à educação os originários de:
{ #art-24 .revogado }

I - impostos próprios;
{ .revogado .tudo }

II - receita de transferências constitucionais e outras transferências:
{ .revogado .tudo }

III - receita do salário educação e de outras contribuições sociais;
{ .revogado .tudo }

IV - receita de incentivos fiscais;
{ .revogado .tudo }

V - outros recursos previstos em Lei.
{ .revogado .tudo }

**Art. 25.** O Município aplicará anualmente nunca menos de 25%, no mínimo da receita resultante de impostos, compreendida proveniente de transferências constitucionais previstas em Lei.
{ #art-25 .revogado }

**Art. 26.** Considerar-se-ão como de manutenção e desenvolvimento de ensino as despesas realizadas com vista à consecução dos objetivos básicos das instituições educacionais públicas que oferecem educação básica e suas modalidades, compreendendo as que se destina a
{ #art-26 .revogado }

I - remuneração e aperfeiçoamento de pessoal docente e demais profissionais da educação;
{ .revogado .tudo }

II - aquisição, manutenção, construção e conservação de instalações e equipamentos necessários ao ensino;
{ .revogado .tudo }

III - uso e manutenção de bens e serviços vinculados ao ensino;
{ .revogado .tudo }

IV - levantamento estatísticos, estudos e pesquisas visando precipuamente ao aprimoramento da qualidade e à expansão do ensino;
{ .revogado .tudo }

V - amortização e custeio de operações de crédito destinadas a atender ao disposto nos incisos deste artigo;
{ .revogado .tudo }

VI - aquisição de material didático-escolar e manutenção de programas de transporte escolar e uniforme;
{ .revogado .tudo }

**Art. 27.** As instituições de ensino públicas e privadas vinculadas ao Sistema Municipal de Ensino adaptarão seus estatutos, regimentos, regulamentos e atos normativos dele recorrentes ao disposto nesta Lei.
{ #art-27 .revogado }

**Art. 29.** O Poder Executivo regulamentará as disposições desta Lei, no que couber no prazo de 90(noventa) dias, após a publicação oficial.
{ #art-29 .revogado }

**Art. 30.** Esta lei entrará em vigor na data de sua publicação e/ou afixação, revogadas as disposições em contrário.
{ #art-30 .revogado }

Prefeitura Municipal de Batayporã-MS, aos cinco dias do mês de dezembro de 2012.
