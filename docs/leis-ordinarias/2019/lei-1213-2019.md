**Lei nº. 1.213/2019 de 11 de setembro de 2019.**
{ .centro .revogado .tudo }

“Regulamenta os procedimentos de regularização fundiária urbana por falta de título hábil para registro, e dá outras providencias”.
{ .revogado .tudo }

O PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo das atribuições que lhe conferem a Lei Orgânica Municipal, e
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e ele sanciona e promulga a seguinte lei:
{ .revogado .tudo }

## TÍTULO I — PARTE GERAL { .centro .revogado }

### CAPÍTULO I — DO PROGRAMA HABITACIONAL { .centro .revogado }

**Art. 1º** Fica criado o programa de regularização fundiária urbana "Batayporã Moradia Legal".
{ #art-1 .revogado }

Parágrafo único. Este programa, de caráter permanente, regulamenta os casos de informalidade dos possuidores, sem título hábil para registro de transferência de propriedade de imóveis com construção cuja titularidade seja do Município de Batayporã-MS.
{ .revogado .tudo }

**Art. 2º** As posses irregulares habitadas dos imóveis do Município de Batayporã-MS serão objeto de regularização fundiária de interesse social ou específico (Reurb-S ou Reurb­ E), desde que obedecidos os critérios fixados nesta Lei e consoante os preceitos da Lei nº 13.465, de 11.7.2017, no que for pertinente.
{ #art-2 .revogado }

§ 1º Para aplicação desta Lei, o Município de Batayporã­MS estabelece a necessidade de o imóvel pertencer a um núcleo urbano ou com destinação urbana, devidamente registrado, com posse iniciada antes 22.12.2016 e que a área do parcelamento esteja dentro dos padrões da legislação ambiental.
{ .revogado .tudo }

§ 2º Considera-se informal a posse de qualquer imóvel de propriedade do Município de Batayporã-MS, com construção habitada, cujos ocupantes utilizem para moradia ou empreendimento comercial e não possuam título de transferência de propriedade hábil para registro.
{ .revogado .tudo }

### CAPÍTULO II — DOS REQUISITOS PARA ENQUADRAMENTO NA REURB-S { .centro .revogado }

**Art. 3º** Os possuidores de imóveis do Município de Batayporã MS deverão ser enquadrados no procedimento de regularização fundiária de interesse social quando:
{ #art-3 .revogado }

I - não possuirem imóvel urbano ou rural, independente de regular registro, ainda que cedidos a qualquer título;
{ .revogado .tudo }

II - possuirem renda familiar de até 03 (três) salários mínimos nacionais ou a renda per capita de até meio salário mínimo nacional;
{ .revogado .tudo }

III - não estejam cadastrados no CADMUT cadastro nacional de mutuários;
{ .revogado .tudo }

IV - não tenham sido beneficiados em outro programa habitacional ou de regularização fundiária, urbana ou rural, seja no âmbito federal, estadual ou municipal;
{ .revogado .tudo }

V - estejam cadastrados no CadÚnico - cadastro único para programas sociais do governo federal;
{ .revogado .tudo }

VI - o imóvel for destinado a moradia;
{ .revogado .tudo }

VII - todas as obras de infraestrutura estejam devidamente implantadas e o imóvel não esteja localizado em área de risco;
{ .revogado .tudo }

VII - comprovar a posse do imóvel conforme prescreve o art. 2º, § 1º desta lei
{ .revogado .tudo }

§ 1º É proibido enquadramento na Reurb-S para lotes vazios ou sem construção própria para moradia.
{ .revogado .tudo }

§ 2º Benefícios sociais não poderão ser considerados como renda familiar.
{ .revogado .tudo }

### CAPÍTULO III — DOS REQUISITOS PARA ENQUADRAMENTO NA REURB-E { .centro .revogado }

**Art. 4º** Os ocupantes de imóveis urbanos que não se enquadrarem ou forem desenquadrados na Reurb-S deverão participar do processo de Regularização Fundiária de Interesse Específico - Reurb-E, desde que atendidos os requisitos desta Lei.
{ #art-4 .revogado }

**Art. 5º** Os imóveis do Município de Batayporã-MS, envolvidos na Reurb-E serão vendidos diretamente aos seus possuidores, dispensados os procedimentos exigidos pela Lei Federal nº 8.666, de 1993.
{ #art-5 .revogado }

§ 1º A venda direta de que trata este artigo somente poderá ser concedida para, no máximo, dois (2) imóveis ou nos casos de haver dois (2) lotes residenciais limítrofes com uma (1) construção própria para moradia abrangendo ambos, cadastrados em nome do beneficiário-possuidor.
{ .revogado .tudo }

§ 2º É proibida a venda direta quando ultrapassar o limite legal individual por espécie ou limite global estipulado no §1º do art. 5°.
{ .revogado .tudo }

§ 3º Para efeito de cobrança do valor para realização da venda direta, o Município deve utilizar como parâmetro o valor de acordo com a avaliação da comissão Avalia Reurb, observando os fins sociais.
{ .revogado .tudo }

§ 4º A venda direta poderá ser realizada à vista, com desconto de até 25%, ou parcelada mediante pagamento de um sinal de, no mínimo, 5% (cinco por cento), em até 60 (sessenta) parcelas mensais e consecutivas, observando o valor de referência do município em cada parcela.
{ .revogado .tudo }

§ 5º A contratação da venda direta depende do pagamento de impostos pendentes relacionados ao imóvel e aos ocupantes beneficiários.
{ .revogado .tudo }

§ 6º Nos contratos de venda direta, deverão constar cláusulas em que o possuidor reconhece a precariedade da posse, a ausência de direito indenizatório das benfeitorias em caso de rescisão contratual e que, em qualquer caso, de consolidação da propriedade, retomada do imóvel ou reversão, não serão indenizadas, pelo Município de Batayporã-MS, eventuais acessões ou quaisquer benfeitorias realizadas no imóvel.
{ .revogado .tudo }

**Art. 6º** o não pagamento de mais de três (3) parcelas e/ou dos impostos pendentes ensejará a notificação dos devedores para solucionar a inadimplência, se o mesmo permanecer inerte pelo prazo de 30 (trinta) dias, o devido será inscrito em divida ativa e será promovida a execução fiscal nos termos da LEI 6830\\80 e aplicada a rescisão do art. 3º.
{ #art-6 .revogado }

**Art. 7º** A Prefeitura Municipal, por meio da Comissão Doc. Reurb, deverá notificar os ocupantes que possuírem imóveis acima do limite legal estabelecido no §1 º do art. 5°, com ou sem construção, ou em caso de fraude na venda direta, concedendo-lhes um prazo de 30 (trinta) dias do recebimento da notificação para desocupar os imóveis que indicar.
{ #art-7 .revogado }

Parágrafo único. Ultrapassado o prazo do art. 7 º, sem cumprimento, a Prefeitura Municipal, por meio da Comissão Doc.Reurb, certificará tal fato e iniciará o processo de retomada do imóvel.
{ .revogado .tudo }

## TÍTULO II — PROCESSO ADMINISTRATIVO { .centro .revogado }

### CAPÍTULO I — COMISSÃO AVALIA. REURB { .centro .revogado }

**Art. 8º** Fica criada a Comissão Avalia.Reurb, destinada a avaliação de imóveis do Programa "Batayporã Moradia Legal", formada por três (3) servidores públicos e 3 suplentes.
{ #art-8 .revogado }

Parágrafo único. As avaliações e decisões da Comissão Avalia. Reurb serão tomadas por maioria simples dos integrantes, sem direito a recurso.
{ .revogado .tudo }

**Art. 9º** A análise dos critérios de enquadramento estabelecidos nessa Lei e desenquadramento será realizada e julgada pela Comissão Doc.Reurb, composta por servidores públicos, sendo dois (2) lotados no Setor de Habitação e um (1) lotado no Departamento de Obras e Infraestruturas da Prefeitura Municipal de Batayporã-MS.
{ #art-9 .revogado }

§ 1º Da análise e julgamento do enquadramento e desenquadramento, caberá recurso no prazo de 3 (três) dias ao Prefeito Municipal.
{ .revogado .tudo }

§ 2º Das demais decisões da Comissão Doc. Reurb caberá recurso no prazo de 3 (três) dias ao Prefeito Municipal.
{ .revogado .tudo }

§ 3º Da decisão do Prefeito Municipal não caberá recurso.
{ .revogado .tudo }

§ 4º Os critérios de enquadramento e desenquadramento serão verificados no momento da apresentação da documentação, podendo ser revistos a qualquer momento, mesmo depois de registrado o título de CRF ou contrato de compra e venda.
{ .revogado .tudo }

§ 5º Verificado, a qualquer momento, que os possuidores não cumpriam os critérios de enquadramento na Reurb-S estabelecidos no inciso I do art. 3 ° desta Lei, a Comissão Doc. Reurb certificará o ocorrido e notificará os ocupantes para, no prazo de quinze (15) dias, apresentar justificativa.
{ .revogado .tudo }

§ 6º Não apresentada ou não aceita a justificativa, a Comissão Doc. Reurb elaborará relatório, notificará os ocupantes para no prazo de 60 (sessenta) dias, se enquadrarem na Reurb-E, sob pena de medidas extrajudicial ou judicial cabível.
{ .revogado .tudo }

### CAPÍTULO II — PROCEDIMENTOS GERAIS { .centro .revogado }

**Art. 10.** Os casos de Reurb-S serão classificados e no final do procedimento, será emitida a CRF na modalidade legitimação fundiária prevista no art. 1 inciso VII da lei 13.465 de 2017, aos possuidores do imóvel e enviada para registro.
{ #art-10 .revogado }

**Art. 11.** A participação no programa de regularização fundiária Batayporã Moradia Legal é obrigatória.
{ #art-11 .revogado }

### CAPÍTULO III — DAS DISPOSIÇÕES FINAIS { .centro .revogado }

**Art. 12.** Todos os valores recebidos oriundos do programa Batayporã Moradia Legal, que não sejam impostos, serão destinados ao Fundo de Habitação de Interesse Social - FHIS - criado pela Lei Municipal nº 1090, de 24 de março de 2015.
{ #art-12 .revogado }

**Art. 13.** A lei 13.465\\2017 será utilizada de forma substitutiva para as omissões presentes nesta lei.
{ #art-13 .revogado }

**Art. 14.** Esta lei entra em vigor na data de sua publicação.
{ #art-14 .revogado }

Batayporã-MS., 11 de setembro de 2019.
