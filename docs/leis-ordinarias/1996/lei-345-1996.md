**LEI Nº-345/96, De 09 de outubro de1996.**
{ .centro }

Dispõe sobre doação de imóveis, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a ampliar a doação efetuada pela [Lei nº-281/94](../1994/lei-281-1994.md), de 27.04.94, em mais até 1.029m² (hum mil e vinte e nove metros quadrados), para o Senhor Geraldo José da Silva.
{ #art-1 }

**Art. 2º** - A área constante do artigo anterior terá as mesmas finalidades e obrigações definidas na [Lei nº-281/94](../1994/lei-281-1994.md), de 27.04.94.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos nove dias do mês de outubro de 1996.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
