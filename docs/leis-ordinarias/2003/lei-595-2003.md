**Lei nº. 595/2003 de 18 de junho de 2003.**
{ .centro .revogado .tudo }

“Cria o Conselho Municipal de Defesa dos Direitos da Pessoa Idosa, e dá outras providências”.
{ .revogado .tudo }

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

### CAPÍTULO I { .centro .revogado }

**Do Conselho Municipal de Defesa dos Direitos da Pessoa Idosa**
{ .centro .revogado .tudo }

**Art. 1º** Fica criado o Conselho Municipal de Defesa dos Direitos da Pessoa Idosa, que se constitui em órgão municipal na conjugação de esforços entre o Poder Público e a Sociedade Civil, com o objetivo de assegurar os direitos sociais do idoso, criando condições para promover sua autonomia, integração e participação efetiva na sociedade, cujo caráter é deliberativo, permanente e consultivo, vinculado ao órgão municipal responsável pela Assistência Social.
{ #art-1 .revogado }

#### SEÇÃO I { .centro .revogado }

**Das Atribuições**
{ .centro .revogado .tudo }

**Art. 2º** São atribuições do Conselho Municipal de Defesa dos Direitos da Pessoa Idosa, sem prejuízo das demais estabelecidas em lei:
{ #art-2 .revogado }

I - formular diretrizes e promover, em todos os níveis da Administração Direta e Indireta, atividades que visem a defesa dos direitos do idoso, a eliminação das discriminações que o atingem, bem como a sua plena inserção na vida sócio-econômica e político cultural;
{ .revogado .tudo }

II - assessorar o Poder Executivo, emitindo pareceres e acompanhando a elaboração e execução de programas do Governo Municipal, em questões relativas ao idoso, com o objetivo de defender seus direitos e interesses;
{ .revogado .tudo }

III - desenvolver estudos, debates e pesquisas relativas a problemática do idoso;
{ .revogado .tudo }

IV - sugerir ao Prefeito e a Câmara Municipal, a elaboração de projetos de lei que visem assegurar e ampliar os direitos do idoso e eliminar da legislação disposições discriminatórias;
{ .revogado .tudo }

V - fiscalizar e tomar providências para cumprimento da legislação relativa aos direitos do idoso;
{ .revogado .tudo }

VI - desenvolver projetos próprios que promovam a participação do idoso em atividade de todos os níveis;
{ .revogado .tudo }

VII - estudar os problemas, receber sugestões da sociedade e opinar sobre denúncias que lhes sejam encaminhadas;
{ .revogado .tudo }

VIII - elaborar o seu regimento interno.
{ .revogado .tudo }

#### SEÇÃO II { .centro .revogado }

**Da Composição do Conselho Municipal de Defesa dos Direitos da Pessoa Idosa.**
{ .revogado .tudo }

**Art. 3º** O Conselho Municipal de Defesa dos Direitos da Pessoa Idosa, e órgão colegiado de composição paritária, composto por 10(dez) membros titulares e seus respectivos suplentes, sendo 05(cinco) representantes do Governo Municipal e 5(cinco) representantes da sociedade civil.
{ #art-3 .revogado }

1º– Integrarão o Conselho, representantes dos seguintes órgãos governamentais:
{ .revogado .tudo }

a) Secretaria Municipal de Desenvolvimento Sustentável;
{ .revogado .tudo }

b) Secretaria Municipal de Educação, Cultura Desporto de Lazer;
{ .revogado .tudo }

c) Secretaria Municipal de Promoção Social e Trabalho;
{ .revogado .tudo }

d) Secretaria Municipal de Saúde ;
{ .revogado .tudo }

e) Secretaria Municipal de Administração, Projetos e Planejamento.
{ .revogado .tudo }

2º– Os conselheiros serão indicados pelos respectivos Secretários ou equivalentes, juntamente com seu respectivo suplente, sendo nomeados pelo Chefe do Executivo, e empossados pelo Secretário do órgão o qual o Conselho é vinculado, para mandato de dois anos, permitida a recondução.
{ .revogado .tudo }

3º– Os representantes da sociedade civil serão escolhidos em foro próprio, após Convocação do Conselho. E estes elegerão entre si seus representantes, entre titulares e suplentes.
{ .revogado .tudo }

**Art. 4º** A presidência e a vice-presidência serão exercidas por um representante governamental e outro não governamental, alternadamente escolhidos por maioria simples de seus membros nomeados por ato do Prefeito por 01 ano cada um.
{ #art-4 .revogado }

1º. – Ocorrendo à ausência ou impedimento do presidente e do vice-presidente, assumirá a presidência da reunião um Conselheiro escolhido pelo Plenário.
{ .revogado .tudo }

2º.- Em caso de vacância da função de presidente, assumirá a mesma o vice-presidente, se restarem menos de seis meses para o término do mandato.
{ .revogado .tudo }

3º.- Se o prazo for superior a seis meses, será realizada eleição para a função de presidente.
{ .revogado .tudo }

**Art. 5º** A substituição de membros do Conselho poderá ocorrer a qualquer tempo por meio de comunicação expressa, encaminhada a presidência pela direção da entidade representada.
{ #art-5 .revogado }

**Art. 6º** Será substituído o membro que renunciar e o que não comparecer a três reuniões consecutivas ou a cinco intercaladas no ano, salvo se a ausência for justificada por escrito ao Conselho.
{ #art-6 .revogado }

Parágrafo único. A indicação do membro que se desligou é privativa do órgão representado.
{ .revogado .tudo }

**Art. 7º** O Conselho de Defesa dos Direitos da Pessoa Idosa terá a seguinte estrutura.
{ #art-7 .revogado }

I - Plenária ;
{ .revogado .tudo }

II - Mesa Diretora;
{ .revogado .tudo }

III - Comissões Permanentes e Temporárias;
{ .revogado .tudo }

IV - Diretoria Executiva.
{ .revogado .tudo }

**Art. 8º** O Conselho receberá apoio técnico, administrativo e financeiro do órgão municipal responsável pela Assistência Social.
{ #art-8 .revogado }

**Art. 9º** A função de membro do Conselho é considerada de relevante interessa público, e não será remunerada;
{ #art-9 .revogado }

**Art. 10.** O Conselho Municipal de Defesa dos Direitos da Pessoa Idosa reuni-se á ordinariamente, uma vez por mês, ou como definir o Regimento Interno do mesmo, e extraordinariamente, sempre que necessário, por convocação de seu Presidente, ou de um terço de seus membros, observada antecedência mínima de cinco dias.
{ #art-10 .revogado }

**Art. 11.** As decisões do Conselho serão consubstanciadas em deliberações, assinadas pelo presidente e publicadas no Diário Oficial do Município quando houver necessidade.
{ #art-11 .revogado }

**Art. 12.** Os membros do Conselho não receberão qualquer remuneração por sua participação no colegiado.
{ #art-12 .revogado }

1º– A função de Conselheiro e seus serviços prestados serão considerados, para todos os efeitos, como de interesse público e de relevante valor social.
{ .revogado .tudo }

2º– O pagamento das despesas com transporte e locomoção, estada e alimentação não são consideradas remuneração.
{ .revogado .tudo }

#### SEÇÃO III { .centro .revogado }

**Da Administração do Conselho**
{ .revogado .tudo }

**Art. 13.** O Conselho Municipal de Defesa dos Direitos da Pessoa Idosa, regular-se por um Regimento Interno, com observância da legislação aplicável, a ser elaborado pelo Conselho e confirmado pro Decreto do Executivo, na forma do artigo da Lei Orgânica Municipal, no prazo de 30(trinta)dias, contados da posse de seus membros.
{ #art-13 .revogado }

**Art. 14.** O mandato dos membros do Conselho será de 02(dois) anos.
{ #art-14 .revogado }

### CAPÍTULO II { .centro .revogado }

**Das Disposições Finais**
{ .centro .revogado .tudo }

**Art. 15.** Cumpre ao Órgão Municipal responsável pela Assistência Social, providenciar a alocação de recursos humanos e materiais necessários ao pleno funcionamento do Conselho.
{ #art-15 .revogado }

**Art. 16.** As despesas decorrentes da presente Lei, correrão por conta das dotações orçamentárias próprias, suplementadas necessário.
{ #art-16 .revogado }

**Art. 17.** Esta Lei entrará em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-17 .revogado }

Prefeitura Municipal de Batayporã-MS, aos dezoito dias do mês de junho de 2003.

Prefeito Municipal
