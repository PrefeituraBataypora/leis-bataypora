**Lei nº. 592/2003 de 28 de maio de 2003.**
{ .centro }

“Dispõe sobre doação de imóveis, e dá outras providências”.

**DR. JERCÉ EUSÉBIO DE SOUZA**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:

**Art. 1º** Fica o Poder Executivo Municipal autorizado a doar os imóveis denominados ***DATA,*** localizados na Quadra n°-07(sete) no perímetro urbano deste município para:

1.  ***Sebastião Euzébio Rita,*** portador do CPF nº [omitido]; DATA n°-12 com área de 630m² ;

2.  ***Márcia Alves Queiroz,*** DATA n°-13, parte com área de 210m²;

3.  ***Cícero José da Costa,*** portador do CPF nº [omitido]; DATA n°-14 com área de 420m² ;

4.  ***Arlindo Rodrigues dos Santos,*** portador do CPF nº [omitido]; DATA n°-15 com área de 420m² ;

5.  ***Adriana de Assis Santos de Campos,*** portadora do CPF nº [omitido]; DATA n°-16 com área de 630m² ;

6.  ***Maria de Jesus Barbosa Assis,*** portadora do CPF nº [omitido]; DATA n°-17 com área de 630m² ;

7.  ***Paulo Mendonça Espíndola,*** portador do CPF nº [omitido]; DATA n°-18 com área de 630m² ;

8.  ***Sueli de Souza Lima,*** portadora do CPF nº [omitido]; DATA n°-19 com área de 630m² ;

9.  ***Maria Nilza Alves da Silva,*** portador do CPF nº [omitido]; DATA n°-20 com área de 420m² ;

10. ***Sebastião Pinheiro dos Santos,*** portador do CPF nº [omitido], DATA n°-21 com área de 420m² ;

11. ***José Luiz Vieira da Costa,*** portador do CPF nº [omitido]; DATA n°-22 com área de 420m² ;

**Art. 2º** A doação constante do artigo anterior destina-se a assegurar o domínio definitivo das famílias que se encontram residindo nos referidos imóveis.
{ #art-2 }

**Art. 3º** Os beneficiados pela presente doação, não poderão em hipótese alguma, alienar e ou transferir o imóvel dentro do prazo de 05 anos a partir do recebimento da Escritura definitiva.
{ #art-3 }

**Art. 4º** Fica o Poder Executivo autorizado a efetuar baixa do Patrimônio Municipal dos referidos imóveis, obedecendo ao valor constante no Balanço Geral do Exercício anterior.
{ #art-4 }

**Art. 5º** O Poder Executivo Municipal, a partir desta data iniciará o lançamento tributário incidentes sobre os imóveis constantes desta Lei.
{ #art-5 }

**Art. 6º** O Município fornecerá toda documentação necessária para o fiel desempenho da presente doação acima autorizada.
{ #art-6 }

**Art. 7º** Esta Lei entrará em vigor na presente data, revogadas as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Batayporã-MS, aos vinte e oito dias do mês de maio de 2003.

**Dr. Jercé Eusébio de Souza**
Prefeito Municipal
