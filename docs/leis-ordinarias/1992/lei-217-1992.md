**LEI Nº-217/92, De 29 de outubro de 1992.**
{ .centro }

Dispõe sobre doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a doar dois imóveis urbanos de até 630m², cada, um para a IGREJA PENTECOSTAL CRISTO SALVA, e outro para a IGREJA EVANGÉLICA ASSEMBLÉIA DE DEUS MINISTÉRIO DO BELÉM.
{ #art-1 }

Parágrafo único - A doação constante deste artigo será realizada dentre os imóveis de propriedade da municipalidade.

**Art. 2º** - As Igrejas beneficiadas serão obrigadas a construirem seus Templos, em alvenaria, mediante um Projeto de Obra.
{ #art-2 }

**Art. 3º** - O prazo para construção previsto no artigo anterior, é de 12 (doze) meses, com 06 (seis) de carência, a partir do recebimento do imóvel.
{ #art-3 }

**Art. 4º** - Não cumpridas as exigências constantes da presente Lei, os imóveis doados retornarão ao domínio do Município.
{ #art-4 }

**Art. 5º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-5 }

**Art. 6º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos vinte e nove dias do mês de outubro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
