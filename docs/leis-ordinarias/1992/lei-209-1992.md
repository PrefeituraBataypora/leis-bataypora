**LEI Nº-209/92, De 27 de agosto de 1992.**
{ .centro .revogado .tudo }

Dispõe sobre nova denominação de Sala de Ensino, e dá outras providências.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - A Sala de Ensino da Escola Municipal Rural José Bonifácio, denominada de Marechal Arthur da Costa e Silva, passará a denominar-se de "Escola Rural de I Grau José Bonifácio Sala Alfredo Jubran".
{ #art-1 .revogado }

**Art. 2º** - As despesas decorrentes da execução da presente Lei correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-2 .revogado }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 .revogado }

Prefeitura Municipal de Batayporã-MS, aos vinte e sete dias do mês de agosto de 1992.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
{ .centro .revogado .tudo }
