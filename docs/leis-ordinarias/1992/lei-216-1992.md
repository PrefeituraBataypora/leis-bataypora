**LEI Nº-216/92, De 29 de outubro de 1992.**
{ .centro }

Dispõe sobre doação de Bens Móveis, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Art. 1º** - Fica o Executivo Municipal autorizado a doar duas motos **HONDA/CG 125 TODAY**, ano de fabricação 1991, modelo 1992, chassi nº-9C2JC1801MR222444 e nº-9C2JC1801MR226622, para premiação da 4ª Festa do Peão, em Batayporã, a realizar-se no presente exercício.
{ #art-1 }

**Art. 2º** - A doação constante do artigo anterior será realizada a quem der direito, por Decreto Municipal.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no Orçamento em vigor, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos vinte e nove dias do mês de outubro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
