**LEI Nº-193/92, De 29 de abril de 1992.**
{ .centro }

Dispõe sobre aquisição de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir imóveis de até 100.000m² (cem mil metros quadrados).
{ #art-1 }

Parágrafo único - A aquisição constante deste artigo será precedida de avaliação prévia por uma Comissão Especial nomeada para os fins específicos, composta de até 5 (cinco) membros.

**Art. 2º** - Os imóveis adquiridos na forma do artigo primeiro, serão destinados a doação para construção de casas populares, para famílias que comprovadamente residem em nosso Município, não é proprietário de imóvel, e mediante Projeto Municipal.
{ #art-2 }

Parágrafo único - A presente doação poderá ser regulamentada por Decreto se necessária.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e nove dias do mês de abril de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.
