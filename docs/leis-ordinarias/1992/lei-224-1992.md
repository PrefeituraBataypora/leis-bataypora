**LEI Nº-224/92, De 25 de novembro de 1992.**
{ .centro }

Dispõe sobre nova denominação de Sala de Ensino, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - A Sala Marechal Artur da Costa e Silva da Escola Municipal Rural de Pré-Escolar de I Grau José Bonifácio-Polo, passa a denominar-se "Sala Alfredo Jubran".
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente Lei correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor a partir de **1º de janeiro de 1993**, revogando em sua totalidade a [lei nº-209/92](lei-209-1992.md), de 27.08.92.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e cinco dias do mês de novembro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
