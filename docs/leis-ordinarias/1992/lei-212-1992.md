**LEI Nº-212/92, De 09 de setembro de 1992.**
{ .centro .revogado .tudo }

Reestrutura o Quadro de Pessoal de Carreira da Prefeitura Municipal, e dá outras providências.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica alterado para 300 (trezentos) o número de empregos do pessoal de carreira da Prefeitura Municipal de Batayporã-MS, previsto no artigo 34 da Lei Municipal [nº-187/91](../1991/lei-187-1991.md#art-34), de 24.12.91, exceto o Quadro de Professores e Especialistas de Educação.
{ #art-1 .revogado }

**Art. 2º** - Ficam criados, transformados ou mantidos os cargos, funções e empregos constantes do Quadro nº-1, Anexos I, II, III, IV e V, da presente Lei.
{ #art-2 .revogado }

**Art. 3º** - O preenchimento das vagas dar-se-á à medida das necessidades da Administração Municipal, observadas as disposições do [art. 13 da Lei Municipal nº-187/91](../1991/lei-187-1991.md#art-13), de 24.12.91.
{ #art-3 .revogado }

Parágrafo Único - Para o preenchimento das vagas, conforme o disposto neste artigo, o Executivo Municipal deverá aproveitar o pessoal já aprovado em Concurso Público realizado anteriormente a vigência desta Lei.
{ .revogado .tudo }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário, inclusive os anexos I, II, III, IV e V do Quadro nº-1 da Lei nº-187/91.
{ #art-4 .revogado }

Prefeitura Municipal de Batayporã-MS, aos nove dias do mês de setembro de 1992.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
{ .centro .revogado .tudo }
