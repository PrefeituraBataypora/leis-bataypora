**LEI Nº-191/92, De 02 de abril de 1992.**
{ .centro }

Dispõe sobre doação de linha telefônica, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Artigo 1º** - Fica o Poder Executivo Municipal autorizado a doar uma linha telefônica para o FRIPORÃ - Frigorífico Batayporã Ltda.
{ #art-1 }

Parágrafo único - A presente doação será executada de conformidade com as normas da TELEMS S/A.

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de dotações orçamentárias, constantes do Orçamento Municipal, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos dois dias do mês de abril de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
