**LEI Nº-228/92, De 09 de dezembro de 1992.**
{ .centro }

Dispõe sobre doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a doar quatro imóveis urbanos de até 630m², cada, um para a **construção de uma Capela da Igreja Católica Apostólica Romana**, na Vila Cantidiano Duarte; um para a **Associação dos Servidores Municipais de Batayporã** construir sua Sede própria; um para a **Associação dos Servidores Públicos Estaduais** construir sua Sede própria e um para o **Empresário Sr. Hilton Soares Silva** construir, instalar e colocar em funcionamento uma fábrica de móveis tubulares.
{ #art-1 }

Parágrafo único - A doação constante deste artigo será realizada dentre os imóveis de propriedade da municipalidade, ou se necessário, adquirí-los mediante avaliação prévia de comissão especial, formada de até 05 (cinco) membros.

**Art. 2º** - Todos os beneficiados serão obrigados a construirem em alvenaria, mediante um Projeto de Obra, e destinarem suas atividades de conformidade com os objetivos constantes do artigo anterior.
{ #art-2 }

**Art. 3º** - O prazo para construção previsto no artigo anterior, é de 12 (doze) meses, com 06 (seis) de carência, a partir do recebimento do imóvel.
{ #art-3 }

**Art. 4º** - Não cumpridas as exigências constantes da presente Lei, os imóveis doados retornarão ao domínio do Município.
{ #art-4 }

**Art. 5º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-5 }

**Art. 6º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos nove dias do mês de dezembro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
