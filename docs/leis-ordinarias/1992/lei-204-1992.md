**LEI Nº-204/92, De 01 de julho de 1992.**
{ .centro .revogado .tudo }

Dispõe sobre alterações na [Lei nº-188/92](lei-188-1992.md), de 20.02.92.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.
{ .revogado .tudo }

**Artigo 1º** - O [artigo primeiro e seu parágrafo único, da Lei 188/92](lei-188-1992.md#art-1), de 20.02.92, passa a vigorar com a seguinte redação:
{ #art-1 .revogado .tudo }

> “Artigo 1º - Fica o Executivo Municipal autorizado a outorgar escritura de doação do terreno de sua propriedade, denominado Chácaras nº-04 e 05 da 1ª linha (adquirido de Carlos Amantino Nantes Ribeiro), com área de 20.000m² (vinte mil metros quadrados) junto ao Agente Promotor **ECOL. ENGENHARIA E COMÉRCIO LTDA** para hipoteca junto ao Sistema Financeiro da Habitação.
> { .revogado .tudo }
>
> Parágrafo único - A área constante deste artigo destina-se a construção de Unidades Habitacionais pelo Programa de Ação Imediata para Habitação Popular, do Ministério da Ação Social.”
> { .revogado .tudo }

**Artigo 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 .revogado .tudo }

**Artigo 3º** - Revogam-se as disposições em contrário.
{ #art-3 .revogado .tudo }

Prefeitura Municipal de Batayporã-MS, ag primeiro dia do mês de julho de 1992.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
{ .centro .revogado .tudo }
