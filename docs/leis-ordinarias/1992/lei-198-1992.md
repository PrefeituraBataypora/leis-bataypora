**LEI Nº-198/92, De 20 de maio de 1992.**
{ .centro }

Dispõe sobre denominação de Vila, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica denominada de "VILA MARIA GONÇALVES DA SILVA", a vila localizada no prolongamento da Avenida Brasil, oriunda do loteamento promovido pelo Executivo Municipal.
{ #art-1 }

Parágrafo único - A Vila constante no caput desse artigo, é parte integrante do imóvel adquirido recentemente do Sr. Rodolfo Alves dos Santos.

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria, constantes no Orçamento em vigor, suplementada se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte dias do mês de maio de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
