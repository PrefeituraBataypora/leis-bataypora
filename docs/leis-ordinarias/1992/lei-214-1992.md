**LEI Nº-214/92, De 14 de outubro de 1992.**
{ .centro }

Dispõe sobre abertura de créditos suplementares no Orçamento do Município, para o exercício financeiro de 1992, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido o limite constante do [artigo 4º, item II da Lei nº-176/91](../1991/lei-176-1991.md#art-4), de 27.11.91 e os autorizados pelas Leis nº-192/92, 196/92, 205/92 e 210/92, fica o Poder Executivo autorizado a suplementar mais 100% (cem por cento) da despesa orçada.
{ #art-1 }

Parágrafo único - São recursos para abertura de créditos suplementares constantes deste artigo, os previstos na Lei nº-4.320/64.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos catorze dias do mês de outubro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
