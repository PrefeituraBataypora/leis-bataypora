**LEI Nº-188/92, De 20 de fevereiro de 1992.**
{ .centro .revogado .tudo }

Dispõe sobre doação de imóvel, e dá outras providências.
{ .revogado .tudo }

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.
{ .revogado .tudo }

**Artigo 1º** - Fica o Executivo Municipal autorizado a autorgar escritura de doação do terreno de sua propriedade, constante da Escritura lavrada nas Folhas 149vº-155 do Livro Nº-40 no Cartório da Paz e Tabelionamento Local, com área de 20.000m² (vinte mil metros quadrados) junto ao Agente Promotor **ECOL. ENGENHARIA E COMÉRCIO LTDA** para hipoteca junto ao Sistema Financeiro da Habitação.
{ #art-1 .revogado .tudo }

Parágrafo único - A área constante deste artigo destina-se a construção de Unidades Habitacionais pelo Programa de Ação Imediata para Habitação Popular, do Ministério da Ação Social.
{ .revogado .tudo }

!!! info "Redação dada pela Lei nº 204/1992"
    Nova redação deste artigo e de seu parágrafo único, dada pelo [art. 1º da Lei nº 204/1992](lei-204-1992.md#art-1):

    Artigo 1º - Fica o Executivo Municipal autorizado a outorgar escritura de doação do terreno de sua propriedade, denominado Chácaras nº-04 e 05 da 1ª linha (adquirido de Carlos Amantino Nantes Ribeiro), com área de 20.000m² (vinte mil metros quadrados) junto ao Agente Promotor **ECOL. ENGENHARIA E COMÉRCIO LTDA** para hipoteca junto ao Sistema Financeiro da Habitação.

    Parágrafo único - A área constante deste artigo destina-se a construção de Unidades Habitacionais pelo Programa de Ação Imediata para Habitação Popular, do Ministério da Ação Social.

**Art. 2º** - Fica igualmente autorizado o Executivo Municipal a executar as obras de infra-estrutura tais como, rede de água, energia elétrica e meio-fio no terreno acima especificado, durante a fase de construção, devendo estar concluídas conjuntamente com as mesmas.
{ #art-2 .revogado }

Parágrafo único - Para fazer face as despesas do presente artigo, serão utilizados recursos do Orçamento Municipal em vigor.
{ .revogado .tudo }

**Art. 3º** - O terreno objeto desta Lei, bem como a sua infra-estrutura serão repassados a custo zero para o mutuário final.
{ #art-3 .revogado }

**Art. 4º** - Esta Lei estará automaticamente revogada, sem ônus para o Município se num prazo de 365 (trezentos e sessenta e cinco) dias corridos, a partir de sua publicação, não se concluir o processo de financiamento junto a Caixa Econômica Federal/ Ministério da Ação Social.
{ #art-4 .revogado }

§1º - Tão logo seja formalizado pela Empresa ECOL ENGENHARIA E COMÉRCIO LTDA o contrato de financiamento junto à Caixa Econômica Federal, cessa a condição de reversão da área para o domínio do Município.
{ .revogado .tudo }

§2º - O prazo acima enunciado poderá ser ampliado por autorização e conveniência do Município por mais 180 (cento e oitenta) dias, através de Decreto do Poder Executivo.
{ .revogado .tudo }

**Artigo 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-5 .revogado .tudo }

**Artigo 6º** - Revogam-se as disposições em contrário.
{ #art-6 .revogado .tudo }

Prefeitura Municipal de Batayporã-MS, aos vinte dias do mês de fevereiro de 1992.
{ .revogado .tudo }

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada através do livro do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
