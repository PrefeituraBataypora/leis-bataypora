**LEI Nº-195/92, De 13 de maio de 1992.**
{ .centro }

Dispõe sobre concessão de auxílio e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a se guinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a conceder auxílio no valor de CR$-11.000.000,00 (onze milhões de cruzeiros), ao Centro Rural do Bairro da Festa.
{ #art-1 }

**Art. 2º** - O auxílio concedido será destinado à aquisição e instalação de uma fecularia.
{ #art-2 }

Parágrafo único - A aquisição constante deste Artigo será destinada aos produtores do Bairro da Festa, com utilização regulamentada pelo seu Centro Rural.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos treze dias do mês de maio de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
