**LEI Nº-203/92, De 01 de julho de 1992.**
{ .centro }

Dispõe sobre permuta de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a permutar o imóvel urbano, nesta cidade, denominado Data 23 da Quadra 34, 630m² (seiscentos e trinta metros quadrados), adquirido através da [Lei nº-196/92](lei-196-1992.md), pela Data nº-19, da Quadra nº-04, com 630m², e CR$-1.500.000,00 (Hum milhão e quinhentos mil cruzeiros) de complementação.
{ #art-1 }

**Art. 2º** - O imóvel permutado de conformidade com o artigo anterior, será destinado à instalação do Posto de Polícia Florestal.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, ao primeiro dia do mês de julho de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
