**LEI Nº-219/92, De 11 de novembro de 1992.**
{ .centro }

Dispõe sobre cessão de Servidores Públicos Municipais, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a ceder em disponibilidade, com ônus para a origem, até 06 (seis) Servidores Públicos Municipais à ASSOCIAÇÃO AMIGOS DO LAR SANTO ANTONIO DE BATAYPORÃ, CGC-24.630.808/0001-10.
{ #art-1 }

Parágrafo único - Os Servidores cedidos obedecerão a jornada de trabalho, de conformidade com o Organograma da Entidade.

**Art. 2º** - A Entidade beneficiada se obriga a apresentar a folha de frequência dos Servidores cedidos, com as respectivas presenças ou faltas, até ao dia 25 de cada mês, ao Setor de Pessoal desta Prefeitura, para processamento dos vencimentos.
{ #art-2 }

**Art. 3º** - Não cumpridas as exigências constantes da presente Lei, os Servidores cedidos retornarão à origem.
{ #art-3 }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos onze dias do mês de novembro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }
