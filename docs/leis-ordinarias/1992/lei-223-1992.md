**LEI Nº-223/92, De 25 de novembro de 1992.**
{ .centro }

Dispõe sobre aquisição e doação de imóvel, e dá outras providências.

JERCÉ EUSÉBIO DE SOUZA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir e doar um imóvel urbano de até 210m², para a construção de um **LABORATÓRIO DE SURFASSAGEM (fabricação) DE LENTES DE VISÃO SIMPLES, BIFOCAIS, MULTIFOCAIS, EM CRISTAL E RESINA ORGÂNICA**, com salão para comercialização, em local com infra-estrutura necessária (luz, água, telefone, etc.), ao empresário **CELSO TADASHI NAKAMICHI**.
{ #art-1 }

Parágrafo único - A aquisição constante deste artigo será precedida de avaliação prévia, por uma Comissão Especial nomeada para os fins específicos, composta de até 05 (cinco) membros.

**Art. 2º** - O empresário beneficiado será obrigado a construir a obra constante do artigo anterior, em alvenaria, mediante um Projeto de Obra.
{ #art-2 }

**Art. 3º** - O prazo para construção e funcionamento de suas atividades previsto no artigo anterior, é de 08 (oito) meses, com 03 (três) de carência, a partir da doação do imóvel.
{ #art-3 }

**Art. 4º** - Não cumpridas as exigências constantes da presente Lei, o imóvel doado retornará ao domínio do Município.
{ #art-4 }

**Art. 5º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-5 }

**Art. 6º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos vinte e cinco dias do mês de novembro de 1992.

Dr. JERCÉ EUSÉBIO DE SOUZA
{ .centro }

Prefeito Municipal
{ .centro }
