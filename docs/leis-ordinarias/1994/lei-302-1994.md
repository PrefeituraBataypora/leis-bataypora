**LEI Nº-302/94, De 07 de dezembro de 1994.**
{ .centro }

Dispõe sobre concessão de abono salarial aos Servidores da Câmara Municipal de Batayporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Artigo 1º** - Fica autorizado a concessão de um abono natalino de R$- 50,00 (cinquenta reais), a todos os Servidores da Câmara Municipal de Batayporã-MS.
{ #art-1 }

Parágrafo único - O abono concedido nos termos do caput deste artigo, será pago até o dia 23 de dezembro de 1994.

**Artigo 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Artigo 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Artigo 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos sete dias do mês de dezembro de 1994.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
