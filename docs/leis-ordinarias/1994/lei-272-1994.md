**LEI Nº-272/94, De 19 de janeiro de 1994.**
{ .centro }

Autoriza o Poder Executivo Municipal a Alienar Ações do Município.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a Alienar Ações pertecentes a este Município.
{ #art-1 }

**Art. 2º** - Os Recursos provenientes da venda das referidas Ações serão aplicados em obras, aquisição de bens móveis ou imóveis, visando atender as prioridades do Município.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogando-se as disposições.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS., aos dezenove dias do mês de janeiro de 1994.

DR. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº. Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
