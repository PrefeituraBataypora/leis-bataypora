**LEI Nº-274/94, De 28 de janeiro de 1994.**
{ .centro }

Dispõe sobre aquisição de imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir imóvel urbano com área de até 840m² (oitocentos e quarenta metros quadrados).
{ #art-1 }

§1º - A aquisição constante deste artigo será precedida de avaliação prévia, por uma Comissão Especial nomeada para os fins específicos, composta de cinco Membros.

§2º - A presente aquisição será destinada a construção e ou a ampliação de Creche.

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos vinte e oito dias do mês de janeiro de 1994.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }
