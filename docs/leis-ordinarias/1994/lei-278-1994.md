**LEI Nº-278/94, De 16 de março de 1994.**
{ .centro }

Dispõe sobre recursos para aquisição de imóvel para a ENERSUL, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a pagar CR$-4.131.600,00 (quatro milhões, cento e trinta e um mil, seiscentos cruzeiros reais), ao Sr. SILVINO BISPO FERREIRA, correspondente a cinquenta por cento da aquisição do imóvel para implantação da SE-BATAYPORÃ, feita pela ENERSUL, a título de doação.
{ #art-1 }

**Art. 2º** - Procedida a doação, fica o Executivo autorizado a gestionar junto a ENERSUL, a viabilidade de retorno ao domínio do Município a quadra nº-9 (nove) da planta da cidade, imóvel este doado a CEMAT, para instalação da Estação Rebaixadora de Energia Elétrica.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos dezesseis dias do mês de março de 1994.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
