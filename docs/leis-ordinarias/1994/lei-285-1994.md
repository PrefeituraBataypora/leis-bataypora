**LEI Nº-285/94, De 11 de julho de 1994.**
{ .centro }

Dispõe sobre permuta de imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a permutar o imóvel urbano, denominado data nº-20, da quadra 49, de propriedade da municipalidade, com o imóvel denominado data nº-03 da quadra 50, com áreas iguais, com o Senhor JOSÉ RAMOS DE OLIVEIRA, portador do CIC. Nº-[omitido], sem ônus para a municipalidade.
{ #art-1 }

Parágrafo único - Toda despesa decorrente da presente transação, ficará por conta do interessado.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos onze dias do mês de julho de 1994.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
