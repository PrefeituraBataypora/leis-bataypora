**LEI Nº273/94, De 28 de janeiro de 1994.**
{ .centro }

Dispõe sobre doações de Linhas Telefônicas e Material de Construções, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a efetuar doações para o FRIPORÃ-Frigorífico Batayporã Ltda, conforme seguem:
{ #art-1 }

a: de até 08 (oito) linhas telefônicas;

b: de até 100 (cem) milheiros de tijolos de 08 (oito) furos.

Parágrafo único - As doações constantes deste artigo serão objeto de aplicação e funcionamento em suas instalações neste Município.

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos vinte e oito dias do mês de janeiro de 1994.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº. Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
