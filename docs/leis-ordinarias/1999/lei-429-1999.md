**LEI Nº-429/99, De 29 de março de 1999.**
{ .centro }

Dispõe sobre aquisição da edificação e acessórios, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Poder Público Municipal, autorizado a adquirir a edificação e demais pertences, da Bat-Couro Comércio de Couro Batayporã Ltda.
{ #art-1 }

Parágrafo único - A construção objeto do "caput" deste artigo, não inclui o terreno de 1000 m² sobre o qual foi constrído, por Ter sido revogado a doação.

**Art. 2º** - Os bens a ser adquirido através de processo de avaliação previa, contém o seguinte:
{ #art-2 }

Um barracão de alvenaria de 15,00 metros por 20,00 metros; um banheiro de 4,5 m X 2,5 m; a cobertura tipo eternit; um padrão de energia elétrica com transformador, trifásico; uma caixa d'água de mil litros.

**Art. 3º** - Os bens acima referidos, poderão a critério da Administração, ser doados ou alienados, para terceiros mediante procedimento de acordo com a legislação pertinente.
{ #art-3 }

**Art. 4º** - Para cobertura das despesas oriundas do artigo 1º, correrão por conta das dotações próprias, consignadas no Orçamento vigente, suplementadas se necessário for.
{ #art-4 }

**Art. 5º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, 29 de março de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria Municipal de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
