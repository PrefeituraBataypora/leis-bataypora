**LEI Nº-456/99, De 21 de dezembro de 1999.**
{ .centro }

Dispõe sobre doação de bens móveis e utensílios ao Legislativo Municipal, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - O Município fica autorizado o Executivo promover a doação de bens móveis e utensílios a Câmara Municipal conforme relação anexa, fazendo parte integrante desta Lei.
{ #art-1 }

**Art. 2º** - Os bens móveis e utensílios, objeto da doação referem-se aos exercícios de 1997; 1998 e 1999.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação, retroagindo seus efeitos a 01 de março de 1997.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Batayporã-MS, 21 de dezembro de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
