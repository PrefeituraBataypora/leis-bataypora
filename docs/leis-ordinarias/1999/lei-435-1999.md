**LEI Nº-435/99, De 29 de abril de 1999.**
{ .centro }

Dispõe sobre denominação de Complexo Esportivo Antonio Afonso de Oliveira, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - O Complexo Esportivo dos Assentamentos São Luiz, São João e Mercedina, passa denominar-se "Complexo Esportivo Antonio Afonso de Oliveira".
{ #art-1 }

**Art. 2º** - Para cobertura das despesas decorrentes da presente lei, correrão por conta de dotação própria, cosignada no Orçamento vigente.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, 29 de abril de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria Municipal de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
