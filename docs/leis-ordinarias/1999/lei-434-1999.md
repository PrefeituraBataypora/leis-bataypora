**LEI Nº-434/99, De 15 de abril de 1999.**
{ .centro }

Dispõe sobre a criação e denominação da Banda Musical de Batayporã, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica criada no município de Batayporã-MS, a "Banda Musical José Chambó Ruiz".
{ #art-1 }

**Art. 2º** - As despesas decorrentes do artigo 1º desta Lei, correrão por conta das dotações consignadas no Orçamento corrente, suplementadas se necessário for.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, 15 de abril de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria Municipal de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
