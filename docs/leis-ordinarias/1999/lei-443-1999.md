**LEI Nº-443/99, De 28 de julho de 1999.**
{ .centro }

Estabelece Imprensa Oficial do Município, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - A Imprensa Oficial do Município de Batayporã-MS, será escolhida através de processo licitatório, conforme previsto na lei nº 8.666, de 21-06-93, e suas alterações.
{ #art-1 }

**Art. 2º** - As despesas oriundas da presente lei correrão por conta da dotação orçamentária do Orçamento vigente, suplementada se necessário for.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, 28 de julho de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
