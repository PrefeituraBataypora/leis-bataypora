**LEI Nº-433/99, De 15 de abril de 1999.**
{ .centro }

Autoriza abertura de crédito especial, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Poder Público Municipal, autorizado a abrir Crédito Especial, no valor até R$ 900.000,00 (novecentos mil reais), para a Construção do Hospital Municipal de Batayporã-MS.
{ #art-1 }

**Art. 2º** - Para cobertura do investimento na edificação do Hospital Municipal, os recursos serão os advindos do objeto do Convênio nº 2766/98 de 03-07-98, do Ministério da Saúde, e da contrapartida pelo Município.
{ #art-2 }

**Art. 3º** - A dotação orçamentária a ser acrescida pelo Credito Especial desta Lei, na seguinte verba consignada no Orçamento vigente:
{ #art-3 }

| 11. | Secretaria Municipal de Saúde – SMS |  |
|---|---|---|
| 11.13 | Saúde e Saneamento |  |
| 11.13.75 | Saúde |  |
| 11.13.75.428 | Assistência Médica Sanitária |  |
| 11.13.75.428-1037. | Construção Hospital Municipal |  |
| 4.000 | Despesas de Capital |  |
| 4.100 | Investimentos |  |
| 4.110 | Obras Públicas | R$ 900.000,00 |

**Art. 4º** - Os recursos orçamentários, serão o seguinte:
{ #art-4 }

a- através da liberação pela União Federal, Convênio nº 2766/98 de 03-07-98;

b- através de recursos próprios consignados no Orçamento Vigente, suplementados por decretos até o limite da contrapartida, obedecidos os parâmetros da presente lei, e demais disposições pertinentes.

**Art. 5º** - A construção do Hospital Municipal, obedece o Plano Plurianual de Investimentos, ([Lei nº 400/98](../1998/lei-400-1998.md) de 15 de julho de 1998, anexo I; item 1.02), e as Diretrizes Orçamentárias ([Lei 401/98](../1998/lei-401-1998.md) de 15 de julho de 1998, código 13.75.03).
{ #art-5 }

**Art. 6º** - Esta Lei entra em vigor na data de sua publicação, retroagindo seus efeitos a 17 de março de 1999.
{ #art-6 }

**Art. 7º** - Revogam-se as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Batayporã-MS, 15 de abril de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria Municipal de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
