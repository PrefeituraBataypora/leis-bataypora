**LEI Nº-436/99, De 29 de abril de 1999.**
{ .centro }

Denomina Complexo esportivo FREDERICO KRUGER a Quadra Coberta da Vila Eduvirges Reina Ribeiro, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica denominada a quadra coberta da Vila a ser denominada EDUVIRGES REINA RIBEIRO do "Complexo Esportivo FREDERICO KRUGER".
{ #art-1 }

**Art. 2º** - As despesas oriundas do artigo 1º desta Lei, correrão por conta das dotações próprias, consignadas no Orçamento vigente.
{ #art-2 }

**Art. 3** – Esta Lei entra em vigor na data de sua publicação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, 29 de abril de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria Municipal de Administração e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
