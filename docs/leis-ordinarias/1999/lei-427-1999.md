**LEI Nº-427/99, De 29 de março de 1999.**
{ .centro }

Autoriza o cancelamento do títulos de lotes doados vazios, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Artigo 1º** - Fica o Município autorizado os cancelamentos de todos os "títulos" emitidos anteriormente, dos lotes doados, não edificados.
{ #art-1 }

Parágrafo único - Os lotes retomados serão doados de acordo com as leis municipais vigentes constantes das [leis nº 381/98](../1998/lei-381-1998.md); 389/98 e 404/98, respectivamente de 08 de janeiro de 1998; 16 de abril de 1998 e 20 de agosto de 1998.

**Artigo 2º** - Ao promover a doação dos lotes remanescentes sem edificação, completamente vazio, todos os títulos ou documentos existentes em poder do donatário, ficam revogados.
{ #art-2 }

**Artigo 3º** - Para a doação dos lotes cancelados ou revogados a municipalidade somente expedirá autorização para edificação nos prazos definidos na legislação pertinente.
{ #art-3 }

Parágrafo único - Os títulos definitivos só serão expedidos após vistoria no local, para a constatação do término da edificação.

**Artigo 4º** - As construções parciais de lotes doados, e com prazos vencidos para edificações serão retomadas e as benfeitorias indenizadas pelo novo dono.
{ #art-4 }

**Artigo 5º** - As possíveis vendas por parte dos donatários, edificados parcialmente ou não construídas, somente serão objeto de transferência ou expedição de títulos definitivos, quando estiver totalmente edificados, mediante o parágrafo único do artigo terceiro desta lei.
{ #art-5 }

**Artigo 6º** - Esta lei será regulamentada por decreto no prazo de 30 (trinta) dias.
{ #art-6 }

**Artigo 7º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-7 }

Batayporã-MS, 29 de março de 1999

AGENOR GAMBA
