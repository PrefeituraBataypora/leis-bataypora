**LEI Nº-432/99, De 15 de abril de 1999.**
{ .centro }

Dispõe sobre denominação de Vila, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Artigo 1º** - O loteamento anexo a Vila Toquinho, passa a denominar-se, Vila "EDUVIRGES REINA RIBEIRO".
{ #art-1 }

**Artigo 2º** - Para cobertura das despesas decorrentes da presente lei, correrão por conta de dotação própria consignada no orçamento vigente, suplementadas se necessário.
{ #art-2 }

**Arttigo 3º** - Esta Lei entra em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Artigo 4º** - Revogadas as disposições em contrário.
{ #art-4 }

Batayporã-MS, 15 de abril de 1999

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria Municipal de Administração, e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
