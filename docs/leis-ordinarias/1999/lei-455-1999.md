**LEI Nº-455/99, De 21 de dezembro de 1999.**
{ .centro }

Promove doação de imóvel que especifica, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Artigo 1º** - Fica o Município autorizado a promover a doação a MILTON FERNANDES AGUIAR, portador da Cédula de Identidade RG n° [omitido] SSP/PR, constituído do lote territorial urbano com a seguinte característica e confrontação:
{ #art-1 }

"Pela frente confronta-se com o prolongamento da Rua Alagoas, numa extensão de 20,00 metros.

Pelo lado direito, de quem, do terreno olha para a Rua, confronta-se com o loteamento da senhora Elizabeth, numa extensão de 40,00 metros.

Pelo lado esquerdo, confronta-se com o remanescente do lote, numa extensão de 40,00 metros.

E, pelos fundos, confronta-se com o Recinto "Diego Sanches Marchi", numa extensão de 20,00 metros., perfazendo área total de 800,00 m².

**Artigo 2º** - A presente doação destina-se a construção exclusivamente para fábrica de produtos de limpeza e similares.
{ #art-2 }

**Arttigo 3º** - O prazo para edificação e funcionamento é de 6 (seis) meses, a partir da efetivação da doação.
{ #art-3 }

**Artigo 4º** - O inadimplemento dos encargos o imóvel retornará ao domínio do município.
{ #art-4 }

**Artigo 5º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-5 }

**Artigo 6º** - Revogadas as disposições em contrário.
{ #art-6 }

Batayporã-MS, 21 de dezembro de 1999

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrado em livro próprio da Secretaria de Administração e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
