**LEI Nº-442/99, De 28 de junho de 1999.**
{ .centro }

Autoriza abertura de Crédito Suplementar, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Poder Público Municipal autorizado a abrir Crédito Suplementar até 30% do valor global do Orçamento Vigente ([Lei nº 423/98](../1998/lei-423-1998.md) de 17/12/98), do Fundo Municipal de Promoção e Assistência Social.
{ #art-1 }

**Art. 2º** - Para cobertura das despesas oriundas do artigo 1º desta lei, correrão por conta de anulação total ou parcial do Orçamento Vigente, nos termos do Art. 43, § 1º, inciso III, da Lei nº 4.320/86.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, 28 de junho de 1999.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
