**LEI Nº-426/99, De 29 de março de 1999.**
{ .centro .revogado .tudo }

Estabelece Subvenção Social a APAE de Nova Andradina-MS, e dá outras providências.
{ .revogado .tudo }

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;
{ .revogado .tudo }

**Art. 1º** - Fica o Município autorizado a conceder Subvenção Social a APAE (Associação de Pais e Amigos dos Excepcionais de Nova Andradina-MS), no valor de R$ 2.000,00 (dois mil reais) por mês, a partir do mês de competência de fevereiro de 1999.
{ #art-1 .revogado }

**Art. 2º** - A entidade beneficiada da Subvenção Social, do art. 1º desta Lei, obriga-se na prestação de Contas dentro das normas ditadas pelo Egrégio Tribunal de Contas do Estado.
{ #art-2 .revogado }

**Art. 3º** - As despesas decorrentes da execução da presente lei, correrão por conta da dotação orçamentária específica, suplementadas se necessário for.
{ #art-3 .revogado }

**Art. 4º** - Esta Lei entra em vigor na data de sua publicação, revogadas as disposições em contrário.
{ #art-4 .revogado }

**Art. 5º** - Revogam-se as disposições em contrário, especialmente todos os termos da [Lei Municipal nº 383/98](../1998/lei-383-1998.md) de 09 de março de 1998.
{ #art-5 .revogado }

Prefeitura Municipal de Batayporã-MS, 29 de março de 1999.
{ .revogado .tudo }

AGENOR GAMBA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio da Secretaria Municipal de Administração, e afixada em local de costume em data supraçitada.
{ .revogado .tudo }

JESSÉ DOS SANTOS BEXIGA
{ .centro .revogado .tudo }

Secretário de Administração e Finanças
