**Lei nº. 919/2011 de 24 de agosto de 2011.**
{ .centro .revogado .tudo }

“Institui taxas relacionadas ou decorrentes da atuação institucional do Serviço de Inspeção Municipal – SIM do município de Batayporã-MS, e dá outras providências”.
{ .revogado .tudo }

**EDSON PERES IBRAHIM**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Observado o disposto na [Lei Municipal N° 768/2008](../2008/lei-768-2008.md), de 13 de maio de 2008, ficam instituídas as taxas relacionadas ou decorrentes da atuação institucional do Serviço de Inspeção Municipal – SIM do município de Batayporã-MS.
{ #art-1 .revogado }

**Art. 2º** As taxas ora instituídas têm como hipóteses de incidência:
{ #art-2 .revogado }

I - a prática de atos em razão do exercício do poder de polícia;
{ .revogado .tudo }

II - os fatos que configuram a utilização, efetiva ou potencial, de serviços públicos específicos e divisíveis, prestados ao contribuinte ou postos à sua disposição.
{ .revogado .tudo }

**Art. 3º** Contribuinte da taxa é a pessoa natural ou jurídica da qual o Serviço de Inspeção Municipal – SIM prestou qualquer tipo de serviço:
{ #art-3 .revogado }

I - sobre a qual é exercido, por qualquer meio, de qualquer forma e independentemente do tempo de duração, o poder de polícia por agente do SIM;
{ .revogado .tudo }

II - que utiliza, efetiva ou potencialmente, serviço público específico e divisível prestado ou posto à sua disposição pelo SIM.
{ .revogado .tudo }

**Art. 4º** Responsável pelo pagamento do valor da taxa devida é a pessoa que solicitou o serviço.
{ #art-4 .revogado }

**Art. 5º** As alíquotas e as bases de cálculo das taxas estão caracterizadas englobadamente nas Tabelas constantes nos Anexos I e II, representadas quantitativamente, por determinados percentuais ou fatores multiplicadores da Unidade Fiscal Estadual de Referência de Mato Grosso do Sul (UFERMS).
{ #art-5 .revogado }

**Art. 6º** Relativamente ao tempo de pagamento, o valor da taxa deve ser pago conforme as disposições do regulamento, observado o disposto nas Tabelas dos Anexos I e II.
{ #art-6 .revogado }

**Art. 7º** São isentos do pagamento da taxa os atos em razão do exercício do poder de polícia e as prestações de serviços em proveito de órgãos e entidades da administração direta e indireta do Poder Executivo Estadual.
{ #art-7 .revogado }

**Art. 8º** A cobrança de determinadas taxas pode ser dispensada nos casos em que, para atender a relevante interesse administrativo ou sanitário:
{ #art-8 .revogado }

I - o SIM:
{ .revogado .tudo }

a) tenha interesse no cadastramento, inscrição, licenciamento ou registro de estabelecimentos agropecuários de pequeno porte, especialmente daqueles situados em assentamentos, observadas as prescrições do regulamento;
{ .revogado .tudo }

II - os agentes do SIM, diante da necessidade ou em certos casos especiais, devam:
{ .revogado .tudo }

a) realizar exames clínicos, laboratoriais ou necrópsicos;
{ .revogado .tudo }

b) emitir documentos essenciais ou de uso obrigatório substitutivos de documentos originais ou que complementem documentos originais.
{ .revogado .tudo }

**Art. 9º** O valor da taxa deve ser pago em postos bancários, devidamente autorizados a receber os valores dos tributos de competência do Município.
{ #art-9 .revogado }

Parágrafo único. A autoridade competente pode, em casos ou situações excepcionais, autorizar o recebimento do valor da taxa em locais ou por estabelecimentos ou pessoas diversos daqueles compreendidos nas disposições do *caput*.
{ .revogado .tudo }

**Art. 10.** A falta de pagamento, a insuficiência quantitativa no pagamento ou o pagamento intempestivo sujeita o infrator às multas nos percentuais seguintes, calculados sobre os valores das taxas devidas:
{ #art-10 .revogado }

I - no caso de denúncia espontânea:
{ .revogado .tudo }

a) 2% (dois por cento) para o pagamento efetuado no prazo de quinze dias contados da data do vencimento do débito;
{ .revogado .tudo }

b) 4% (quatro por cento) para o pagamento efetuado depois do prazo de quinze dias e até o trigésimo dia seguinte ao da data do vencimento do débito;
{ .revogado .tudo }

c) 8% (oito por cento) para o pagamento efetuado depois do prazo de trinta dias e até o sexagésimo dia seguinte ao da data do vencimento do débito;
{ .revogado .tudo }

d) 20% (vinte por cento) para o pagamento efetuado depois do prazo de sessenta dias e até o nonagésimo dia seguinte ao da data do vencimento do débito;
{ .revogado .tudo }

e) a multa estabelecida na alínea “***d***”, mais 2% (dois por cento) ao mês ou fração, para o pagamento efetuado depois do nonagésimo dia seguinte ao da data do vencimento do débito;
{ .revogado .tudo }

II - no caso de exigência formalizada em auto de infração: 100% (cem por cento), observadas as reduções de:
{ .revogado .tudo }

a) 50% (cinquenta por cento) para o pagamento efetuado no prazo de trinta dias contados da data do recebimento da notificação do lançamento;
{ .revogado .tudo }

b) 30% (trinta por cento) para o pagamento efetuado depois do prazo estabelecido na alínea “***a***” e até a data do ajuizamento da ação de execução fiscal.
{ .revogado .tudo }

Parágrafo único. O pagamento do valor de multa implica o pagamento do valor do principal acrescido dos demais encargos decorrentes da mora.
{ .revogado .tudo }

**Art. 11.** Competem aos agentes do SIM os atos típicos de lançamento, arrecadação, controle e fiscalização das taxas, sem prejuízo do exercício da competência originária dos agentes da Tributação Municipal para a prática dos atos de lançamento e fiscalização dos tributos de competência do Município.
{ #art-11 .revogado }

Parágrafo único. A competência dos agentes administrativos em referência compreende, inclusive, a aplicação de penalidades pelo inadimplemento da obrigação tributária ou pelo descumprimento de dever jurídico instrumental.
{ .revogado .tudo }

**Art. 12.** Os recursos financeiros arrecadados em decorrência da cobrança de taxas, preços e multas pelo SIM, no âmbito das ações de interesse deste orgão:
{ #art-12 .revogado }

!!! info "Redação dada pela Lei nº 1233/2020"
    Nova redação deste artigo, dada pelo [art. 2º da Lei nº 1233/2020](../2020/lei-1233-2020.md#art-2):

    “Art. 12 – Os recursos financeiros arrecadados em decorrência da cobrança de taxas, preços e multas pelo SIM, no âmbito das ações de interesse deste órgão, sujeitam-se, dentre outras, às seguintes regras:

    I - Devem ser aplicados exclusivamente no SIM, SENDO PERMITIDO para pagamento, a qualquer título, de despesa de pessoal NO PERCENTUAL MAXIMO DE 60%;

    II - NO MÍNIMO 40% devem ser destinados a fundos ou reservas financeiras para aquisição de Infraestrutura para serviço”.

I - devem ser aplicados exclusivamente no SIM, vedada a aplicação para o pagamento, a qualquer título, de despesas de pessoal;
{ .revogado .tudo }

II - podem ser destinados a fundos ou reservas financeiras para as aquisições de infraestrutura para o serviço.
{ .revogado .tudo }

**Art. 13.** Cabe ao regulamento dispor complementarmente sobre as disposições desta Lei.
{ #art-13 .revogado }

**Art. 14.** Esta Lei entra em vigor na data de sua publicação e/ou afixação, revogadas as disposições em contrário.
{ #art-14 .revogado }

Prefeitura Municipal de Batayporã-MS, aos vinte e quatro dias do mês de agosto de 2011.
