**Lei nº. 1.229, de 24 de março de 2020.**
{ .centro .revogado .tudo }

“Altera dispositivos da [Lei nº. 1090/2015](../2015/lei-1090-2015.md) de 24 de março de 2015, e dá outras providências”.
{ .revogado .tudo }

O **PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL**, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** O artigo 2º da [Lei nº 1090/2015](../2015/lei-1090-2015.md#art-2) de 24 de março de 2015, passa a vigorar com a seguinte redação:
{ #art-1 .revogado }

> “Art. 2º ..........
> { .revogado .tudo }
>
> Parágrafo único. O Fundo de Habitação de Interesse Social – FHIS fica vinculado à Secretária Municipal de Obras, Desenvolvimento Econômico, Turismo e Meio Ambiente.”
> { .revogado .tudo }

**Art. 2º** Revogam-se as disposições em contrário.
{ #art-2 .revogado }

**Art. 3º** Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 .revogado }

Batayporã-MS., 24 de março de 2020.
{ .revogado .tudo }
