**LEI Nº-049/85, De 14 de junho de 1985.**
{ .centro }

Dispõe sobre doação de imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a doar a área denominada "Campo de Aviação", na Gleba Caiuás, parte integrante da Fazenda Samambaia de até 32.255m² para a COOPAVIL-Cooperativa Agroindustrial do Vale do Ivinhema Ltda construir um Laticínio.
{ #art-1 }

Parágrafo Único - A área destinar-se-á a construção e instalação industrial de Laticínio.

**Art. 2º** - O prazo para construção do Laticínio será de 12 (doze) meses, a partir da data da lavratura da escritura de doação, com seis meses de carência.
{ #art-2 }

**Art. 3º** - Não atendida as determinações do artigo anterior, o imóvel doado retornará ao patrimônio do Município.
{ #art-3 }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Bataiporã-MS, aos catorze dias do mês de junho de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }
