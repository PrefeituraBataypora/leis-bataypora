**LEI Nº-56/85, De 30 de outubro de 1985.**
{ .centro }

Declara de Utilidade Pública o "CENTRO RURAL DO BAIRRO DA FESTA", e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica declarado de Utilidade Pública para todos os efeitos legais, o CENTRO RURAL DO BAIRRO DA FESTA, entidade sem fins lucrativos, com sede no Bairro do mesmo nome, no Município de Bataiporã-MS.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-2 }

Prefeitura Municipal de Bataiporã-MS, aos trinta dias do mês de outubro de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
