> Autoriza o Poder Executivo Municipal a celebrar Convênio com a Televisão Cidade Modelo Ltda. (TV Caiuás), e dá outras providências.

**LEI Nº-53/85, De 20 de setembro de 1985.**
{ .centro .revogado .tudo }

Autoriza o Poder Executivo Municipal a celebrar Convênio com a Televisão Cidade Modelo Ltda. (TV Caiuás), e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.
{ .revogado .tudo }

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica o Poder Executivo autorizado a celebrar Convênio com a Televisão Cidade Modelo Ltda. (TV Caiuás), até o valor de Cr$-40.000.000 (quarenta milhões de cruzeiros).
{ #art-1 .revogado }

**Art. 2º** - O Convênio supra citado terá finalidade de divulgação publicitária de interesse do Município.
{ #art-2 .revogado }

Parágrafo Único - Matéria objeto do "Caput" deste artigo, será autorizada na seguinte proporção:
{ .revogado .tudo }

75% pelo Executivo e
{ .revogado .tudo }

25% pelo Legislativo.
{ .revogado .tudo }

**Art. 3º** - Se dentro de 90 (noventa) dias a Empresa não instalar uma repetidora de suas imagens nesta Comarca, com direcionamento de imagens para a nossa cidade, será revogada a presente Lei e o valor do Convênio revertido à municipalidade, acrescido de juros e correção monetária, no prazo de 90 (noventa) dias a partir da revogação da Lei.
{ #art-3 .revogado }

Parágrafo Único - Após a instalação da repetidora e consequentemente transmissão de imagens, é que ocorrerá a veiculação publicitária, objeto do Convênio citado.
{ .revogado .tudo }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão à conta do orçamento vigente.
{ #art-4 .revogado }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 .revogado }

Prefeitura Municipal de Bataiporã-MS, aos vinte dias do mês de setembro de 1985.
{ .revogado .tudo }

Dr. JOÃO JAMIL MELLA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
{ .centro .revogado .tudo }
