**LEI Nº-59/85, De 13 de novembro de 1985.**
{ .centro .revogado .tudo }

Dispõe sobre criação de Fundo da Assistência Social do Município de Bataiporã, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e ele sanciona e promulga a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica criado junto ao Gabinete do Prefeito (ou outra unidade administrativa da Prefeitura Municipal) o Fundo de Assistência Social do Município, com o objetivo de mobilização da Comunidade para atender às necessidades e problemas sociais locais.
{ #art-1 .revogado }

**Art. 2º** - O Fundo será dirigido por um Conselho Deliberativo.
{ #art-2 .revogado }

**Art. 3º** - São atribuições do Conselho Deliberativo:
{ #art-3 .revogado }

I - fazer o levantamento das principais necessidades e aspirações da comunidade;
{ .revogado .tudo }

II - levantar recursos humanos, materiais, financeiros e outros mobilizáveis na comunidade;
{ .revogado .tudo }

III - definir e encaminhar soluções possíveis para os problemas levantados;
{ .revogado .tudo }

IV - valorizar, estimular e apoiar iniciativas da comunidade voltadas para a solução dos problemas locais;
{ .revogado .tudo }

V - promover articulações e atuar integradamente com unidades administrativas da Prefeitura Municipal ou outras entidades públicas privadas.
{ .revogado .tudo }

**Art. 4º** - O Conselho Deliberativo será composto de sete membros sob a Presideência da esposa do Prefeito Municipal, ou por pessoa de livre indicação deste.
{ #art-4 .revogado }

**Art. 5º** - O mandato dos membros do Conselho Deliberativo será de dois anos, renovável a convite, cumprindo-lhes exercer suas funções até a designação de seus substitutos.
{ #art-5 .revogado }

§1º - O Prefeito poderá substituir, temporária ou definitivamente, os membros impedidos do exercício de suas funções.
{ .revogado .tudo }

§2º - As funções de membro do Conselho não serão remuneradas, a qualquer título, sendo, porém, consideradas como serviço público relevante.
{ .revogado .tudo }

§3º - Extingue-se o mandato dos membros do Conselho Deliberativo ao término da legislatura.
{ .revogado .tudo }

**Art. 6º** - Compete ao Presidente do Conselho Deliberativo tomar todas todas as medidas administrativas, financeiras e orçamentárias para a gestão do Fundo.
{ #art-6 .revogado }

Parágrafo Único - A conta bancária do Fundo será movimentada conjuntamente pelo Presidente e por um membro do Conselho Deliberativo, designado por este para as funções de Tesoureiro.
{ .revogado .tudo }

**Art. 7º** - Constituirão receitas do Fundo de Assistência Social do Município:
{ #art-7 .revogado }

I - contribuições, donativos e legados de pessoas físicas ou jurídicas de direito privado;
{ .revogado .tudo }

II - auxílios, subvenções ou contribuições;
{ .revogado .tudo }

III - outras vinculações de receitas municipais cabíveis
{ .revogado .tudo }

IV - receitas auferidas pela aplicação no mercado de capitais;
{ .revogado .tudo }

V - quaisquer outras receitas que lhe possam ser destinadas.
{ .revogado .tudo }

Parágrafo Único - Todos os recursos destinados deverão ser contabilizados como receita orçamentária municipal e a ele alocados através de dotações consignadas na Lei Orçamentária ou de créditos adicionais, obedecendo sua aplicação às normas gerais de direito financeiro.
{ .revogado .tudo }

**Art. 8º** - O Conselho Deliberativo emitirá mensalmente um balancete demonstrativo da receita e da despesa do mês anterior e, anualmente, o Balanço Geral do exercício.
{ #art-8 .revogado }

**Art. 9º** - Os Servidores que forem colocados à disposição do Fundo de Assistência Social do Município, sem prejuízo de vencimentos e demais vantagens, não poderão perceber vantagem pecuniária de qualquer espécie exceto as decorrentes da legislação comum aos Servidores do Município.
{ #art-9 .revogado }

**Art. 10** - O Fundo, criado por esta Lei, receberá, dos órgãos de administração e finanças da Prefeitura Municipal, apoio direto e imediato para consecução de seus objetivos.
{ #art-10 .revogado }

**Art. 11** - As despesas decorrentes com a execução desta Lei, correrão às contas do orçamento em vigor, suplementadas se necessário.
{ #art-11 .revogado }

**Art. 12** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-12 .revogado }

Prefeitura Municipal de Bataiporã-MS., aos treze dias do mês de novembro de 1985.
{ .revogado .tudo }

Dr. JOÃO JAMIL MELLA
