**LEI Nº-50/85, De 14 de agosto de 1985.**
{ .centro }

Dispõe sobre a abertura de créditos suplementares no orçamento do Município para o exercício financeiro de 1985, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Exaurido o limite constante da Lei Orçamentária ([Lei nº-034/84, de 21.11.84](../1984/lei-34-1984.md), art. 4º, ítem II) do presente exercício, fica o Poder Executivo autorizado a suplementar mais 20% (vinte por cento) da despesa orçada.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS., aos catorze dias do mês de agosto de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em lugar de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
