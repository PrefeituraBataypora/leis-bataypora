**LEI Nº-55/85, De 23 de outubro de 1985.**
{ .centro }

Dispõe sobre aquisição e doação de imóveis, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir imóveis urbanos com área até 1.260m².
{ #art-1 }

**Art. 2º** - Adquiridos os imóveis na forma do artigo anterior, fica também autorizado a efetuar a doação de até 1.260m², para a Caixa Econômica Federal construir sua Agência própria neste Município.
{ #art-2 }

Parágrafo Único - O prazo para a construção será de 12 (doze) meses, com 06 (seis) meses de carência, a partir da aprovação da presente Lei.

**Art. 3º** - Não cumpridas as exigências do parágrafo único do artigo anterior, retornará ao domínio do Município o imóvel doado.
{ #art-3 }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e três dias do mês de outubro de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
