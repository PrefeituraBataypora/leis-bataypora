**LEI Nº-039/85, De 10 de janeiro de 1985.**
{ .centro }

Autoriza o Sr. Prefeito Municipal a se constituir em depositário fiel, perante a Justiça Federal em Mato Grosso do Sul.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Sr. Prefeito Municipal, autorizado a assinar o termo de Depositário Fiel, perante a Justiça Federal em Mato Grosso do Sul, de um caminhão sob cautela, para uso da Administração.
{ #art-1 }

**Art. 2º** - Fica também autorizado a efetuar o seguro total do referido veículo, contra furto, roubo, acidente e incêndio.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos dez dias do mês de janeiro de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, livro nº-06 e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
