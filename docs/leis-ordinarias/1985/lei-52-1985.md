**LEI Nº-52/85, De 14 de agosto de 1985.**
{ .centro }

Dispõe sobre crédito suplementar adicional no orçamento vigente, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a abrir crédito suplementar, junto ao Deptº de Contabilidade no valor de Cr$-79.000.000 (setenta e nove milhões de cruzeiros) para cobertura das seguintes dotações orçamentárias:
{ #art-1 }

| Dotação | Valor |
|---|---:|
| **Órgão: Poder Legislativo** | |
| Un. Orç.: Câmara Municipal | |
| Elemento: 3100 - Despesas de Custeio | |
| Sub-elemento: 3111 - Pessoal Civil | Cr$-37.000.000 |
| 3132 - Outros Serv. e Encargos | Cr$-34.000.000 |
| 3120 - Material de Consumo | Cr$-6.000.000 |
| **TOTAL** | **Cr$-77.000.000** |
| **Órgão: Poder Legislativo** | |
| Un. Orç.: Câmara Municipal | |
| Elemento: 4100 - Investimentos | |
| Sub-elemento: 4120 - Equip. e Material Permanente | Cr$-2.000.000 |
| **TOTAL** | **Cr$-2.000.000** |
| **TOTAL GERAL DA SUPLEMENTAÇÃO** | **Cr$-79.000.000** |

**Art. 2º** - O crédito suplementar de que trata esta Lei será compensado de acordo com o ítem III, do §1º, do art. 43, da Lei nº-4320/64, pela anulação de igual valor da Reserva de Contingência, constante no orçamento em vigor. ([Lei nº-034/84, de 21.11.84](../1984/lei-34-1984.md)).
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos catorze dias do mês de agosto de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
