**LEI Nº-041/85, De 23 de abril de 1985.**
{ .centro }

Dispõe sobre a criação de cargo, fixa os respectivos vencimentos e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica criado o cargo de AUXILIAR LEGISLATIVO, no quadro de Servidores da Câmara Municipal de Bataiporã-MS.
{ #art-1 }

**Art. 2º** - Fica fixado em dois salários mínimos vigente a título de vencimentos mensal, ao titular do cargo constante no artigo anterior.
{ #art-2 }

**Art. 3º** - As despesas decorrentes da execução da presente Lei correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e três dias do mês de abril de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada no livro próprio de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
