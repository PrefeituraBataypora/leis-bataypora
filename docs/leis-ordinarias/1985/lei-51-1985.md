**LEI Nº-51/85, De 14 de agosto de 1985.**
{ .centro }

Dispõe sobre aquisição e doação de imóveis, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir, desapropriar ou dispor de imóveis de propriedade do Município para construção de uma Unidade de Segurança, com área de até 2.100m².
{ #art-1 }

**Art. 2º** - Adquiridos os imóveis na forma do artigo anterior, fica também o Poder Executivo autorizado a efetuar a doação para o Estado de Mato Grosso do Sul, com o fim específico de construir uma Unidade de Segurança.
{ #art-2 }

Parágrafo Único - A Unidade de Segurança de que trata o presente artigo, será construída dentro dos padrões adotados pelo Estado.

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Fica revogada a Lei nº-408/82, de 31 de agosto de 1982, e as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos catorze dias do mês de agosto de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
