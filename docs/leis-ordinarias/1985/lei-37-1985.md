**LEI Nº-037/85, De 10 de janeiro de 1985.**
{ .centro }

Dispõe sobre aquisição de imóveis rurais, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir dois imóveis rurais, situados neste Município, na 2ª linha da Gleba Caiuás, denominados chácaras nº-23 e 24, com 1 alqueire cada uma ou seja, 2 alqueires paulista ou ainda 4,84ha, imóveis localizados no prolongamento da Av. Brasil, confrontando-se com a Rodovia Alcides Sãovesso e chácara nº-22 da 2ª linha.
{ #art-1 }

**Art. 2º** - O valor da compra não poderá ultrapassar ao da avaliação determinada pela Comissão Especial, constituída para o fim específico.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS, aos dez dias do mês de janeiro de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, livro nº-06 e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
