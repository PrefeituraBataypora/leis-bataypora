**LEI Nº-046/85, De 07 de junho de 1985.**
{ .centro }

Incorpora ao calendário de festividades do Município, A FESTA DO SERENO, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica incorporada ao calendário de festividades do Município de Bataiporã-MS., a FESTA DO SERENO, a partir do presente exercício.
{ #art-1 }

**Art. 2º** - A FESTA DO SERENO será realizada no dia 28 de junho, no período noturno e nos moldes ocorridos nas quatro versões anteriores.
{ #art-2 }

**Art. 3º** - Para a FESTA DO SERENO será formada uma Comissão dirigente composta de 3 a 5 membros, que organizará sua programação e normas de participação das entidades interessadas.
{ #art-3 }

**Art. 4º** - O Poder Executivo oferecerá ao evento apoio administrativo-financeiro, na forma que for combinado com a Comissão dirigente.
{ #art-4 }

**Art. 5º** - As entidades participantes auferirão as rendas que obtiverem com seu trabalho desenvolvido na FESTA DO SERENO.
{ #art-5 }

**Art. 6º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Bataiporã-MS., aos sete dias do mês de junho de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
