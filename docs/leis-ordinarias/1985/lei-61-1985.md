**LEI Nº-61/85, De 13 de novembro de 1985.**
{ .centro }

Dispõe sobre crédito suplementar adicional no orçamento vigente, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a abrir crédito suplementar, junto ao Departamento de Contabilidade no valor de Cr$-13.000.000 (treze milhões de cruzeiros) para cobertura das seguintes dotações orçamentárias:
{ #art-1 }

| Dotação | Valor |
|---|---:|
| **Órgão: Poder Legislativo** | |
| Un. Orç.: Câmara Municipal | |
| Elemento: 3100 - Despesas de Custeio | |
| Sub-elemento: 3111 - Pessoal Civil | Cr$-5.000.000 |
| 3132 - Outros Serv. e Encargos | Cr$-8.000.000 |
| **TOTAL** | **Cr$-13.000.000** |

**Art. 2º** - O crédito suplementar de que trata esta Lei será compensado de acordo com o artigo 43, §1º da Lei nº-4320/64.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS., aos treze dias do mês de novembro de 1985.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
