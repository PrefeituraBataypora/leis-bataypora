**LEI Nº-479/00, De 20 de novembro de 2000.**
{ .centro }

Institui o Programa "KIT BEBÊ", e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, no uso das atribuições legais, faz saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a instituir o programa "KIT BEBÊ", no âmbito do Município de Batayporã-MS.
{ #art-1 }

Parágrafo único - A coordenação do programa instituído nos têrmos do caput desse artigo, ficará sob a responsabilidade da Secretaria Municipal de Promoção e Assistência Social.

**Art. 2º** - O KIT BEBÊ deverá constar obrigatoriamente além de gaze e de um termômetro para medir temperatura, os medicamentos necessários para o tratamento do coto umbilical dos recem nascidos.
{ #art-2 }

**Art. 3º** - Acompanhará o KIT BEBÊ, também um folheto explicativo dando todas as informações sobre o uso adequado dos materiais e orientação sobre todos os cuidados e preocupações com os bebês.
{ #art-3 }

**Art. 4º** - As despesas decorrentes da execução da presente lei correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-4 }

**Art. 5º** - Esta Lei entra em vigor na data de sua publicação ou afixação.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã 20 de novembro de 2000.

Agenor Gamba
{ .centro }

Prefeito Municipal
{ .centro }
