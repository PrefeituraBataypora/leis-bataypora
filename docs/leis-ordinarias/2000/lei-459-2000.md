**LEI Nº-459/00, De 01 de março de 2000.**
{ .centro }

Dispõe sobre aquisição de imóveis para fins que especifica, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Artigo 1º** - Fica o Município autorizado a adquirir terrenos urbanos de Diego Júlio Sanches e sua esposa, que se destina a construção de um Centro Cultural e Recreação.
{ #art-1 }

**Artigo 2º** - As datas a serem adquiridas possui as seguintes características, lote territorial urbano com 14,00 metros a da Rua Goiás por 45,00 metros de frente aos fundos perfazendo o total de 630,00 m², constituindo o lote nº 04 da quadra 11. Um terreno com 14,00 metros de frente por 30,00 metros de frente aos fundos, perfazendo 420,00 m², constituindo o lote 03 da quadra 11 na Rua Goiás. O total da aquisição dos dois terrenos perfazem 1.050,00 m².
{ #art-2 }

**Arttigo 3º** - A aquisição obedecerá o limite da avaliação, pela avaliação constituída para esse fim.
{ #art-3 }

**Artigo 4º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-4 }

**Artigo 5º** - Revogadas as disposições em contrário.
{ #art-5 }

Batayporã-MS, 01 de março de 2000

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
