**LEI Nº-470/00, De 01 de junho de 2000.**
{ .centro }

Estabelece Subvenção Social para APAE ASSOCIAÇÃO DOS PAIS E AMIGOS DOS EXCEPCIONAIS DE NOVA ANDRADINA, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica o Poder Executivo Municipal, autorizado a conceder subvenção social a APAE- ASSOCIAÇÃO DE AMIGOS DOS EXCEPCIONAIS, de Nova Andradina- MS, no valor de R$ 2.500,00 (dois mil e quinhentos reais) mensal, a partir do mês de maio p.v.
{ #art-1 }

**Art. 2º** - A Entidade beneficiada, obriga-se a prestação de contas, dentro das normas do Egrégio Tribunal de Contas do Estado de Mato Grosso do Sul.
{ #art-2 }

**Art. 3º** - As despesas oriúndas da presente lei, correrão por conta da dotação Orçamentária constante do Orçamento vigente, suplementadas se necessário.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação retroagindo seus efeitos a partir de 1º de maio de 2000.
{ #art-4 }

**Art. 5º** - Ficam revogadas as demais disposições da [lei nº 426/99](../1999/lei-426-1999.md), de 29 de março de 1999.
{ #art-5 }

Batayporã-MS, 01 de junho de 2000.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração e afixada em local de costume em data acima citada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
