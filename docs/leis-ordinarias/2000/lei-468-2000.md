**LEI Nº-468/00, De 24 de maio de 2000.**
{ .centro }

Intitui o Projeto "AGENTE JOVEM", e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica Instituído o Projeto AGENTE JOVEM Municipal, para atuação junto a Comunidade na área social na promoção de reversão de indicadores sociais para integrá-los junto a sociedade.
{ #art-1 }

Parágrafo único - O Projeto Municipal será integrado em até 50 (cinquenta ) Jovens inscritos e cadatrados pela Secretaria Municipal de Promoção e Assistência Social.

**Art. 2º** - A manutenção do Projeto AGENTE JOVEM de desenvolvimento social e humano, terão sua formação constituídos da faixa etária de 15, 16 e 17 anos de idade, para integração do adolescente vitimado na sociedade.
{ #art-2 }

**Art. 3º** - As despesas por cada jovem será no valor de R$ 65,00 (sessenta e cinco reais) mensal "per capta", acrescidos de R$ 150,00 (cento e cinquenta reais) mensal para uma orientadora, na tentativa de conceder a cidadania e os direitos humanos.
{ #art-3 }

!!! info "Parágrafo único acrescentado pela Lei nº 472/2000"
    O [art. 1º da Lei nº 472/2000](lei-472-2000.md#art-1) acrescentou a este artigo o parágrafo único:

    "Parágro Único - pagamento a instrutores com 140 horas/aula, a razão de R$ 12,00 (doze reais) por hora, perfazendo um total de R$ 1.680,00 (um mil seiscentos e oitenta reais),do Projeto Agente Jovem".

**Art. 4º** - As despesas oriundas da presente Lei correrão por conta de dotação própria consignada no orçamento vigente ou através, se necessário for, de Crédito Especial para o presente fim.
{ #art-4 }

**Art. 5º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Batayporã-MS, 24 de maio de 2000.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }
