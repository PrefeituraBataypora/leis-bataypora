**LEI Nº-472/00, De 20 de junho de 2000.**
{ .centro }

Acrescenta Parágrafo Único no [Artigo 3º da Lei 468/2000](lei-468-2000.md#art-3) de 24 de maio de 2000, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã, Estado de Mato Grosso do Sul, no uso de suas atribuições legais que lhes são conferidas por lei, Faz saber que a Câmara Municipal aprovou e eu promulgo e sanciono a seguinte lei;

**Art. 1º** - Fica acrescentado parágrafo único no [artigo 3º da Lei 468/2000](lei-468-2000.md#art-3) de 24 de maio de 2000, a seguinte redação:
{ #art-1 }

> "Parágro Único - pagamento a instrutores com 140 horas/aula, a razão de R$ 12,00 (doze reais) por hora, perfazendo um total de R$ 1.680,00 (um mil seiscentos e oitenta reais),do Projeto Agente Jovem".

**Art. 2º** - As despesas correrão por conta da Dotação própria consignada no orçamento Vigente, suplementadas se necessário
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-3 }

**Art. 4º** - Ficam revogadas as demais disposições em contrário.
{ #art-4 }

Batayporã-MS, 20 de junho de 2000.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da secretaria de Administração e afixada em local de costume em data acima citada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
