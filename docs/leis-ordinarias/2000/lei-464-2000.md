**LEI Nº-464/00, De 30 de março de 2000.**
{ .centro }

Dispõe sobre denominação de Vila, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - O conglomerado de casas existentes à margem esquerda da Rodovia MS- 134 "ALCIDES SÃOVESSO", no sentido Batayporã/Nova Andradina, no trecho entre o trevo da Avenida Brasil, até o trevo da Rodovia MS-276, que dá acesso à Anaurilândia, passa a denominar-se VILA MONTEIRO.
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente lei, correrão por conta de verba própria constante no orçamento em vigor, suplementada se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entra em vigor na data de sua publicação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Batayporã-MS, 30 de março de 2000.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração e afixada em local de costume em data acima citada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
