**LEI Nº 461/2000, de 09 de março de 2000**
{ .centro }

Dispõe sobre alteração da [Lei nº 397/98](../1998/lei-397-1998.md) de 25-5-98, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Ficam acrescentados no quadro do provimento efetivo da Prefeitura Municipal de Batayporã-MS, as seguintes vagas:
{ #art-1 }

I- 01 (uma) vaga de Advogado

II- 01 (uma) vaga de Fisioterapeuta

III- 02 (duas) vagas de Assistente de Administração

IV- 01 (uma) vaga de Merendeira

V- 01 (uma) vaga para Auxiliar de Farmácia

VI- 01 (uma) vaga de Professor II

VII- 04 (quatro) vagas de Auxiliar de Serviços Diversos - Saúde

VIII- 02 (duas) vagas de Auxiliar de Serviços Diversos - Limpeza

**Art. 2º** - A tabela 1 do anexo II e a tabela 2 do Anexo II, passam a vigorar com a redação constante da Lei nº 424/999 de 22 de março/99.
{ #art-2 }

**Art. 3º** - As despesas oriundas da presente Lei, correrão por conta de dotação própria consignada no Orçamento vigente.
{ #art-3 }

**Art. 4º** - Esta lei entra em vigor na data de sua publicação.
{ #art-4 }

**Art. 5º** - Revogam as disposições em contrário.
{ #art-5 }

Batayporã-MS, 09 de março de 2000.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração e afixada em local de costume em data supracitada.

JESSÉ DOS SANTOS BEXIGA
{ .centro }

Secretário de Administração e Finanças
{ .centro }
