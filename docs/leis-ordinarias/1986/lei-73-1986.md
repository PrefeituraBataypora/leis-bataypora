**LEI Nº-73/86, De 02 de outubro de 1986.**
{ .centro }

Dispõe sobre aumento de vencimentos dos Servidores da Câmara Municipal de Bataiporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento salarial sobre os vencimentos dos Servidores da Câmara Municipal de Bataiporã-MS., na ordem de 10% (dez por cento).
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente Lei correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor a partir de 1º de outubro do corrente ano, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos dois dias do mês de outubro de 1986.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
