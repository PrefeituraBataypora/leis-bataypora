**LEI Nº-68/86, De 30 de maio de 1986.**
{ .centro }

Dispõe sobre doação de Bem Imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a demolir e doar um prédio de madeira, com 35m², para o Centro Rural do Bairro da Festa.
{ #art-1 }

Parágrafo Único - O prédio de que trata este artigo é o de propriedade do Município, onde funcionava uma das salas da Escola Rural Municipal José Bonifácio, no Bairro da Festa.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos trinta dias do mês de maio de 1986.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
