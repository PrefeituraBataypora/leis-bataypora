**LEI Nº-75/86, De 28 de novembro de 1986.**
{ .centro }

Dispõe sobre aquisição de ônibus, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a adquirir por compra direta ou em leilão público, 1 (um) ou 2 (dois) ônibus usados, até o valor de CZ$-500.000,00 (quinhentos mil cruzados) cada um.
{ #art-1 }

**Art. 2º** - Os ônibus adquiridos de conformidade com o artigo 1º, é para transportar alunos de 1º Grau, da Zona Rural para a Zona Urbana do Município.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-4 }

**Art. 5º** - Revogam-se as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Bataiporã-MS., aos vinte e oito dias do mês de novembro de 1986.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
