**LEI Nº-65/86, De 09 de abril de 1986.**
{ .centro }

Declara de Utilidade Pública o "Sindicato dos Trabalhadores Rurais de Bataiporã", e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica declarado de Utilidade Pública para todos os efeitos legais o "SINDICATO DOS TRABALHADORES RURAIS DE BATAIPORÃ-MS", entidade sem fins lucrativos, com sede na cidade de Bataiporã, à Rua Ataliba Ramos, nº-1.513.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS., aos nove dias do mês de abril de 1986.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, e afixado em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
