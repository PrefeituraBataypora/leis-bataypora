**Lei nº. 1.402, de 10 de setembro de 2025.**
{ .centro .revogado .tudo }

“Altera a redação dos artigos 2º e 5º da [Lei nº. 1090/2015](../2015/lei-1090-2015.md) de 24 de março de 2015, e dá outras providências”.
{ .revogado .tudo }

O **PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL**, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** Os artigos 2º e 5º da [Lei nº 1090/2015](../2015/lei-1090-2015.md) de 24 de março de 2015, passam a vigorar com a seguinte redação:
{ #art-1 .revogado }

> “Art. 2º ...
> { .revogado .tudo }
>
> Parágrafo único. O Fundo de Habitação de Interesse Social – FHIS fica vinculado à Secretaria Municipal de Infraestrutura Pública - SEINFRA.” (NR)
> { .revogado .tudo }

*\[....\]*
{ .revogado .tudo }

> “Art. 5º ...
> { .revogado .tudo }
>
> § 1º
> { .revogado .tudo }
>
> § 2º A Presidência do Conselho Gestor de FHIS será exercida pelo Secretário Municipal de Infraestrutura Pública; (NR)
> { .revogado .tudo }
>
> § 3º
> { .revogado .tudo }
>
> § 4º Compete à Secretaria Municipal de Infraestrutura Pública – SEINFRA proporcionar os meios necessários para o exercício das competências do Conselho Gestor do FHIS.” (NR)
> { .revogado .tudo }

**Art. 2º** Revogam-se as disposições em contrário, e em especial a Lei nº. [1.210/2019](../2019/lei-1210-2019.md), de 4 de setembro de 2019, e a [Lei nº. 1.229, de 24 de março](../2020/lei-1229-2020.md) de 2020.
{ #art-2 .revogado }

**Art. 3º** Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 .revogado }

Batayporã-MS, 10 de setembro de 2025.
