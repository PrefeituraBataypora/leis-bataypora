**LEI Nº-368/97, De 09 de outubro de 1997.**
{ .centro }

Dispõe sobre aquisição de mudas de café para doação aos proprietários nos Assentamentos: São Luiz, São João e Mercedina.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a aquisição para doação de mudas de café aos produtores assentados nos assentamentos: São Luiz, São João e Mercedina.
{ #art-1 }

§1º - A doação a que se refere este artigo será feita na proporção de 50 (cinquenta) mudas de café por propriedade.

§2º - Fica sob a responsabilidade da Secretaria Municipal de Agricultura o acompanhamento e fiscalização para o fiel cumprimento desta lei, cujo preço unitário não poderá exceder à R$ 0,30 (trinta centavos).

**Art. 2º** - As despesas decorrentes com a execução desta Lei correrão por conta de dotação orçamentária constante do orçamento em vigor.
{ #art-2 }

**Art. 3º** - O Executivo Municipal regulamentará a presente lei, através de Decreto.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã aos nove dias do mês de outubro de um mil novecentos e noventa e sete.

Agenor Gamba
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

MÁRIO FUSANO
{ .centro }

Secretário Mun. de Administração
{ .centro }
