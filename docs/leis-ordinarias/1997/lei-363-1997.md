**LEI Nº-363/97, De 30 de junho de 1997.**
{ .centro }

Dispõe sobre o Orçamento Plurianual de Investimentos para o período de 1998 a 2000.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, no uso das atribuições legais, faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - O Orçamento Plurianual de Investimento do Município de Batayporã-MS., para os anos de 1998 à 2000, discriminados nos quadros anexos que integram a presente, estima a Receita para o triênio em R$ 9.700.000,00 (Nove milhões e setecentos mil reais), e programa para a realização das despesas de igual importância, no mesmo período.
{ #art-1 }

**Art. 2º** - A receita estimada, proveniente de diversas fontes, arrecadar-se-á, de conformidade com a legislação em vigor, observando o desdobramento no quadro nº. 01.
{ #art-2 }

**Art. 3º** - As despesas programada deverão ser realizadas na forma constante do anexo nº 02.
{ #art-3 }

**Art. 4º** - Os orçamentos dos exercícios de 1998 à 2000, consignarão dotações correspondentes às despesas programadas desta Lei:
{ #art-4 }

**Art. 5º** - Esta lei entrará em vigor, na data de sua publicação ou afixação.
{ #art-5 }

**Art. 6º** - Revogam-se as disposições em contrário.
{ #art-6 }

Prefeitura Municipal de Batayporã-MS, aos trinta dias do mês de junho de 1997.

AGENOR GAMBA
{ .centro }

Prefeito
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

MÁRIO FUSANO
{ .centro }

Secretário de Administração
