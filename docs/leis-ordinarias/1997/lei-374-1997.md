**LEI Nº-374/97, De 15 de dezembro de 1997.**
{ .centro }

Estima a Receita e fixa a Despesa do Município de Batayporã-MS, para o exercício de 1998.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais,

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - O Orçamento Geral do Município de Batayporã para o exercício financeiro de 1998, estima a Receita em R$ 6.000.000,00 (Seis milhões de reais), e fixa a Despesa em R$ 6.000.000,00 (Seis milhões de reais).
{ #art-1 }

**Art. 2º** - A Receita será realizada mediante a arrecadação dos Tributos, rendas e outras receitas correntes e de capital, na forma da legislação em vigor e das especificações constantes do anexo nº 2 da Lei nº 4320/94, com os seguintes desdobramentos:
{ #art-2 }

| Discriminação | Valor (R$) |
|---|---:|
| **01- RECEITAS CORRENTES** | **5.400.000,00** |
| 11- Receita Tributária | 1.640.000,00 |
| 1.1- Receita Patrimonial | 20.000,00 |
| 1.2- Transferências Correntes | 3.440.000,00 |
| 1.3- Outras receitas Correntes | 300.000,00 |
| **02- RECEITAS DE CAPITAL** | **600.000,00** |
| 21- Operações de Crédito | 450.000,00 |
| 22- Alienação de Bens | 100.000,00 |
| 2.2- Transferências de Capital | 50.000,00 |
| **TOTAL DAS RECEITAS** | **6.000.000,00** |
