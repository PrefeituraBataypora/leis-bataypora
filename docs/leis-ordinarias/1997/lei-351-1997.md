**LEI Nº-351/97, De 19 de fevereiro de 1997.**
{ .centro }

Dispõe sobre concessão de desconto para quitação de Débitos inscritos em Dívida Ativa, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Art. 1º** - Fica o Executivo Municipal autorizado a conceder desconto de 10% (dez) a 40% (quarenta) por cento, àqueles que quitarem os débitos inscritos em Dívida Ativo do Município conforme segue adiante discriminado:
{ #art-1 }

- 40% para pagamento efetuado até 31-03-97
- 30% para pagamento efetuado até 30-04-97
- 20% para pagamento efetuado até 31-05-97
- 10% para pagamento efetuado até 30-06-97

**Art. 2º** - Fica o setor de Tributação autorizado a realizar o recebimento dos pagamentos, obedecendo os percentuais de descontos e seus respectivos prazos.
{ #art-2 }

**Art. 3º** - As despesas decorrentes da execução desta Lei correrão por conta de dotação orçamentária constantes do orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos dezenove dias do mês de fevereiro de 1997.

AGENOR GAMBA
{ .centro }

Prefeito
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

MÁRIO FUSANO
{ .centro }

Secretário
