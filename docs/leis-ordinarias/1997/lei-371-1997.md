**LEI Nº-371/97, De 05 de novembro de 1997.**
{ .centro }

Dispõe sobre aquisição de lotes urbanos e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a adquirir os lotes 16 e 18 da quadra 38, que consta pertencer a MAURO FRANCISCO DE OLIVEIRA e JOAQUIM CÂNDIDO DOS SANTOS ou a quem de direito, respectivamente.
{ #art-1 }

**Art. 2º** - Fica o Executivo Municipal autorizado a pagar pela aquisição, a importância de até R$ 2.520,00 (Dois mil, quinhentos e vinte reais), por cada lote.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução desta Lei, correrão por conta de dotações orçamentárias próprias constante do Orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta lei entrará em vigor na data de sua publicação, revogando as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã aos cinco dias do mês de novembro de um mil novecentos e noventa e sete.

Agenor Gamba
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

Mário Fusano
{ .centro }

Secretário Mun. de Administração
{ .centro }
