**LEI Nº-370/97, De 05 de novembro de 1997.**
{ .centro }

Dispõe sobre concessão de desconto de 50% sobre a Dívida Ativa e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, usando de suas atribuições legais, Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a conceder o desconto de 50% (cinqüenta por cento), sobre os débitos inscritos em dívida ativa, referente a taxa de conservação de estradas.
{ #art-1 }

**Art. 2º** - Além do desconto constante do artigo anterior, fica também autorizado a anistiar pagamento de juros e multas incidentes sobre os mesmos.
{ #art-2 }

**Art. 3º** - Somente poderão usufruir dos benefícios desta Lei, os inscritos em dívida ativa que efetuarem suas quitações até o dia 20-12-97.
{ #art-3 }

**Art. 4º** - Esta lei entrará em vigor na data de sua publicação, revogando as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã aos cinco dias do mês de novembro de um mil novecentos e noventa e sete.

Agenor Gamba
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada

Mario Fusano
{ .centro }

Secretaria Mun. de Administração
