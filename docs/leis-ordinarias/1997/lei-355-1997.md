**LEI Nº-355/97, De 19 de março de 1997.**
{ .centro .revogado .tudo }

Dispõe sobre Subvenção Social, e dá outras providências.
{ .revogado .tudo }

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, no uso das atribuições legais, faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a conceder Subvenção Social no valor de 05 (cinco) salários mínimos, mensal, à APAE-Associação de Pais e Amigos dos Excepcionais de Nova Andradina.
{ #art-1 .revogado }

**Art. 2º** - A Associação beneficiada constante do artigo 1º, fica obrigada a prestar contas de conformidade com as normas do Tribunal de Contas Estadual, à Contabilidade Municipal.
{ #art-2 .revogado }

**Art. 3º** - A contribuição concedida pelo artigo 1º, será paga de 1 a 15 do mês subsequente ao seu vencimento.
{ #art-3 .revogado }

**Art. 4º** - As despesas decorrentes da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-4 .revogado }

**Art. 5º** - Esta Lei entrará em vigor a partir de 01 de março de 1997
{ #art-5 .revogado }

**Art. 6º** - Fica revogada a [Lei nº 255/93](../1993/lei-255-1993.md) de 15 de setembro de 1993, e disposições em contrário.
{ #art-6 .revogado }

**Art. 7º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-7 .revogado }

Prefeitura Municipal de Batayporã-MS, aos dezenove dias do mês de março de 1997.
{ .revogado .tudo }

AGENOR GAMBA
{ .centro .revogado .tudo }

Prefeito
{ .centro .revogado .tudo }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.
{ .revogado .tudo }

MÁRIO FUSANO
{ .centro .revogado .tudo }

Secretário
