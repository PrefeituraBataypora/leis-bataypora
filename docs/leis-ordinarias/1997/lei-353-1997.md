**LEI Nº-353/97, De 19 de março de 1997.**
{ .centro }

Dispõe sobre doação de bem móvel, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a doar em caráter definitivo para a Igreja Católica local os seguintes bens:
{ #art-1 }

- 1 TV Mitsubischi 20" - tombamento nº 2.603
- 1 Video Cassete Philips - tombamento nº 2.604

**Art. 2º** - Fica o setor de Patrimônio e Tombamento autorizado a desmembração dos bens acima do Inventário Patrimonial do Município.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos dezenove dias do mês de março de 1997.

AGENOR GAMBA
{ .centro }

Prefeito
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

MARIO FUSANO
{ .centro }

Secretário
