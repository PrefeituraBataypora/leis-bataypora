**LEI Nº-354/97, De 19 de março de 1997.**
{ .centro }

Dispõe sobre extensão das atividades da AMUBEM, e alteração na destinação das instalações do Balneário Municipal, e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, no uso das atribuições legais, faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Executivo Municipal autorizado a fazer uso das instalções e estrutura esportiva do Balneário Municipal, para funcionamento de extensão das atividades recreativas e culturais do AMUBEM.
{ #art-1 }

**Art. 2º** - Fica o Executivo Municipal autorizado a realizar as adptações e reformas que se fizerem necessárias para salvaguardar a integridade dos usuários.
{ #art-2 }

**Art. 3º** - As despesas decorrentes com a execução da presente Lei correrão por conta de dotação orçamentária constantes do orçamento em vigor.
{ #art-3 }

**Art. 4º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos dezenove dias do mês de março de 1997.

AGENOR GAMBA
{ .centro }

Prefeito
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

MÁRIO FUSANO
{ .centro }

Secretário
