**LEI Nº-365/97, De 13 de agosto de 1997.**
{ .centro }

Dispõe sobre prorrogação de prazo para adesão ao PDV, instituído pela [Lei Municipal nº 357/97](lei-357-1997.md), e dá outras providências.

AGENOR GAMBA, Prefeito Municipal de Batayporã-MS, no uso das atribuições legais, faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica prorrogado no âmbito do Legislativo Municipal o prazo para adesão ao Programa de Demissão Voluntária PDV, instituído pela [Lei Municipal nº 357/97](lei-357-1997.md) de 19-03-97, até o dia 15 de agosto de 1997.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-2 }

Prefeitura Municipal de Batayporã-MS, aos treze dias do mês de agosto de 1997.

AGENOR GAMBA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data supracitada.

MÁRIO FUSANO
{ .centro }

Secretário Mun. Administração
{ .centro }
