**LEI Nº-313/95, De 03 de julho de 1.995.**
{ .centro }

Dispõe sobre doação de imóvel, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo autorizado a doar um imóvel com área de até 1.225,00m² ( um mil, duzentos e vinte e cinco metros quadrados), ao Sr. Ademir Claudio Pereira, portador do RG nº-[omitido] e CIC.-[omitido], dentre os imóveis de propriedade do Município, para implantação de uma Floricultura.
{ #art-1 }

**Art. 2º** - O empresário beneficiado será obrigado a instalar e funcionar a respectiva Floricultura.
{ #art-2 }

**Art. 3º** - O interessado receberá o imóvel constante do artigo primeiro, após a apresentação de uma petição, em que conste a descrição dos objetivos propostos, e detalhe todos os bens a serem incorporados no imóvel objeto da doação, bem como o número aproximado de empregos a serem absorvidos, para a homologação.
{ #art-3 }

Parágrafo único - Os objetivos e detalhamentos constantes deste artigo, são os propostos na Carta e ou Requerimento de Intenção.

**Art. 4º** - O prazo para construção e funcionamento de suas atividades previstos no artigo anterior, é de 12 (doze) meses, com 03 (três) de carência, a partir da publicação da presente Lei.
{ #art-4 }

**Art. 5º** - Não cumpridas às exigências constantes da presente Lei, o imóvel doado retornará ao domínio do Município.
{ #art-5 }

**Art. 6º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-6 }

**Art. 7º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-7 }

Prefeitura Municipal de Batayporã-MS, aos três dias do mês de julho de 1995.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito
{ .centro }
