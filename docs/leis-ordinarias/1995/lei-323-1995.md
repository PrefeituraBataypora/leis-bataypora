**LEI Nº-323/95, De 28 de setembro de 1.995.**
{ .centro .revogado .tudo }

Dispõe sobre nova regulamentação da [Lei nº-234/93](../1993/lei-234-1993.md), de 02.04.93, que autoriza a doação de imóveisl, construção de casas populares, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - Fica aprovado o Regulamento que versa sobre a doação de imóveis urbanos e construção de casas populares no Município de Batayporã.
{ #art-1 .revogado }

**Art. 2º** - As casas populares edificadas ou que vierem a ser edificadas com recursos SHDU/PREFEITURA, se sujeitarão às normas do SHDU e as demais pelas normas da presente Lei.
{ #art-2 .revogado }

**Art. 3º** - Fica assegurado todos os direitos concedidos pela [Lei Municipal 234/93](../1993/lei-234-1993.md), de 02.04.93, e o Decreto Municipal 136/94, de 31.12.94, que o regulamentou.
{ #art-3 .revogado }

## CAPÍTULO I — DA DOAÇÃO { .centro .revogado }

**Art. 4º** - Terá direito a receber o imóvel a título de doação aqueles que preencherem os requisitos do artigo 1º e ítens, da [Lei Municipal nº-234/93](../1993/lei-234-1993.md).
{ #art-4 .revogado }

§1º - Terão prioridade na obtenção do domínio de direito de posse do terreno, aqueles que declararem interesse em construir com recurso próprio, dentro do prazo cedido pela Comissão, e o não cumprimento dentro do prazo acordado acarretará na retomada do direito de posse.
{ .revogado .tudo }

§2º - Não poderá ser concedido novo direito de posse, aqueles que já foram beneficiados uma vez.
{ .revogado .tudo }

§3º - O direito de posse será concedido na proporção de 1 (um) para cada família.
{ .revogado .tudo }

## CAPÍTULO II — DA CONSTRUÇÃO { .centro .revogado }

**Art. 5º** - A partir da vigência desta Lei, fica proibido as construções do tipo 'barraco'.
{ #art-5 .revogado }

Parágrafo único - Aos 'barracos' já instalados será concedido um prazo para construção da moradia definitiva, podendo ser de madeira, alvenaria ou mista(madeira/alvenaria).
{ .revogado .tudo }

## CAPÍTULO III — DOS DIREITOS DO BENEFICIADO { .centro .revogado }

**Art. 6º** - Fica assegurado o direito à posse do imóvel, a todos aqueles beneficiados através da [Lei Municipal 234/93](../1993/lei-234-1993.md), e o Decreto Municipal 136/94, e que não tenham infringido o que nele estão dispostos.
{ #art-6 .revogado }

**Art. 7º** - Desde que o beneficiado esteja enquadrado dentro do que preceitua a [Lei Municipal 234/93](../1993/lei-234-1993.md) e o Decreto Municipal 136/94, após o prazo de 10 (dez) anos, receberá todas as documentações que se fizerem necessárias para a escrituração definitiva do imóvel, aqueles beneficiados com recursos do Convênio SHDU/PREFEITURA, o prazo se estende para 20 (vinte) anos, conforme consta do Convênio.
{ #art-7 .revogado }

§1º - O prazo aqui citado refere-se a imóveis com a casa construída e habitada pelo detentor do direito de posse.
{ .revogado .tudo }

§2º - As transferências já efetivadas antes da vigência da presente Lei tem a validade assegurada.
{ .revogado .tudo }

§3º - Em caso de terreno já edificado aplica-se no que couber, o que está estipulado na [Lei 234/93](../1993/lei-234-1993.md).
{ .revogado .tudo }

**Art. 8º** - Todo o direito de posse de imóvel retomado na forma da Lei, será redistribuído aos carentes interessados, que preencherem os requisitos da Lei.
{ #art-8 .revogado }

**Art. 9º** - Em caso de separação ou falecimento do titular(es) do domínio de posse será feito nos termos que a Lei determinar em caso de divisão de bens entre herdeiros.
{ #art-9 .revogado }

**Art. 10** - Em caso de abandono do lar, por parte de um dos cônjuges, o direito de posse reverterá a favor do cônjuge que estiver permanecido no imóvel.
{ #art-10 .revogado }

## CAPÍTULO IV — DA CASSAÇÃO DO DIREITO DE POSSE { .centro .revogado }

**Art. 11** - Perderá automáticamente o direito de posse do imóvel a favor da Prefeitura Municipal, aqueles que infringirem alguns dos ítens abaixo:
{ #art-11 .revogado }

1- fixar residência fora do Município;
{ .revogado .tudo }

2- não comparecer ao pedido de recadastro feito pela Prefeitura;
{ .revogado .tudo }

3- quando for constatado duplicidade de cadastramento, deverá optar por um único imóvel, e em caso de casal onde cada um dos cônjuges esteja beneficiado, prevalecerá o imóvel que esteja em nome da cabeça do casal;
{ .revogado .tudo }

4- a não manutenção da limpeza do imóvel com capinas periódicas, independente de notificação para limpeza;
{ .revogado .tudo }

5- em caso de imóvel construído, o titular do domínio do direito de posse alugá-lo a terceiros, em desconformidade com a [Lei 234/93](../1993/lei-234-1993.md);
{ .revogado .tudo }

6- aqueles que tiverem o direito de posse de imóvel sem construção, retomado pela Prefeitura, não terá direito a nenhum tipo de indenização.
{ .revogado .tudo }

**Art. 12** - Se necessário for, o Executivo com a participação da Comissão poderá regulamentar esta Lei por Decreto.
{ #art-12 .revogado }

**Art. 13** - Em caso de retomada de direito de posse de imóvel com benfeitoria, será indenizado ao detentor do direito, os gastos que comprovadamente foram realizados pelo mesmo, na execução da benfeitoria.
{ #art-13 .revogado }

**Art. 14** - A transferência do direito de posse sómente será autorizado após analisado pela Comissão, com obtenção de parecer favorável, e posterior deferimento do Executivo Municipal.
{ #art-14 .revogado }

**Art. 15** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-15 .revogado }

Prefeitura Municipal de Batayporã-MS, aos vinte e oito dias do mês de setembro de 1995.
{ .revogado .tudo }
