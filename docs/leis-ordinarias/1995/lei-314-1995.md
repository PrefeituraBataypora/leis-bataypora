**LEI Nº-314/95, De 03 de julho de 1995.**
{ .centro .revogado .tudo }

Altera o artigo 3° e seus §§1°, 2° e 3°, da [Lei Municipal nº-248/93](../1993/lei-248-1993.md), de 25.06.93, e dá outras providências.
{ .revogado .tudo }

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:
{ .revogado .tudo }

**Art. 1º** - O artigo 3° e os parágrafos primeiro, segundo e terceiro, da [Lei nº-248/93](../1993/lei-248-1993.md), de 25.06.93, passam a ter a seguinte redação:
{ #art-1 .revogado }

> “Art. 3º - O Conselho Municipal de Saúde terá a seguinte composição:
> { .revogado .tudo }
>
> I-REPRESENTANTES DO GOVERNO MUNICIPAL:
> { .revogado .tudo }
>
> a. um representante da Secretaria Municipal de Saúde;
> { .revogado .tudo }
>
> b. um representante da Secretaria de Administração;
> { .revogado .tudo }
>
> c. um representante da Secretaria Municipal de Educação e Cultura;
> { .revogado .tudo }
>
> d. um representante da Coordenadoria de Promoção e Assistência Social.
> { .revogado .tudo }
>
> II-DOS PRESTADORES DE SERVIÇO:
> { .revogado .tudo }
>
> a. um representante da F.N.S.;
> { .revogado .tudo }
>
> b. um representante da Sociedade Hospitalar São Lucas;
> { .revogado .tudo }
>
> c. um representante do Centro de Saúde.
> { .revogado .tudo }
>
> III-DOS USUÁRIOS
> { .revogado .tudo }
>
> a. um representante do Centro Rural do Bairro da Festa;
> { .revogado .tudo }
>
> b. um representante da Associação de Desenvolvimento Comunitário de Batayporã;
> { .revogado .tudo }
>
> c. um representante dos Trabalhadores Rurais de Batayporã;
> { .revogado .tudo }
>
> d. um representante da Associação Batayporãense de Ecologia e Cultura;
> { .revogado .tudo }
>
> e. um representante da Associação dos Produtores de Leite de Batayporã-Pró-Leite;
> { .revogado .tudo }
>
> f. um representante da Associação de Moradores da Fazenda Primavera.
> { .revogado .tudo }
>
> §1º - A cada titular do C.M.S., corresponderá um suplente.
> { .revogado .tudo }
>
> §2º - O número de representantes de que trata os incisos I e II, do presente artigo, não será inferior a 50% (cinquenta por cento), dos membros do C.M.S.
> { .revogado .tudo }
>
> §3º - Dos representantes dos usuários, serão escolhidos pelas suas comunidades/e ou representantes de Associações de Moradores, 03 representantes que deverá ser lavrado em Ata e encaminhado ao Prefeito Municipal, que nomeará um de cada unidade.”
> { .revogado .tudo }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-2 .revogado }

Prefeitura Municipal de Batayporã-MS, aos três dias do mês de julho de 1995.
{ .revogado .tudo }

Dr. JOÃO JAMIL MELLA
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.
{ .revogado .tudo }

JOSÉ ANTONIO FRUTUOSO
{ .centro .revogado .tudo }

Secretário
