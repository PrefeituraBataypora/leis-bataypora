**LEI Nº-321/95, De 17 de agosto de 1995.**
{ .centro }

Declara de Utilidade Pública Municipal a Associação de Desenvolvimento Comunitário de de Batayporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica declarado de UTILIDADE PÚBLICA MUNICIPAL, para todos os efeitos legais, a 'ASSOCIAÇÃO DE DESENVOLVIMENTO COMUNITÁRIO DE BATAYPORÃ-MS - ADEPORÃ', Entidade Civil, sem fins lucrativos, com sede à Avenida Antonia Spinosa Mustafá, 1379.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos dezessete dias do mês de agosto de 1995.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
