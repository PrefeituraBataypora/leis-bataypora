**LEI Nº-324/95, De 04 de outubro de 1995.**
{ .centro }

Revoga o inciso III, do [artigo 4º, da Lei nº-299/94](../1994/lei-299-1994.md#art-4), de 07.12.94, do Fundo Municipal de Saúde, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei.

**Art. 1º** - Fica revogado todos os termos do inciso III, do [artigo 4º, da Lei nº-299/94](../1994/lei-299-1994.md#art-4), de 07 de dezembro de 1994.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Batayporã-MS, aos quatro dias do mês de outubro de 1995.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Reristrada em livro próprio da Secretaria de Administração, e fixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
