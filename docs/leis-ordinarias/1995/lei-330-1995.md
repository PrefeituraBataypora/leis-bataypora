**LEI Nº-330/95, De 06 de dezembro de 1995.**
{ .centro }

Denomina o Posto de Saúde da Fazenda Santa Ilídia, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - O Posto de Saúde da Fazenda Santa Ilídia, neste Município, passará a denominar-se 'POSTO DE SAÚDE ODETTE NASSIF JUBRAN'.
{ #art-1 }

**Art. 2º** - As despesas decorrentes da execução da presente Lei, correrão por conta de verba própria, constante no Orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Batayporã-MS, aos seis dias do mês de dezembro de 1995.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
