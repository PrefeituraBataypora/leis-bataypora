**LEI Nº-333/95, De 15 de dezembro de 1995.**
{ .centro }

Dispõe sobre denominação de Vilas e logradouros públicos do Município de Batayporã-MS., e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte lei:

### CAPÍTULO I — PRINCÍPIOS FUNDAMENTAIS { .centro }

**Art. 1º** - Esta Lei dispõe sobre a criação e denominação de Vilas e logradouros públicos do Município, que corresponde aos vilarejos e aglomerações com denominações próprias de ruas, travessas e becos, etc.
{ #art-1 }

## TÍTULO I — VILA NOVA ERA { .centro }

**Art. 2º** - Fica criada e denominada Vila NOVA ERA, localizada nas imediações junto à Quadra nº-01, do perímetro urbano principal, paralela com a Rua Ceará, até a altura do prolongamento da Rua Jair de Abranches Mella, constituídas das quadras nº-1, 2, 3 e 4;
{ #art-2 }

I-Denominações de suas ruas, travessas e praças:

a- Rua Goiás;

b- Rua Guaicurus;

c- Rua Jair de Abranches Mella;

d- Travessa Tupiniquins;

e- Praça Nova Era

f- Rua Iguassú;

g- Rua Cayuás.

### CAPÍTULO II — DAS DISPOSIÇÕES GERAIS E FINAIS { .centro }

**Art. 8º** - A numeração das edificações nas avenidas, ruas e travessas das Vilas, quando de nova nomenclatura, obedecerá acumulação métrica individual de seus logradouros e quando existir continuidade do perímetro urbano principal, prevalecerá as das adjacentes, obedecido a legislação pertinente.
{ #art-8 }

**Art. 9º** - O Poder Executivo dentro de 90 (noventa) dias baixará Decreto disciplinando a numeração das edificações para cada Vila.
{ #art-9 }

**Art. 10** - As denominações constantes da presente Lei, obedecerão os dispostos nos anexos croqui de cada Vila.
{ #art-10 }

**Art. 11** - As despesas decorrentes da execução da presente Lei, correrão por conta de verbas próprias constantes no Orçamento em vigor, suplementadas se necessário for.
{ #art-11 }

**Art. 12** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições contrárias, especialmente as Leis Municipais nº-174/91, 175/91 e 198/92, de 08.11.91, 08.11.91 e 20.05.92.
{ #art-12 }
