**LEI Nº-316/95, De 09 de agosto de 1.995.**
{ .centro }

Dispõe sobre área industrial, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Batayporã-MS. Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - O imóvel adquirido por força da [Lei nº-280/94](../1994/lei-280-1994.md), de 14.04.94, com área de 11,7128ha, sob a Matrícula nº-14.688, Livro 2, de 27.06.94, à margem da Rodovia MS-134 (Alcides Sãovesso), no Bairro Córrego Esperança, de Antonio Honório de Oliveira Filho, passará a área industrial do Município de Batayporã.
{ #art-1 }

**Art. 2º** - As doações e ou alienações de porções da área constante do artigo anterior será feita mediante autorização legislativa.
{ #art-2 }

Parágrafo único - As doações respeitarão as deliberações de instâncias superiores, quando for o caso e/ou a necessidade.

**Art. 3º** - O Poder Executivo Municipal elaborará Projeto dando condições de acesso a todas as indústrias que vierem a se instalar.
{ #art-3 }

**Art. 4º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentarias, constantes no Orçamento Municipal, suplementadas se necessário.
{ #art-4 }

**Art. 5º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, revogadas as disposições em contrário.
{ #art-5 }

Prefeitura Municipal de Batayporã-MS, aos nove dias do mês de agosto de 1995.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito
{ .centro }

Registrada em livro próprio da Secretaria de Administração, e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
