# Lei nº 831/2009

> Altera o Art. 1º da Lei nº 689/2006 de 09/03/2006, e dá outras providências.

**Lei nº. 831/2009 de 02 de dezembro de 2009.**
{ .centro .revogado .tudo }

“Altera o Art. 1º da [Lei nº 689/2006](../2006/lei-689-2006.md#art-1) de 09/03/2006, e dá outras providências”.
{ .revogado .tudo }

**EDSON PERES IBRAHIM**, PREFEITO MUNICIPAL DE BATAYPORÃ, ESTADO DE MATO GROSSO DO SUL, no uso e gozo de suas atribuições legais,
{ .revogado .tudo }

Faz saber que a Câmara Municipal aprovou e o Poder Executivo sanciona e promulga a seguinte lei:
{ .revogado .tudo }

**Art. 1º** O artigo 1º da [Lei nº 689/2006](../2006/lei-689-2006.md#art-1), de 09/03/2006, passa a vigorar com a seguinte redação:
{ #art-1 .revogado }

> “Art. 1º. Fica o Poder Executivo Municipal autorizado a conceder subvenção social à Associação de Pais e Amigos dos Excepcionais – APAE, pessoa jurídica de direito privado sem fins lucrativos, inscrita no CNPJ sob nº 01.239.173/0001-20, com sede à Rua Jair de Abranches Mella, nº 1027, município de Batayporã-MS, no valor de R$10.000,00 (dez mil reais) mensais, a partir do mês de janeiro de 2010.”
{ .revogado .tudo }

**Art. 2º** Esta lei entrará em vigor na data de sua publicação e/ou afixação, revogadas as disposições em contrário, e em especial a [Lei nº 752/2008](../2008/lei-752-2008.md), de 14 de fevereiro de 2008.
{ #art-2 .revogado }

Prefeitura Municipal de Batayporã-MS., aos dois dias do mês de dezembro de 2009.
{ .revogado .tudo }

**Edson Peres Ibrahim**
{ .centro .revogado .tudo }

Prefeito Municipal
{ .centro .revogado .tudo }

Registrado em livro próprio da Secretaria de Administração, Finanças e Planejamento, e afixado em local de costume em data acima citada.
{ .revogado .tudo }

**José da Rocha**

Secretário
