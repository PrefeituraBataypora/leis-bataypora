**LEI Nº-031/84, De 16 de novembro de 1984.**
{ .centro }

Dispõe sobre aumento salarial aos Servidores Públicos Municipais, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã, Estado de Mato Grosso do Sul.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica concedido um aumento de 75% (setenta e cinco por cento) sobre os vencimentos, aos Servidores Públicos do Município.
{ #art-1 }

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de dotações orçamentárias constantes no orçamento em vigor.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor, a partir do primeiro dia do mês de novembro do corrente ano.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos dezesseis dias do mês de novembro de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, no livro de Leis nº-06 (seis) e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
