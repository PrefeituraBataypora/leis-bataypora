**LEI Nº-033/84, De 16 de novembro de 1984.**
{ .centro }

Dispõe sobre doação de prédio.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a efetuar a doação do prédio onde funciona a Central Telefônica e P.S. de Bataiporã, para a TELEMAT S/A-Telecomunicações de Mato Grosso S/A.
{ #art-1 }

Parágrafo Único - Prédio construído no imóvel denominado data nº-17 da quadra nº-25, rua Ataliba Ramos, nesta cidade.

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos dezesseis dias do mês de novembro de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Deptº Geral de Administração, no livro de Leis nº-06 (seis) e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
