**LEI Nº-036/84, De 20 de dezembro de 1984.**
{ .centro }

Dispõe sobre transposição de dotação orçamentária, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS., no uso e gozo de suas atribuições que lhe são conferidas por Lei, e consoante ao disposto no artigo 61, parágrafo 1º, letra "a" da Constituição Federal.

Faz saber que a Câmara Municipal aprovou e ele sanciona e promulga a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a realizar a transposição das seguintes dotações orçamentárias:
{ #art-1 }

| Dotação | Valor |
|---|---:|
| **I - PODER LEGISLATIVO** | |
| **Câmara Municipal** | |
| 4100 - Investimentos | |
| 4120 - Equip. e Material Permanente | Cr$-2.000.000,00 |
| **II - PODER EXECUTIVO** | |
| **Deptº Geral de Administração** | |
| Gabinete do Secretário | |
| 4100 - Investimentos | |
| 4120 - Equip. e Material Permanente | Cr$-1.000.000,00 |
| **Deptº Geral de Administração** | |
| Deptº Obras e Serviços Urbanos | |
| 4200 - Inversão Financeira | |
| 4210 - Aquisição de Imóveis | Cr$-1.740.000,00 |
| **TOTAL** | **Cr$-4.740.000,00** |

**Art. 2º** - As dotações constantes do artigo 1º desta Lei ficam transpostas para as dotações a seguir:
{ #art-2 }

| Dotação | Valor |
|---|---:|
| **I - PODER LEGISLATIVO** | |
| **Câmara Municipal** | |
| 3100 - Despesas de Custeio | |
| 3111 - Pessoal Civil | Cr$-1.507.000,00 |
| 3120 - Material de Consumo | Cr$-1.462.000,00 |
| 3132 - Outros Serv. e Encargos | Cr$-1.771.000,00 |
| **TOTAL** | **Cr$-4.740.000,00** |

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos vinte dias do mês de dezembro de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }
