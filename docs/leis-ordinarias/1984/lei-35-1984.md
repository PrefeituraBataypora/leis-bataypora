**LEI Nº-035/84, De 21 de novembro de 1984.**
{ .centro }

Dispõe sobre crédito suplementar adicional no orçamento vigente e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a abrir crédito suplementar adicional, junto ao Departamento de Contabilidade até o limite de Cr$-47.529.000 (quarenta e sete milhões, quinhentos e vinte e nove mil cruzeiros), para cobrir insuficiências das dotações do orçamento vigente.
{ #art-1 }

**Art. 2º** - O crédito previsto no artigo 1º será coberto neste exercício, com recursos provenientes de excesso de arrecadação a verificar, de acordo com o artigo 43, §1º, ítem II, da Lei nº-4.320/64.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e um dias do mês de novembro de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro de Leis nº-06 (seis) e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
