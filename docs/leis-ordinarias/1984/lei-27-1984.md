**LEI Nº-027/84, De 26 de setembro de 1984.**
{ .centro }

Dispõe sobre crédito suplementar adicional no Orçamento vigente e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a abrir crédito suplementar adicional, junto ao Departamento de Contabilidade até o limite de Cr$-80.000.000,00 (oitenta milhões de cruzeiros), para cobertura das seguintes dotações orçamentárias no Orçamento vigente:
{ #art-1 }

| Dotação | Valor |
|---|---:|
| **I - Poder Legislativo** | |
| 3111 - Pessoal Civil | Cr$-4.500.000,00 |
| 3120 - Material de Consumo | Cr$-1.000.000,00 |
| 3132 - Outros Serv. e Encargos | Cr$-3.000.000,00 |
| 4120 - Equip. e Mat. Permanente | Cr$-2.000.000,00 |
| **TOTAL** | **Cr$-10.500.000,00** |
| **II - Poder Executivo** | |
| 3111 - Pessoal Civil | Cr$-32.500.000,00 |
| 3120 - Material de Consumo | Cr$-10.000.000,00 |
| 3131 - Remuneração de Serv. Pessoais | Cr$-1.500.000,00 |
| 3132 - Outros Serv. e Encargos | Cr$-8.000.000,00 |
| 4110 - Obras e Instalações | Cr$-10.000.000,00 |
| 4120 - Equip. e Mat. Permanente | Cr$-5.000.000,00 |
| 4210 - Aquisição de Imóveis | Cr$-2.500.000,00 |
| **TOTAL** | **Cr$-69.500.000,00** |
| **TOTAL GERAL** | **Cr$-80.000.000,00** |

**Art. 2º** - O crédito previsto no artigo 1º será coberto neste exercício, com recursos provenientes de excesso de arrecadação a verificar, de acordo com o artigo nº-43, §1º, ítem II da Lei 4.320/64.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos vinte e seis dias do mês de setembro de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro de Leis nº-06 (seis) e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
