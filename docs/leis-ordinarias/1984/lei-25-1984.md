**LEI Nº-025/84, De 31 de maio de 1984.**
{ .centro }

Dispõe sobre a abertura de créditos suplementares no Orçamento do Município, para o exercício financeiro de 1984 e dá outras providências.

O Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica o Poder Executivo Municipal autorizado a abrir créditos suplementares até a importância de 30% (trinta por cento) do Orçamento Municipal do exercício financeiro de 1984.
{ #art-1 }

**Art. 2º** - Esta Lei entrará em vigor na data de sua publicação ou afixação.
{ #art-2 }

**Art. 3º** - Revogam-se as disposições em contrário.
{ #art-3 }

Prefeitura Municipal de Bataiporã-MS, aos trinta e um dias do mês de maio de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro de Leis nº-06 (seis) e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
