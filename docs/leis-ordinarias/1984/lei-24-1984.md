**LEI Nº-024/84, De 18 de maio de 1984.**
{ .centro }

Dispõe sobre aumento dos vencimentos dos Servidores da Câmara Municipal de Bataiporã-MS, e dá outras providências.

JOÃO JAMIL MELLA, Prefeito Municipal de Bataiporã-MS.

Faço saber que a Câmara Municipal aprovou e eu sanciono e promulgo a seguinte Lei:

**Art. 1º** - Fica majorado em 50% (cinquenta por cento) os vencimentos dos Servidores da Câmara Municipal de Bataiporã-MS regidos pela CLT Consolidação das Leis do Trabalho.
{ #art-1 }

**Art. 2º** - As despesas decorrentes com a execução da presente Lei, correrão por conta de verba própria constante no orçamento em vigor, suplementadas se necessário.
{ #art-2 }

**Art. 3º** - Esta Lei entrará em vigor na data de sua publicação ou afixação, retroagindo seus efeitos a partir de 1º de maio de 1984.
{ #art-3 }

**Art. 4º** - Revogam-se as disposições em contrário.
{ #art-4 }

Prefeitura Municipal de Bataiporã-MS, aos dezoito dias do mês de maio de 1984.

Dr. JOÃO JAMIL MELLA
{ .centro }

Prefeito Municipal
{ .centro }

Registrada em livro próprio do Departamento Geral de Administração, no livro de Leis nº-06 (seis) e afixada em local de costume em data acima citada.

JOSÉ ANTONIO FRUTUOSO
{ .centro }

Secretário
{ .centro }
