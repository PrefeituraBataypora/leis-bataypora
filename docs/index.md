# Legislação Municipal

A legislação municipal de Batayporã (MS) em texto pesquisável, com histórico de cada mudança.

Os textos vêm dos PDFs publicados na página de
[Legislação Municipal da prefeitura](https://bataypora.ms.gov.br/cidadao/legislacao-municipal)
e foram convertidos automaticamente, alguns por OCR (reconhecimento de texto em documentos
escaneados).

!!! warning "Textos em revisão"
    Os textos ainda estão **em revisão** e podem ter erros de conversão, principalmente nas
    leis escaneadas. Toda página tem o link para o PDF publicado pela prefeitura.

## Como usar

- **Buscar:** use a caixa de busca no topo para procurar qualquer palavra em todas as leis.
- **Citar um artigo:** os artigos têm link próprio. Por exemplo, `.../lc-003-2001/#art-5`
  abre direto no art. 5º.
- **Ver o que mudou:** cada lei é um arquivo no GitHub. O ícone de relógio, no canto direito
  ao lado do título, abre a lista de todas as alterações feitas no texto daquela lei.
- **Corrigir um erro:** o ícone de lápis abre o texto para edição no GitHub. Quem quiser pode
  propor a correção comparando com o PDF publicado pela prefeitura.
